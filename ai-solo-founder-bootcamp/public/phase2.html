    【W8 · 中文媒体的 AI 自动化】围绕中文媒体制作、审核与交付内容素材，准备接入 W10 发布流程。

    🎯 现场看的是产线怎么跑，这里补的是工具怎么选、成本怎么算

    视觉这块工具换得比谁都快，重点不是记住某个工具，是记住「什么场景该用哪一层」。三层结构：生成层（文生视频 / 文生图）、形象层（数字人 / 角色一致性）、后期层（配音 / 剪辑 / 尺寸）。

    视频层选型

    文生视频按「真实感 / 运镜 / 中文生态 / 出片速度」分场景，产品 demo、founder story、15s hook 各自适合的不一样；数字人层做「一个形象多语言对口型」，适合 cold outreach 和批量讲解；配音剪辑层负责把片子变成能发的成品（配音 + BGM + 字幕 + 多平台尺寸）。

    静态图层选型

    按「海报 / 产品图 / 改图」分开选：中英文字渲染准的做海报，brand 一致 + 矢量导出的做品牌物料，去背换景的做产品图，低分辨率提升的做投流素材。品牌一致性靠把 W5 定的 brand 段写进 prompt 锁住，不靠每次碰运气。

    漫剧：角色一致性是唯一的难点

    漫剧（连续动画短剧）不用出镜、可批量、留存高、适合连续 IP。最容易翻车的是同一个角色每集长得不一样。做法：先出角色三视图设定图锁死形象，再用它作为参考图喂给图生动画工具保持跨镜头一致，配音用多角色音色区分。另外要搞清各平台的漫剧分账与引流规则，决定你是走分账还是纯导流。

    📋 验收

    一张属于你自己的「场景 → 工具」决策表 + 一条 60s 成片 + 一套 launch 视觉资产（1 张小红书封面 + 1 张投流海报 + 1 张 hero 图，中英文双版）+ 一份成本产能账：一条片的 API / 工具月成本是多少，你每周能稳定产几条。

    1. 三层工具栈与场景决策表（40min）：把生成层 / 形象层 / 后期层的候选工具各列 3-5 个，逐个标注：擅长什么、中文支持如何、出片速度、月成本。然后写成一张「我要做 X 就用 Y」的决策表存进 SoT，之后不再每次重新选。
    2. 出一条 60s 成片 + 三种平台尺寸（40min）：选一个真实卖点，走完脚本 → 画面 → 配音 → 剪辑 → 字幕 → 导出三尺寸的全流程。第一次做慢是正常的，记录每一步实际花了多久，这是算产能的原始数据。
    3. 出一套 launch 视觉资产（35min）：为自己产品出小红书封面、投流海报、hero 图各一张，中英文双版，全部带上 W5 定的 brand 段。做完摆在一起看：像不像同一个品牌出的？不像就说明 brand 段写得不够具体。
    4. 角色设定图 + 一集漫剧样片（可选）（20min）：走漫剧路线的：先出角色三视图设定，再做一集 60-90s 样片 + 3 集剧本大纲，并定好走平台分账还是导流到自己产品。不走漫剧的这一步跳过，把时间加到成片和海报上。
    5. 成本产能账：一条片多少钱、一周能出几条（15min）：把工具订阅 + API 调用摊到单条片上，对比外包剪辑的工时报价。然后定一个你真能维持的产能（比如每周 2 条视频 + 5 张图），写进 W6 的 sprint 模板里当固定项——产能定得太高，第三周就会停。

      [W9·自学] Reddit / IndieHackers 社区策略

      【W9 · 英文媒体的自动化】配套练习：整理英文渠道资料，生成有依据的内容或外联草稿，经人工审核后交付。

      🎯 不要发 spam，要发『价值帖』

      Reddit / IndieHackers 社区对 self-promotion 极度敏感（一发被删 + ban），但对『我用 X 工具解决了 Y 问题』这种价值帖欢迎度高。公式：90% 价值 + 10% 软提产品。课上发 20 个真实『价值帖 → 转化 100+ 用户』案例分析。

      1. 社区规则：90% 价值 + 10% 软提（20min）：讲清 Reddit / IndieHackers 对 self-promotion 的敏感度（硬广一发被删 + ban），以及『我用 X 解决了 Y』价值帖为什么受欢迎。拆 subreddit 选择、karma 门槛、发帖时段、软提产品的合规位置（评论区 / 文末一句 / profile）。
      2. 拆 20 个『价值帖 → 100+ 用户』案例（20min）：过 20 个真实案例，标出每篇的钩子、价值密度、软提手法、引流路径。归纳成 4 类可复制的价值帖型（教程 / 数据复盘 / 工具对比 / 踩坑总结）。

      【W10 · AI 内容工厂：实现 AI 自动化发布】承接 W8–W9 已审核的中英文内容，搭建选题 → 生成 → 人工审核 → 排程 → 发布 → 状态回读的工作流。

      1. 复盘 W8–W9 中英文内容资产，确定发布目标（15min）：检查已有图文、短视频与品牌资料，确定目标账号、内容来源、人工审核人和本次允许发布的范围。

      [现场课] 让人和 AI 都搜到你 · SEO & GEO

      本周真实动作：给产品页做完 long-tail SEO + GEO + E-E-A-T + Schema，并提交 GSC 验证。

      🎬 现场 3 小时 · 6 个环节

      1. ①传统 SEO vs GEO：两套逻辑，两种写法30min ChatGPT search / Perplexity / Claude search 已分走 15-20% 的搜索流量，所以要双线：传统 SEO 强 long-tail keyword + technical SEO + backlink；GEO 强 cite-worthy 内容 + 结构化数据 + entity authority。两者的内容写法不一样——GEO 要的是能被 AI 整段引用的段落（有明确结论、有可核实的数据、有清晰的实体关系），不是关键词密度。
      2. ②拆真实 GSC 数据找 long-tail 机会35min 用 jiangren.com.au 的真实 Search Console 数据现场演示：怎么找 long-tail 机会词、看哪些页有曝光没点击、哪些 query 已经被 AI 搜索引用。讲一个产品页同时做 SEO 和 GEO 的落地步骤，以及为什么新站前三个月只该做 long-tail。
      3. ③用 AI 产 long-tail 内容矩阵30min 把学员产品拆成一组 long-tail 关键词 + 对应内容主题，每个对应一个真实搜索意图（不是关键词变体堆砌）。生成内容矩阵表，标出哪些优先写、哪些适合做成 GEO 引用源。重点讲怎么判断一个词是不是「你现在能排上的」——看现有结果的质量和站点权重，不看搜索量。
      4. ④E-E-A-T 四要素落到产品页25min 把 Experience / Expertise / Authoritativeness / Trustworthiness 翻译成产品页上的可执行项：Author 框带 LinkedIn、真实 case study、外部引用与媒体提及、联系方式与公司信息（澳洲的话把 ABN 放上去很加分）。讲为什么 AI 搜索时代 E-E-A-T 权重更高——AI 只引可信源。
      5. ⑤给产品页加 Schema.org JSON-LD 现场实操35min 现场给学员产品页加 FAQPage / SoftwareApplication / Person 三种 JSON-LD，用 Cursor 直接写进页面，逐个过必填字段。讲 GEO 视角下结构化数据怎么帮 AI 准确理解你是谁、做什么、跟谁有关。
      6. ⑥提交 GSC 验证 + 定本周清单25min 现场把改好的页提交 Google Search Console 的 Rich Results 测试和 URL 检查，确认 schema 通过。每人对照 E-E-A-T 清单查自己产品页还缺哪几项，列出本周要补的，并定下 10 个目标词 / 3 篇优先内容 / 1 个 GEO 优化点。TA 1:8 审关键词搜索意图是否真实、够不够细到能排上。

      [现场课] 用户增长 · Growth Hacking

      本周真实动作：填完 AARRR 五环表找出最大漏水环，上线一个推荐循环，跑一次 10 渠道 launch。

      🎬 现场 3 小时 · 6 个环节

      1. ①AARRR 五环 + 一人公司为什么只能修一个环25min 逐环解释定义和常见误用（把访问量当获取成果、把注册当激活、把没退款当留存）。讲「最大漏水环」原则：修转化率最低的那一环，投入产出比通常是修其他环的 3-5 倍。一人公司同时修多个环 = 一个都修不完。
      2. ②现场拉数据填五环表 + 算转化率找漏水环30min 打开自己的 PostHog / Plausible 和 Stripe 后台，把五环的原始数字填进表：各渠道访问、关键动作完成数、回访数、付费数、老带新数。没埋点的当场补（讲师给最小埋点清单），数据不足的先记「待测」不要瞎填。逐环算转化率并跟三类产品（B2B SaaS / C 端工具 / 生产化服务）的参考区间比，找出偏离最大的那一环，写下结论：本周只修这一环。
      3. ③AI 出 3 个改法，选 1 个成为下周实验假设25min 把卡点环的原始数据和产品上下文喂给 AI，让它出 3 个具体改法——不要「优化文案」这种废话，要「把首屏的三段介绍换成一句用户原话 + 一个 30 秒 demo」这种。选一个写成实验假设：因为观察到 X，我认为做 Y 会让 Z 提升到 N。
      4. ④三种循环 + K 因子怎么算25min 激励型 / 协作型 / 产出型三种循环，逐个讲适用形态、上线成本、常见翻车点：激励型翻车在给现金和防刷没做；协作型翻车在产品本来就是单人使用还硬加邀请；产出型几乎不翻车但天花板低。最实际的做法是先上产出型（零成本），再看要不要加激励型。K = 人均邀请数 × 邀请转化率，现场算一个例子，讲清为什么 K>1 在小众 B2B 里基本不可能。
      5. ⑤选一种循环写完整机制 + 本周上线最小版本25min 每人写四件事：奖励是什么（非现金）、触发点在哪（用户刚获得价值的那一刻，不是注册时）、怎么归因（邀请码 / 专属链接 / 手动记账都行，小规模别过度工程）、怎么防刷（同 IP / 同支付方式 / 需完成关键动作才计数）。最小版本要求这周就能上线：写代码的加一个带参数的分享链接；不写代码的在交付物页脚 / 邮件签名 / 报告封底加一行来源链接。
      6. ⑥一个 launch 跑通 10 渠道 + 营销 OS 闭环演示50min 回看 W8-W11 学的所有渠道（小红书 / 视频号 / 公众号 / 私域 / 华人 meetup / 微信群 / 华人媒体 / X / LinkedIn / ProductHunt / Reddit / 本地 tech meetup / Podcast / SEO / GEO），画出「一个 launch 怎么同时点燃 10 渠道」的总图，定义什么算一次 launch。选一个学员真实 launch 现场拆出全套 asset：1 篇 SEO 长文 + 10 条多平台短文 + 5 张海报 + 3 条短视频 + 1 套邮件序列 + 100 条个人化私信。最后跑一遍全自动闭环，每人产出自己的 launch checklist + 工作流图，作为 Phase 2 出关物。

      SELF · 90min
      [W11·自学] 付费投放最小实验：Meta / Google / 小红书三选一，$200 试出答案

      🎯 一人公司要不要投流？先花 $200 买一个答案

      不投的理由很多（没预算、不会、怕烧钱），但有一件事只有投流能最快告诉你：陌生人看到你的落地页，会不会付钱。内容和 SEO 要几个月才能回答，投流一周就能给你一个粗糙但真实的答案。最小实验四条规矩：① 只投一个渠道——B2B / 英文 → Google Search（买明确意图的关键词）；C 端 / 视觉驱动 → Meta；中文华人受众 → 小红书信息流。三选一，绝不同时开三个。② 预算封顶 $200，跑完就停。③ 只测一个变量。④ 结果无论好坏都写进实验卡片。
