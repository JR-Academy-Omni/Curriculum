# Lab 3 · 组合与发布闭环

## 任务

1. 把通过审核的 Seedance 镜头加入 Lab 1 工程。
2. 再跑一次 `npm run check`，导出最终 MP4 后记录 SHA-256。
3. 分别写 TikTok 和 YouTube Shorts 标题/说明，不直接复制。
4. 生成 `release-manifest.json` 并完成 Human review gate。
5. 已有授权课堂账号：发布并回读；没有账号：停在 `needs-review`，不可伪造回执。

## 提交证据

- 最终 MP4 hash
- 两个平台文案
- 审核人、审核时间与勾选记录
- provider post id、公开 URL、公开回读截图或失败/处理中状态
