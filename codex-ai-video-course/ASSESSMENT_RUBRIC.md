# 结课作品评分标准（100 分）

| 维度 | 分值 | 通过标准 |
|---|---:|---|
| 故事与节奏 | 20 | 前 2 秒信息明确；每个镜头有功能；没有无意义停顿。 |
| Codex / HyperFrames 工程 | 25 | 时间线可读、素材路径可替换、渲染确定、`hyperframes check` 通过。 |
| Seedance 镜头 | 20 | 主体与环境连续；没有明显手脸、文字、穿模或物理错误；保留生成记录。 |
| 平台适配 | 15 | 9:16、字幕安全区、标题/描述/标签分别适配 TikTok 与 YouTube Shorts。 |
| 审核与证据 | 20 | 有版权与账号确认；公开前有人工放行；发布后保存 provider receipt 和 URL 回读。 |

## 一票否决

- 未经人工确认自动公开发布。
- 使用无权发布的音乐、人物肖像或第三方素材。
- 用截图或本地预览冒充平台已发布。
- 提交的 composition 无法在另一台机器按 README 运行。
