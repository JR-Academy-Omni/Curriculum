# Codex AI 视频课

3 次课、共 6 小时。学员从已有素材开始，用 Codex 驱动 HyperFrames 完成程序化剪辑；第二次课用 Seedance 补齐缺失镜头；第三次课把两条链路组合起来，在人工审核后发布 TikTok 与 YouTube Shorts。

## 课程顺序

1. Codex + HyperFrames：素材体检、镜头选择、时间线、字幕与批量变体。
2. Seedance：首尾帧、参考图、运镜提示词、失败镜头诊断与重做。
3. 组合与发布：生成镜头进入 HyperFrames，自动质检，人工放行，平台发布与回读。

## 目录

- `public/outline.json`：课程结构唯一数据源。
- `public/curriculum.html`：公开课程大纲页。
- `hyperframes-starter/`：第一节课可直接 fork 的工程。
- `labs/`：三次课逐步实验与验收证据。
- `prompts/`：Codex、Seedance 和发布审核提示词。
- `PUBLISHING_PLAYBOOK.md`：TikTok / YouTube Shorts 发布流程。
- `ASSESSMENT_RUBRIC.md`：结课作品评分标准。

## 已确认边界

- 不使用剪映、Premiere 或 Remotion。
- 生产剪辑由 Codex + HyperFrames 完成；生成镜头由 Seedance 完成。
- AI 可以准备发布包，但公开发布前必须由人确认账号、文案、音乐版权和最终画面。
- 价格、开课日与讲师尚未确认，不写入课程源文件。
