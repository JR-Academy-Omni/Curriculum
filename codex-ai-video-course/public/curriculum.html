每次课都有明确产出。不是听完“知道了”，而是下课时项目真的向前一步。

CLASS 01

产品卖点与 Seedance 广告镜头

120 MIN＋
  • 从客户、卖点、优惠和渠道出发，确定一条广告要说什么
  • 用 Codex 生成前三秒钩子、广告文案和结构化分镜
  • Seedance 文生视频、图生视频与首尾帧生成实操
  • 组合文字、产品图、参考视频和音频，控制主体、动作与风格
  • 把静态产品图变成展示镜头，并生成真实使用场景与运镜
本节产出

广告脚本 + 分镜 + Seedance 镜头

获得产品特写、动态展示和使用场景等可以进入剪辑的核心素材。

CLASS 02

AI视频特效与自动剪辑包装

120 MIN＋
  • 使用 video-shotcraft 镜头配方，为广告选择正确的视觉节奏
  • 制作产品出场、局部放大、2.5D运镜、粒子、光效与画面延展
  • 用AI完成转场、背景替换、素材融合和有冲击力的视觉变化
  • 让 Codex 创建 Remotion 项目，自动完成镜头、字幕与品牌包装
  • 加入配音、音乐、音效、价格卖点与“立即咨询”等行动号召
本节产出

完成音画包装、品牌信息和行动号召，获得可继续修改的 Remotion 工程。

CLASS 03

广告精修、改版与多平台发布

120 MIN＋
  • 用自然语言修正镜头、特效、字幕、价格和音画同步
  • 用剪映或 Premiere 完成必要的局部精修
  • 掌握成片的信息、节奏、视觉和声音验收标准
  • 生成小红书、视频号、抖音、官网所需的横竖屏版本

FAQ

你可能还想知道

完全不会剪辑或写代码，可以参加吗？

可以。课程重点是做出广告并学会判断效果，Codex只是帮助你执行的工具。我们会解释必要概念，但不会要求你先掌握编程。

Seedance在课程里具体做什么？

它负责把文字、产品图、参考视频和音频变成广告镜头：让静态产品动起来、生成使用场景、控制镜头运动，并为后续特效和剪辑提供动态素材。

课程是不是全部由 AI 自动完成？

主体流程由 Seedance、Codex、AI工具和 Remotion 完成，约占80%。最后约20%用于人工审片和必要的传统剪辑精修，确保广告真正清楚、可信、能发布。

为什么还要学习 Remotion？

Remotion让视频中的镜头、字幕和动画变成可精确控制的组件。相比每次手工拖动时间轴，它更适合让 Codex 修改、复用和批量生成。

上完课可以独立做什么类型的视频？

可以制作产品广告、上新介绍、促销活动、门店展示、服务说明和社交媒体短片，并把同一内容快速改成多个平台版本。

需要准备哪些工具？

建议准备可运行 Codex 和 Remotion 的电脑、Seedance可用账号，以及剪映或 Premiere 中的任意一种作为精修工具。具体版本与费用清单会在开课前提供。
