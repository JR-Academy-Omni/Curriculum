3 CLASSES · 6 HOURS

三次课，从零走到成片。

每次课都有明确产出。不是听完“知道了”，而是下课时项目真的向前一步。

CLASS 01

Codex + HyperFrames 自动剪辑

120 MIN＋
  • 用 ffprobe 读取文件名、时长、画幅、帧率、音轨与编码
  • 让 Codex 先写 SHOTLIST，再决定保留、裁切、排序和画幅
  • 在 HyperFrames 中实现竖版时间线、字幕安全区与 CTA
  • 检查确定性、布局、对比度、黑帧和素材时间范围
  • 把同一工程改成可替换产品、文案和素材的 starter
本节产出

可验证的 HyperFrames 工程

提交镜头表、composition、完整 check 输出，以及 0 秒、6 秒、11 秒三张 snapshot。

CLASS 02

Seedance 生成缺失镜头

120 MIN＋
  • 把现有镜头分成可用、可修复、必须重生三类
  • 用主体、动作、摄影机、环境、节奏与禁用项写镜头提示词
  • 根据目标选择参考图、首尾帧或图生视频路径
  • 逐帧检查主体、手脸、文字、物理、运动方向与连续性
  • 失败后只改一个变量，保留 prompt、参数和淘汰理由
本节产出

合格镜头 + 失败诊断记录

至少一个可进入时间线的生成镜头，以及一个失败案例从 v1 到 v2 的修复证据。

CLASS 03

组合、人工审核与自动发布

120 MIN＋
  • 把通过审核的 Seedance 镜头加入 HyperFrames 时间线
  • 用 Codex 完成节奏、字幕、音量、首帧钩子与末帧 CTA 精修
  • 分别生成 TikTok 与 YouTube Shorts 的平台文案和媒体包
  • 执行技术、内容、版权、账号四层检查与 Human review gate
  • 保存 provider id、公开 URL，并从公开环境回读画面、声音和可见性
结课产出

1 条成片 + 双平台发布闭环

获得最终文件 hash、双平台文案、审核记录；账号已授权时再提交平台回执和公开 URL。

FAQ

你可能还想知道

完全不会剪辑或写代码，可以参加吗？

可以。课程重点是做出广告并学会判断效果，Codex只是帮助你执行的工具。我们会解释必要概念，但不会要求你先掌握编程。

Seedance在课程里具体做什么？

它负责把文字、产品图、参考视频和音频变成广告镜头：让静态产品动起来、生成使用场景、控制镜头运动，并为后续特效和剪辑提供动态素材。

课程是不是全部由 AI 自动完成？

制作环节全部由 Codex、HyperFrames 与 Seedance 完成，不使用传统剪辑软件。公开发布仍由真人审核事实、版权、账号和最终画面。

为什么学习 HyperFrames？

HyperFrames 把镜头、字幕、动画和时间变成 Codex 可直接修改、检查、复用和批量渲染的 HTML 工程。

上完课可以独立做什么类型的视频？

可以制作产品广告、上新介绍、促销活动、门店展示、服务说明和社交媒体短片，并把同一内容快速改成多个平台版本。

需要准备哪些工具？

需要可运行 Codex 与 HyperFrames 的电脑、Seedance 可用账号，以及自己有权使用的练习素材。发布实操需要目标平台账号授权。
