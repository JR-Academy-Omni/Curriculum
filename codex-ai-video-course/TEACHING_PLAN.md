# 教学计划

## Class 1 · Codex + HyperFrames 自动剪辑（120 分钟）

- 0–15：查看最终成片和工程结构，明确原始素材、时间线、输出文件各自职责。
- 15–35：让 Codex 读取素材清单，生成镜头表和剪辑决定，不先写动画。
- 35–65：在 HyperFrames 中实现裁切、排序、画幅、安全区和文字层。
- 65–90：运行 lint / check，修复时间、布局、对比度与不可重复渲染问题。
- 90–110：从同一工程生成 9:16 主版与平台文案草稿。
- 110–120：提交 Lab 1 证据并记录尚未解决的问题。

课堂产出：一条通过 `hyperframes check` 的竖版 composition、镜头表、检查报告。

## Class 2 · Seedance 生成缺失镜头（120 分钟）

- 0–20：把镜头分成可直接使用、可修复、必须重生三类。
- 20–45：写清主体、动作、摄影机、环境、节奏和禁用项。
- 45–70：完成首尾帧或参考图工作流，生成第一轮候选。
- 70–95：逐帧检查脸、手、文字、物理连续性、主体一致性和镜头运动。
- 95–110：只针对失败原因改一个变量，生成第二轮。
- 110–120：登记 prompt、参数、候选与淘汰理由。

课堂产出：至少一个可进入剪辑的生成镜头，以及一个失败案例的诊断记录。

## Class 3 · 组合、质检、人工放行与发布（120 分钟）

- 0–30：把 Seedance 镜头加入 HyperFrames，不破坏已有时间线。
- 30–55：补齐字幕、音量、首帧钩子、末帧 CTA 和平台安全区。
- 55–75：生成 TikTok 与 YouTube Shorts 两个平台包，文案独立，不机械复制。
- 75–95：运行技术、内容、版权和账号四层审核。
- 95–110：人工确认后发布；保存 provider receipt 和公开 URL。
- 110–120：公开回读，核对封面、声音、字幕、比例、标题和链接。

课堂产出：发布准备包；若课堂账号已授权，则再提交 provider 回执和公开回读证据。
