Knowledge check

A prepared invoice has a GST arithmetic mismatch. What should be retained?

  • Only the corrected number.
  • The original field, expected check and review decision.
  • Nothing; approve it anyway.
Answer and reasoning

The original field, expected check and review decision.

Keep source evidence and route discrepancies to the accountable reviewer.

Reference reasoning

The invoice packet yields one review-ready record, one GST arithmetic mismatch, one duplicate and one record missing context. The correct output is a register plus exception queue, not four approved invoices.

展开教学步骤、任务与评审

Connecting Business Tools

把客户跟进、采购或入职等任务串成流程，处理表单、文件和业务工具之间的信息，保留授权、去重与人工确认。

Preparation

Identify the forms, files, shared lists and staff decisions involved. Draw the boundary between preparing an action and executing it.

Client brief

Connect intake, a shared register and a review queue. Process a duplicate event and a changed request. Keep proposed messages and access requests awaiting the right owner.

  • connected-workflow/: input form, shared register and review queue
  • handover-rules.md: identities, approvals, duplicates and recovery
  • change-log.csv: input revision and affected decisions

Review criteria

  • Repeated input does not create repeated work commitments.
  • Changed input is visible and triggers revalidation.
  • The workflow does not silently send, book, pay or grant access.

Decision to obtain

Approve a controlled cross-department workflow.

Knowledge check

A customer changes the preferred time after a reply draft is approved. What should happen?

  • Send the old reply.
  • Reuse the old approval for all revisions.
  • Update the draft and request a new approval.
Answer and reasoning

Update the draft and request a new approval.

Approval applies to the content and revision that was reviewed.

Reference reasoning

A repeated customer enquiry updates the existing record. A changed preferred time invalidates the old draft approval. A changed employee role invalidates the prior access decision; IT still owns provisioning.
