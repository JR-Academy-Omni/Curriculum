## Learning and review

Use AI assistants or Codex for file and task work, then inspect the output. The participant is responsible for source checks, arithmetic, missing fields, permissions, approval, duplicate handling and handover. The course does not require writing an MCP server, production API integration or a full engineering evaluation harness.

Human-facing examples include a complete invoice register and exception queue, a customer response draft and an onboarding responsibility checklist. Deterministic reference code checks the supplied records without models, sends, payments or access grants. Each participant presents their work and contribution and explains a changed condition. Peer/facilitator review criteria are a curriculum plan, not a promise of unspecified staffing hours.

No platform InteractiveLab is referenced or hidden inside another lesson. These are authored case assignments; there are no made-up lab URLs. No automatic gating, certification, P3 entitlement or AI grader is claimed.
