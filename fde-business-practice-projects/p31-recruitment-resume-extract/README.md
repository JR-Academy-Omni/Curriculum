# P31 · 招聘 / 人力外包：简历批量提取成候选人表

| 行业 | 难度 | 时长 | 工具 |
|---|---|---|---|
| 招聘 / 人力外包 | L1 自动化 | 50 分钟 | Claude（Projects）+ Excel / Google Sheets |

## 1. 客户场景

恒信人力在悉尼 Parramatta，专门给中小企业招会计助理、行政和客服。顾问小周每天从招聘网站和邮箱收十几份简历，有中文有英文，有 Word 转出来的纯文本也有 Markdown。她现在是一份份打开，把姓名、电话、工作权利、几年经验、最近一份工作敲进公司的候选人表。一天下来光录入就一个多小时，还老出错：同一个人换了邮箱又投一次，表里就多出一行；两份工作时间叠在一起，经验年限被算多了；有的简历写了出生日期、婚姻、国籍，新同事顺手也录进了表里——这些信息本来就不该进表。

她想要的是：**把一批简历丢进去，拿到一张字段统一、能直接粘进候选人表的表格；重复的人合并，没写清楚的地方标出来让她去问，跟岗位无关的个人信息一个字都不录。**

## 2. 练习数据

`data/resumes/` 下 12 份简历，`R01` 到 `R12`，`.txt` 和 `.md` 混着，中英文都有。全部是练习数据：人名、公司、学校经历、电话（`0400 xxx 000` 这种明显不是真号码的格式）、邮箱（`.example` 域名）都是为这个练习设计的。

要提取成的候选人表字段：

| 字段 | 含义 |
|---|---|
| candidate_id / source_file | 简历编号 / 文件名 |
| full_name / email / phone / location | 姓名、邮箱、电话（统一成 `0400 101 000` 格式）、所在区 |
| work_rights_as_stated | 工作权利，**照抄简历原话**；没写就填「未写明」 |
| total_experience_years | 总工作年限（按月算，保留一位小数） |
| most_recent_title / most_recent_employer | 最近一份工作的职位和公司 |
| key_skills / certifications / availability | 技能、证书、到岗时间 |
| record_status | 保留 / 重复，已合并到 Rxx |
| needs_check | 需要顾问核对的地方，写清原因 |

数据里**故意藏了 5 类问题**：

1. **工作权利没写**：一份简历完全没提，不能按名字、学校去猜。
2. **经历时间重叠**：一份简历两份全职工作重叠了 8 个月，总年限不能直接相加。
3. **同一个人投了两次**：电话一样，一个写 `+61` 开头一个写 `04` 开头，邮箱不同，后一份是更新过的版本。
4. **日期不完整**：一段经历只写了年份，没法按月算。
5. **跟岗位无关的个人信息**：三份简历里写了出生日期和年龄、性别、婚姻、国籍、照片、孩子、宗教。这些一律不提取、不进表、不进备注，也不能影响任何判断。

还有一份证书写的有效期已经过了。

教学假设：澳洲的反歧视和隐私规定不允许用年龄、性别、婚姻、国籍、宗教、家庭责任等做招聘判断，具体适用范围以官方信息和法律意见为准。「学生签证每两周 48 小时」这类说法只照抄简历自述，签证能不能做这份工作，由顾问按官方信息核实，表格不下结论。

## 3. 做法

**第一步：在 Claude 里建一个 Project。** 名字叫「恒信简历录入」。项目说明里写清规则，以后每批简历都用这一份：

```
你是恒信人力的简历录入助手。我会一次上传一批简历文件，请把每份简历提取成候选人表的一行。
字段顺序：candidate_id, source_file, full_name, email, phone, location, work_rights_as_stated,
total_experience_years, most_recent_title, most_recent_employer, key_skills, certifications,
availability, record_status, needs_check。

规则：
1. 电话统一成「04xx xxx xxx」格式，+61 开头的去掉国家码补 0。
2. 工作权利只照抄简历原话。没写就填「未写明」，并在 needs_check 里写「请顾问问本人」。
   不要根据姓名、学校、语言去推测，也不要判断签证够不够做这份工作。
3. 总工作年限按月算：「至今 / present」按 2026 年 11 月；几段经历时间重叠时，重叠的月份只算一次；
   结果 ÷ 12 保留一位小数。某段经历只写了年份、没有月份，就不算总年限，留空，needs_check 写原因。
4. 两段全职工作时间有重叠，在 needs_check 里写出重叠了几个月。
5. 证书写了有效期而且早于 2026 年 11 月，在 needs_check 里提醒。
6. 同一个电话出现在多份简历里，算同一个人：保留简历更新日期最新的那份，其他的 record_status 写「重复，已合并到 Rxx」。
7. 以下信息不提取、不写进任何一列、不写进 needs_check、也不在回复里复述：
   出生日期、年龄、性别、婚姻、怀孕、孩子或家庭情况、国籍、种族、宗教、照片和外貌、健康或残障。
   简历里出现了就当没看见。语言能力如果写在「技能」里，算技能，可以照抄。
8. 先输出 CSV（第一行是表头），再用三五句话列出这批简历里需要顾问跟进的事。不确定的地方写出来，不要猜。
```

**第二步：上传 12 份简历，发一句话：**「把这批简历整理成候选人表。」

**第三步：核对。** 至少手工算一份的年限：打开 `R06.txt`，把三段经历画在一条时间线上，重叠的 2022 年 11 月到 2023 年 6 月只算一次，应该是 57 个月、4.8 年。再在结果里搜一遍「1992」「34 岁」「已婚」「Nationality」「基督」「孩子」，一个都不该出现。

**第四步：粘进候选人表。** 把 CSV 粘进 Google Sheets 或 Excel。`record_status` 为「重复」的那行不要新建候选人，按备注把信息合并到保留的那一行。`needs_check` 不为空的，小周打电话或发邮件时顺手问掉。

> 用 ChatGPT 也可以：建一个 ChatGPT Project（或自定义 GPT），把同样的规则写进说明，一次上传这批文件即可。

## 5. 验收清单

- [ ] 候选人表 12 行，其中 11 行「保留」，R09 标为重复并指向 R12。
- [ ] R06 是 4.8 年，不是 5.4 年；R11 年限留空并写了原因。
- [ ] 表格和回复里没有出现任何出生日期、年龄、性别、婚姻、国籍、宗教、孩子、照片的信息；表头里也没有这类列。
- [ ] R04 工作权利是「未写明」，没有被猜成任何身份；R05、R08 的工作权利是原话照抄，没有「符合 / 不符合」之类的结论。
- [ ] 电话全部是 `04xx xxx xxx` 格式，R03、R12 的 `+61` 已转换。
- [ ] 5 类问题都出现在 `needs_check` 里，每条都写了原因。

## 6. 加分挑战

- 加一份岗位要求（比如「会计助理：Xero、2 年以上 AP/AR 经验」），让 Claude 在表格后面加一列「跟岗位要求的对照」，只对照技能和经验，并说明为什么不能用第 7 条那些信息。
- 第二天再来一批简历，让 Claude 先跟昨天的表按电话和邮箱查重，再出新增的行。
- 让 Claude 为每个 `needs_check` 起草一句给候选人的追问短信，比如「麻烦确认一下您在澳洲的工作权利」，语气客气，不暗示任何结论。

## 7. 简历 / 面试可以这样讲

> 为一家人力外包公司设计简历批量录入流程：用 Claude Project 固化提取规则，把中英文、不同格式的简历统一成候选人表；按电话识别重复投递并保留最新版本，按月合并重叠经历计算工作年限，对工作权利未写明、日期不完整、证书过期等情况标出待核对；在规则里明确排除年龄、性别、国籍、家庭等与岗位无关的信息，并用关键字检查确认没有进表（教学项目，数据为这个练习设计）。
