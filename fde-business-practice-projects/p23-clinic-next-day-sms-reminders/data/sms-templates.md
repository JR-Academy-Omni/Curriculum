# 佳美牙科 次日提醒短信模板（诊所批准的固定写法，练习数据）

只能替换花括号里的内容，不能加治疗项目、医生诊断或任何病情信息。

## 中文（本人）

```
【佳美牙科】{称呼}您好，提醒您明天{日期}{时间}有预约。改约请回复本短信或致电前台。回复STOP退订。
```

## 中文（未成年人，发给监护人）

```
【佳美牙科】{称呼}您好，提醒{孩子名字}明天{日期}{时间}有预约。改约请回复本短信或致电前台。回复STOP退订。
```

## English (patient)

```
Jiamei Dental: Hi {who}, a reminder that you have an appointment at {time} tomorrow, {date}. Reply to this SMS to reschedule. Reply STOP to opt out.
```

## English (minor, to parent / guardian)

```
Jiamei Dental: Hi {who}, a reminder that {child} has an appointment at {time} tomorrow, {date}. Reply to this SMS to reschedule. Reply STOP to opt out.
```

多个孩子同一位监护人：合成一条，名字和时间按先后列出。
