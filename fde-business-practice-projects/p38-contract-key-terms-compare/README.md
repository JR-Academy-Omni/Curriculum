# P38 · 通用：合同关键条款提取成对比表

| 行业 | 难度 | 时长 | 工具 |
|---|---|---|---|
| 通用 | L1 自动化 | 60 分钟 | Claude（Projects）+ Excel / Google Sheets |

## 1. 客户场景

晨光咖啡在布里斯班有三家店（Fortitude Valley、New Farm、West End），一周用掉一千两百多升牛奶。现在的牛奶合同 11 月底到期，老板 Jason 手上有三家供应商发来的合同，全是英文，每份七八节。他以前的做法是只看单价，谁便宜签谁，结果上一份合同有自动续约，忘了提前通知，又被绑了一年。这次他想先看清楚三份合同在期限、续约、付款、赔偿、解约上到底差在哪，再拿着问题去找律师。

他想要的是：**把三份合同丢进去，拿到一张中文对比表，哪条要小心标出来，顺便按我们的用量粗算一年总共花多少钱。**

## 2. 练习数据

三份合同，英文 Markdown（练习数据，供应商、合同编号、邮箱都是为这个练习设计的，邮箱是 `.example` 域名）：

| 文件 | 供应商 |
|---|---|
| `data/contract-A-riverbend-dairy.md` | Riverbend Dairy Co |
| `data/contract-B-sunfield-milk.md` | Sunfield Milk Supply |
| `data/contract-C-coastline-fresh.md` | Coastline Fresh Foods |

对比表要提取的字段：

| 字段 | 说明 |
|---|---|
| 期限 | 开始日期、月数、到期日（到期日 = 开始 + 月数 − 1 天） |
| 续约 | 是否自动续约；不续约要提前多少天书面通知、最晚哪天 |
| 价格 | 每升单价（不含 GST）、能不能调价、怎么调 |
| 送货 | 截单时间、运费、免运费门槛 |
| 付款 | 账期 |
| 质量 / 退货 | 不合格品怎么处理、谁承担变质 |
| 责任上限 | 出了事最多赔多少 |
| 解约 | 违约解约、无理由解约的通知期 |
| 适用法律 | 哪个州 |

数据里**故意藏了 3 类问题**，真实合同常见：

1. **自动续约**：有一份到期不通知就自动续 12 个月，必须在到期前 90 天书面通知。
2. **责任上限低得不正常**：有一份最多只赔 500 澳元或当月货款里更少的那个，而且签收后变质一概不管。
3. **缺少解约条款**：有一份从头到尾没写怎么提前解约。

另外还有一个算账的坑：单价最低的那家，按店里的用量每次送货不到免运费线。

年度粗估用店里自己的估算：每周 1,250 升，每周 18 次送货（3 家店 × 6 次），一年 52 周，不含 GST。牛奶的 GST 处理按教学假设不展开，以 ATO 规定和供应商发票为准。**这个项目只做信息整理，不下法律结论；签合同前必须由律师或懂合同的人审核。**

## 3. 做法

**第一步：在 Claude 里建一个 Project。** 名字叫「晨光咖啡 合同对比」，把三份合同传进去，项目说明写：

```
你是晨光咖啡的合同整理助手。我上传了几份英文供应合同。请做三件事：
1. 逐份提取下列字段，每个字段后面括号写出处（第几节）：期限（开始/月数/到期日，到期日 = 开始 + 月数 − 1 天）、
   是否自动续约 + 不续约通知期 + 最晚通知日期、单价和调价方式、送货和运费、付款账期、质量与变质责任、
   责任上限、解约（违约 / 无理由）、适用法律。
2. 合同里找不到的字段写「合同未写」，不要用常识补，也不要猜对方的意思。
3. 按这个用量粗估每份合同一年的总成本：每周 1,250 升、每周 18 次送货、52 周；
   运费按合同的规则算（有免运费门槛的，先算每次送货的金额再判断）。
4. 单独列「需要注意」：自动续约、责任上限明显偏低或排除了常见责任、缺少条款、供应商可以单方改价。
   每条用一句大白话说清楚对我们有什么影响。
输出：① 中文对比表（每份合同一列）；② 需要注意的清单；③ 一份带去问律师的问题清单。
最后一行写：本表只做信息整理，不是法律意见，签之前请律师审核。
```

**第二步：发一句：**「把三份合同做成对比表，按我们的用量算一年多少钱。」

**第三步：核对。** 每个字段都点开原文对一下出处。重点看三处：B 的续约通知截止日期是不是 2027-09-01；C 的运费是不是按 25 元一次算进去了；A 的解约是不是写了「合同未写」而不是编了一个 30 天。

**第四步：交给人。** 对比表和问题清单发给 Jason，由他转律师审。表里任何「建议签哪家」都只是成本角度的参考，不替他做决定。

> 用 ChatGPT 也可以：建一个 Project，上传三份合同，把同样的说明贴进去即可。

## 4. 应该做出的结果

`expected/answer.json` 是标准答案（日期和成本由脚本按规则算出），`expected/comparison.csv` 是对比表。

| 项目 | 合同 A Riverbend | 合同 B Sunfield | 合同 C Coastline |
|---|---|---|---|
| 期限 | 2026-12-01 至 2028-11-30（24 个月） | 2026-12-01 至 2027-11-30（12 个月） | 2026-12-01 至 2028-05-31（18 个月） |
| 自动续约 | 否 | **是，每次 12 个月；最晚 2027-09-01 书面通知** | 否 |
| 单价 / 升 | 1.68，首年固定，之后按 CPI | 1.59，**提前 30 天通知可改价，无上限** | 1.52，全期固定 |
| 运费 | 含在价格里 | 每次 12 元 | 满 150 元免运费，否则 25 元 |
| 付款 | 次月底后 14 天 | 开票后 7 天 | 开票后 30 天 |
| 责任上限 | 过去 12 个月货款（人身伤害等除外） | 过去 12 个月货款 | **500 元与当月货款取低；签收后变质不管** |
| 解约 | **合同未写** | 违约 14 天未改；首期满后 60 天通知 | 违约 30 天未改；随时 90 天通知 |
| 适用法律 | 昆士兰 | 昆士兰 | 昆士兰 |
| 年度粗估（AUD） | **109,200.00** | 114,582.00 | 122,200.00 |

- B 的年度粗估 = 牛奶 103,350.00 + 运费 11,232.00。
- C 每次送货约 105.56 元，不到 150 元免运费线，运费 23,400.00，加上牛奶 98,800.00 = 122,200.00。单价最低，总价反而最高。
- 按粗估成本 A 最低，但 A 没有解约条款，这是要问律师的第一件事。

## 5. 验收清单

- [ ] 三份合同的到期日、B 的不续约通知截止日（2027-09-01）跟上表一致。
- [ ] 自动续约（B）、责任上限偏低（C）、缺少解约条款（A）三处都在「需要注意」里，并且写了对店里的影响。
- [ ] A 的解约写的是「合同未写」，没有用常识补一个通知期。
- [ ] 年度粗估三个数字跟标准答案一致，C 的运费按 25 元一次算了进去。
- [ ] 结尾明确写了「不是法律意见，签之前请律师审核」，没有出现「这条合法 / 不合法」「建议直接签 A」这种结论。

## 6. 加分挑战

- 换一个用量假设（比如旺季每周 1,600 升）重算，看 C 能不能过免运费线、排名会不会变。
- 让 Claude 给 A 供应商起草一封英文邮件，请对方补充解约条款，只提问题，不替律师写条款内容。
- 把字段清单做成一张固定模板，以后任何供应合同都按这张表提取，再拿一份别的合同（比如咖啡豆）试一次。

## 7. 简历 / 面试可以这样讲

> 为一家三店咖啡连锁整理牛奶供应合同：用 Claude Project 按固定字段从三份英文合同中提取期限、续约、价格、付款、责任上限和解约条款，每个字段标注出处；自动标出自动续约截止日期、异常偏低的责任上限和缺失的解约条款，并按门店用量粗算全年成本，发现单价最低的合同因运费门槛反而最贵；结果作为律师审核前的问题清单，不替代法律意见（教学项目，合同和供应商都是为练习设计的）。
