# P25 · 教育培训：课堂签到表生成出勤周报

| 行业 | 难度 | 时长 | 工具 |
|---|---|---|---|
| 教育培训 | L1 自动化 | 45 分钟 | Claude（Projects）+ Excel / Google Sheets |

## 1. 客户场景

致远学堂是悉尼 Eastwood 的一家课后补习中心，三年级到八年级，一周六个班、八节课。每节课老师在共享表格里点名，标「到 / 迟到 / 缺勤 / 请假」。教务主任周老师每周一早上要出一份出勤周报给校长：各班出勤率多少、哪些孩子连着缺课要打电话给家长、哪些孩子老迟到。现在她是把一周的签到表拷出来，在 Excel 里一个班一个班数，经常数到一半发现有老师把一行录了两遍、有个试听的孩子被算进了班里，或者某个孩子那节课压根没记。

她想要的是：**周一早上把上周的签到表丢进去，十分钟拿到一份对得上的周报，要打电话的孩子和要老师补记的记录分开列好。**

## 2. 练习数据

三份文件，都是为这个练习设计的（学堂、老师、学生都不是真实的）。学生只用「名 + 姓氏首字母」，周报只在学堂内部用，不发给其他家长。

`data/attendance-week-2026-11-02.csv`：11 月 2 日到 8 日这一周的签到记录，共 71 行。

| 字段 | 含义 |
|---|---|
| date / time | 上课日期和时间 |
| class_id / class_name / teacher | 班级编号、班名、老师 |
| student_id / student | 学生编号、名字 |
| status | present 到 / late 迟到 / absent 缺勤 / excused 请假 |
| minutes_late | 迟到几分钟 |
| note | 老师备注 |

`data/roster.csv`：六个班的名单，共 51 个学生（class_id, student_id, student）。

`data/classes.csv`：每个班本周上了哪几节课。

数据里**故意藏了 6 处问题**，真实签到表也常见：

1. 两条记录被老师整行复制，录了两遍；
2. 一个不在班级名单上的孩子（备注「试听」）被记成了出勤；
3. 一条记录状态是空的；
4. 一条记录日期写成了下周一；
5. 名单上有个孩子，那节课一条记录都没有（漏记）；
6. 一条记录状态是缺勤，备注却写着家长已经请假。

学堂的规则（这家学堂自己定的，不是行业标准）：迟到算到课；请假不进出勤率的分母；同一班一周无故缺勤 2 次或以上要当天联系家长，迟到 2 次或以上要跟家长确认接送时间。

## 3. 做法

**第一步：在 Claude 里建一个 Project。** 名字叫「致远学堂出勤周报」，把 `roster.csv` 和 `classes.csv` 放进项目文件（名单不常变，换学期再更新），说明里写：

```
你是致远学堂的出勤周报助手。我每周一会上传上周的签到表 CSV。项目文件里有班级名单 roster 和课表 classes。
按下面顺序处理，先挡问题，再算数：
1. date 不在本周（周一到周日）范围内 → 不计入，列进「需要核对」。
2. 同一天、同一个班、同一个学生出现多次 → 只算一次，多出来的列进「需要核对」。
3. 学生不在这个班的 roster 里 → 不计入出勤率，列进「需要核对」，备注原样带上。
4. status 为空 → 不计入，列进「需要核对」。
5. status 是 absent 但备注里有「请假」→ 先按缺勤算，同时列进「需要核对」，请老师确认。不要自己改成请假。
6. 对照 classes 和 roster：名单上的学生某节课没有任何记录 → 列进「需要核对」（漏记）。
7. 出勤率 = (present + late) ÷ (present + late + absent)，excused 不进分母，保留一位小数。
输出：
① 分班表：班级、老师、课次、名单人数、有效记录、到、迟到、缺勤、请假、出勤率；最后一行合计。
② 需要联系家长：同一班本周无故缺勤 ≥ 2 次，或迟到 ≥ 2 次的学生，写清是哪一条。
③ 需要老师核对：日期、班级、学生、问题、原因。
④ 给校长的三句话总结，只说数据里看得出来的事。
学生名字照表上写，不补全姓氏；不对孩子的情况做任何猜测或评价。
```

**第二步：上传签到表，发一句：**「出 11 月 2 日这一周的出勤周报。」

**第三步：核对。** 用第 5 节的清单逐条对。至少手工数一个有两节课的班（比如四年级数学）：在 Excel 里筛这个班、去掉重复行，数缺勤和请假，看跟周报是否一致。

**第四步：变成每周的流程。** 规则存在 Project 里，周老师每周一只要上传一份新的签到表。「需要老师核对」那张表可以直接复制发到老师群里，让老师当天补完。

> 用 ChatGPT 也可以：建一个 ChatGPT Project（或自定义 GPT），把名单和课表放进文件，同样的规则写进说明，上传签到表即可。

## 5. 验收清单

- [ ] 合计有效记录是 66 条，不是 71 条；合计出勤率 90.5%。
- [ ] 两条重复、试听孩子、空状态、日期写错这 5 行都没算进任何班的数字，并且出现在「需要老师核对」里。
- [ ] Ryan M. 的漏记被找出来了（这一条签到表里看不到，必须对照名单才找得到）。
- [ ] Lily Q. 仍按缺勤算，没有被 Claude 自己改成请假，但列进了核对表。
- [ ] 需要联系家长的正好是 Olivia G.、俊杰 Z.、思远 S. 三个人。
- [ ] 周报里没有出现姓氏全名，也没有对任何孩子写「学习态度不好」这类评价。

## 6. 加分挑战

- 加一列「名单人数 × 课次 = 应到人次」，跟有效记录对比，一眼看出哪个班记录不全。
- 把上上周的签到表也做一份，标出出勤率下降超过 10 个百分点的班。
- 让 Claude 按「需要老师核对」给每位老师写一条一两句的提醒，只写这位老师自己班的记录。

## 7. 简历 / 面试可以这样讲

> 为一家课后补习中心设计每周出勤周报流程：用 Claude Project 固化名单和统计规则，自动排除重复录入、试听学生、空状态和日期错误的记录，对照班级名单找出老师漏记的学生，按班输出出勤率，并列出需要当天联系家长的学生；学生信息只保留名和姓氏首字母，周报只在内部使用（教学项目，学堂和数据都是为练习设计的）。
