# P15 · 零售电商：商品描述批量改写成中英双语

| 行业 | 难度 | 时长 | 工具 |
|---|---|---|---|
| 零售电商（Shopify 小店） | L1 自动化 | 60 分钟 | Claude（Projects）+ Shopify 商品 CSV 导出 / 导入 |

## 1. 客户场景

南风优选是悉尼 Eastwood 的一家 Shopify 网店，卖蜂蜜、羊毛被、羊奶皂、坚果这些澳洲特产，客人一半是华人、一半是本地人。商品描述是老板何姐几年前一条条手写的，只有中文，还夹着从供应商宣传单上抄来的「增强免疫力」「治疗感冒」。最近有本地客人留言说看不懂，平台也提醒过她治疗类宣传不能乱写。她想统一改一遍，可 50 多个商品，一条条改要好几个晚上，改着改着标题格式又不统一了。

她想要的是：**把 Shopify 导出的商品 CSV 丢进去，按她的规则改成中英双语的标题和描述，禁用说法自动去掉，缺规格的、Handle 撞了的单独列出来，改好的那批能直接导回 Shopify。**

## 2. 练习数据

都是练习数据：店名、商品、SKU、价格都是为这个练习设计的。

| 文件 | 内容 |
|---|---|
| `data/products_export.csv` | Shopify 商品导出（删减到 13 列），16 行、13 个商品 |
| `data/copy-rules.md` | 何姐定的文案规则：标题格式和长度、描述三段结构、禁用说法、保健品怎么写、Handle 和重量的要求 |

CSV 字段（跟 Shopify 导出的列名一致）：

| 字段 | 含义 |
|---|---|
| Handle | 商品的唯一标识，也是网址的一部分；同一个 Handle 的多行是同一个商品的不同规格 |
| Title / Body (HTML) | 标题 / 描述（HTML）；规格行这两列是空的 |
| Vendor / Type / Tags | 品牌 / 类型 / 标签 |
| Option1 Name / Option1 Value | 规格名 / 规格值（比如 Size / Queen 210x210cm）；只有一个规格的写 Title / Default Title |
| Variant SKU / Variant Grams / Variant Price | SKU / 重量（克，算运费用）/ 售价（澳元） |
| Published / Status | 是否上架 |

羊毛被有 2 个尺寸、拖鞋有 3 个尺码，所以 16 行里有 3 行是规格行，不是新商品。

数据里**故意藏了 4 类问题**：

1. **禁用说法**：5 个商品的原文写了「增强免疫力」「治胃病」「治疗感冒」「杀菌消炎」「降血脂、预防心脏病」「助眠」「缓解痛经、治疗关节炎」，改写时必须去掉，也不能换个说法偷偷留着。
2. **缺规格**：绵羊油面霜和巧克力饼干礼盒没写净含量，Variant Grams 也是空的。不能编一个「100g」上去。
3. **Handle 重复**：UMF 10+ 和 UMF 15+ 两种麦卢卡蜂蜜用了同一个 Handle `manuka-honey-250g`，直接导入会互相覆盖。
4. **标题过长**：羊毛被的标题堆了一串关键词，78 个字符，规则是不超过 60。

另外鱼油是保健品，去掉功效以后也要何姐对照实物标签再上架。

**教学假设：** 治疗类宣传的要求以 TGA（Therapeutic Goods Administration）和 ACCC 的官方说明为准，本项目只按店里的禁用词表处理，不判断某个商品在法律上能不能卖。Shopify CSV 导入时空列会不会覆盖原有内容、怎么覆盖，以 Shopify 官方帮助文档为准，正式导入前先备份、先拿一个商品试。

## 3. 做法

**第一步：在 Claude 里建一个 Project。** 名字叫「南风优选商品文案」，上传 `copy-rules.md`，项目说明写：

```
你是南风优选的商品文案助手。我会上传 Shopify 商品导出 CSV，请按 copy-rules.md 改写。
处理顺序：
1. 先认商品：Title 不为空的行是一个商品的开头，后面 Title 为空、Handle 相同的行是它的规格行。
   同一个 Handle 下有两个不同的 Title → 这是两个商品撞了 Handle，两个都标「Handle 重复」，给第二个建议一个新 Handle。
2. 每个商品改写：
   - Title：「中文名 | English name 规格」，不超过 60 个字符，去掉堆砌的关键词。
   - Body (HTML)：<p>中文 2–3 句</p><p>English，同样的意思</p><ul>规格清单，中英对照</ul>。
   - 只用原文里有的信息。原文没写净含量 / 容量 / 尺寸，规格写「待补 / TBC」，不要编。
   - 去掉所有治疗、预防、缓解疾病或症状的说法（见禁用说法），不要换成同义词保留，也不要写成「有助于」「据说」。
   - 保健品只写成分、规格和「用法用量请按瓶身标签」。
3. 输出两样：
   ① 一个 CSV：Handle, Title, Body (HTML), status, issues。status 只能是「可导入」「可导入（何姐核对标签后）」「先不导入，需要核对」。
   ② 一张「需要核对」清单：Handle + 问题类型 + 原文里的问题 + 建议怎么补。
   缺规格、缺重量、Handle 重复的，status 一律「先不导入，需要核对」。
4. 每个商品后面写一行改动说明：去掉了哪些说法、标题从多少字符改到多少字符。
```

**第二步：上传 `products_export.csv`，发一句话：**「按规则改写全部商品。」

**第三步：核对。** 拿第 4 节和验收清单逐条对。重点看三件事：禁用说法是不是一个都没剩、缺规格的有没有被编出数字、羊毛被和拖鞋的规格行有没有被当成新商品。再挑两三个商品，把中文和英文对着读一遍，意思一致、读起来像人写的。

**第四步：导回 Shopify。** 只拿 status 为「可导入」的那几行。Shopify 导入时选覆盖同 Handle 的商品；导入前先在后台导出一份完整备份，先导一个商品看前台显示正常，再导其余的。「需要核对」清单发给何姐，补好规格、换好 Handle 再跑一次。

> 用 ChatGPT 也可以：建一个自定义 GPT（或 Project），把同样的规则写进说明、上传 `copy-rules.md`，再上传 CSV 即可。

## 4. 应该做出的结果

`expected/answer.json` 是脚本按规则查出的问题和每个商品的状态，`expected/products_rewritten.csv` 是 13 个商品改写后的参考写法（中英文是按上面的提示词手写的参考答案，你的措辞可以不同，但规则必须一致）。

- 文件 16 行 = **13 个商品** + 3 行规格行（羊毛被 King、拖鞋 M 和 L）。
- 状态：**8 个可导入**、**1 个何姐核对标签后可导入**（鱼油）、**4 个先不导入**。

| 问题 | 商品 | 怎么处理 |
|---|---|---|
| 禁用说法 | 麦卢卡蜂蜜 UMF 10+（治胃病、增强免疫力）、羊毛被（助眠）、尤加利精油（治疗、消炎、杀菌、感冒）、鱼油（预防、降血脂、心脏病）、薰衣草热敷包（治疗、缓解痛经、关节炎） | 改写里全部去掉 |
| 标题过长 | 羊毛被：78 → 42 个字符 | 改成「澳洲美利奴羊毛被 500gsm \| Merino Wool Duvet 500gsm」 |
| 缺规格 + 缺重量 | 绵羊油面霜、巧克力夹心饼干礼盒 | 规格写「待补 / TBC」，先不导入 |
| Handle 重复 | `manuka-honey-250g`：UMF 10+ 和 UMF 15+ 两个商品 | 两个都先不导入；UMF 15+ 建议改成 `manuka-honey-umf15-250g` |
| 保健品 | 深海鱼油 1000mg 400 粒 | 只留规格和「用法用量请按瓶身标签」，何姐核对标签后导入 |

改写后 13 个标题都在 60 个字符以内，标题和描述里都扫不到禁用词表里的任何一个词。

## 5. 验收清单

- [ ] 识别出 13 个商品，不是 16 个；羊毛被的两个尺寸、拖鞋的三个尺码都写进了同一个商品的规格清单。
- [ ] 改写后的标题和描述里，禁用词表里的词一个都没有，也没有「有助于睡眠」「据说能提高抵抗力」这类换个说法的写法。
- [ ] 绵羊油面霜和巧克力饼干礼盒的规格是「待补」，没有编出重量或容量，状态是「先不导入」。
- [ ] 两个麦卢卡蜂蜜都被标了「Handle 重复」，没有进可导入的那一批。
- [ ] 每个标题不超过 60 个字符，格式是「中文名 | English name 规格」。
- [ ] 中英文意思一致，英文里没有中文原文没有的信息（比如编出来的产地或认证）。

## 6. 加分挑战

- 让 Claude 顺便给每个商品写 SEO 标题（Meta title）和描述（Meta description），各自限长，同样不能有禁用说法。
- 把禁用词表做成一张 Google Sheets，以后何姐自己加词；让 Claude 每次先读这张表再改写。
- 拿改写后的 CSV 再跑一遍「只检查不改写」：让另一个对话窗口按同样的规则逐条挑错，看第一遍有没有漏网的。

## 7. 简历 / 面试可以这样讲

> 为一家 Shopify 特产网店设计商品文案批量改写流程：用 Claude Project 固化标题格式、描述结构和禁用说法规则，把只有中文的商品描述改成中英双语，自动去掉治疗类宣传；正确区分商品行和规格行，缺规格、缺重量和 Handle 冲突的商品单独列出、不进导入批次，保健品保留人工核对标签这一步（教学项目，数据为为练习设计）。
