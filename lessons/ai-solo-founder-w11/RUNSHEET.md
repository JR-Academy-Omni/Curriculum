# 用户增长原理、真实案例与方法 · 讲师流程

90分钟，62页。四个企业案例各两页：真实启动/机制与OPC借鉴。方法页选讲，其他作为课后查阅。

| 时间 | 页码 | 讲法 |
|---|---|---|
| 0–7 | 1–3 | 增长因素与AARRR |
| 7–22 | 4–10 | 飞轮、推力摩擦、三种回流、留存模型和诊断 |
| 22–27 | 11–12 | Dropbox：免费价值与协作/推荐传播；OPC改奖励与兑现事件 |
| 27–32 | 13–14 | Canva：窄场景起步、首次成功与口碑；OPC观察一项真实任务 |
| 32–37 | 15–16 | Notion：创作者、模板与小社区；OPC从有用模板和愿分享用户开始 |
| 37–42 | 17–18 | Zapier：真实产品场景页与搜索需求；OPC把重复交付做成有内容的页面 |
| 42–45 | 19–20 | 方法地图与适用条件 |
| 45–67 | 21–56 | 按学员卡点选讲：接触、样例、模板、付费试点、推荐、自然周期留存 |
| 67–82 | 57–59 | 5分钟实验讲解、7分钟填写、3分钟互评 |
| 82–90 | 60–62 | 来源、下一步与答疑 |

每个案例：1分钟讲真实启动，2分钟逐箭头推导，2分钟问“OPC借哪一个动作，什么条件下会断”。没有精确因果/回流数据时，不讲未核实的增长倍数。Dropbox历史模式和当前规则分开；Fusion Books与Canva阶段分开；Notion只有部分用户创作；Zapier反馈→扩场景是教学分析，不复用2012排名保证。

N备注，箭头翻页，F全屏，P打印。第59/62页打开工作单；先选一个最接近自己项目的案例，说明前提差异，再填自己的四步循环与小实验。
