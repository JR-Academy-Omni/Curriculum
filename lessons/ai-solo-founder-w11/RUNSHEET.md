# 用户增长原理、飞轮与方法 · 讲师流程

90分钟，54页。2026-10-11。方法页作为可选教学材料与课后查阅，不要求全部同等展开。

| 时间 | 页码 | 讲法 |
|---|---|---|
| 0–7 | 1–3 | 增长因素与AARRR；指出一次转化和长期回流的不同问题 |
| 7–25 | 4–10 | 画飞轮；推力/摩擦/积累；三种循环；OPC手动首圈；价值和留存；调参数；诊断瓶颈 |
| 25–30 | 11–12 | 按卡点找方法，检查项目适用条件 |
| 30–55 | 13–32 | 重点讲精准接触、手工交付、问题内容、免费小工具、真实案例和推荐；其他快速查阅 |
| 55–70 | 33–48 | 重点讲模板/引导、付费试点、自然周期留存和高意向广告，接回飞轮与单位成本 |
| 70–85 | 49–51 | 5分钟选动作与实验；7分钟画自己的循环并填工作单；3分钟同伴质询 |
| 85–90 | 52–54 | 来源、明天第一步与答疑 |

第4页问“这轮结束留下什么，下轮怎样用？”；第7页是教学模拟，逐箭头要记录；第9页先调留存60%→80%，再调邀请到访20%→40%，解释90→110→140，所有数字均非预测。强调周期速度、容量与维护成本。第10页把卡点连到方法，避免把渠道清单当增长策略。

N讲师备注，箭头翻页，F全屏，P打印预览。第51/54页打开工作单。工作单增加四步飞轮和回流证据字段，沿用本机草稿，不删除旧填写。
