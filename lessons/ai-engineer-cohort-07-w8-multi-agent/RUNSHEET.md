## 被问到时

- **Managed Agents 和 Agent SDK 选哪个**：看谁来跑循环、谁来托管。自己托管、要深度控制和 hooks，用 SDK；要服务端版本化的 Agent、托管容器和多线程，用 Managed Agents。两者都是 Anthropic 的产品，不是跨厂商标准。
- **为什么 advisor 的建议看不到**：Opus 5.5 作 advisor 时，建议对客户端是 redacted，只有 Agent 在服务端能读。这是平台的设计，不是 demo 的问题。
- **A2A 呢**：本课讲一个系统内部的编排。独立 Agent 之间跨组织协作（A2A）在 W11 治理讲：身份、能力声明、授权、撤销。
- **为什么 demo 没开 dynamic workflows**：只有六位住户，roster 足够；关掉后成本和路径可预测。打开要同时写清楚什么时候用，并设预算。
- **LangGraph、OpenAI Agents SDK、CrewAI 能做吗**：能，同样的五种模式。大纲把它们列为扩展参考，本课不比较框架。
- **数字会变吗**：会。模型、prompt、平台更新都会改变结果，所以 eval 脚本要能重跑。
