主要入口

  • handover.py：运行 single/team 交班演示
  • setup_agents.py：创建 Agent 环境与 roster
  • carekind.py：权限、工具、审计和幂等逻辑
  • prompts.py：Agent prompts 与委派契约
  • eval_compare.py：single-agent 与 multi-agent 对比
  • tests/test_handover.py：14 项离线测试

离线测试不需要 API；运行 Managed Agents 演示需要自行配置有对应权限的 Anthropic API Key。请勿上传或分享真实密钥。
