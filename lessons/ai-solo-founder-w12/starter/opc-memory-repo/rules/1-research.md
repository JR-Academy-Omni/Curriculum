# 第 1 步 · 话题调查

## 先读
- `memory/brand.md`：我的用户是谁、他们最常问什么
- `memory/learnings.md`：以前什么题目有人看
- `topics/` 里最近 7 天的文件：避免重复
- `memory/sources.md`：只看最近 48 小时的内容

## 要做的
1. 找 3–5 个候选题目。每个写一句「和我的用户有什么关系」，写不出来就丢掉。
2. 每个按 4 项打 1–5 分，算总分：
   - 相关（和用户最常问的问题有多近）× 0.4
   - 时效（是不是新变化）× 0.2
   - 可写（我有没有自己的经验可以加进去）× 0.3
   - 咨询（读完会不会想找我）× 0.1
   - 如果 learnings.md 说明某类题目效果好或差，在分数旁边写出来
3. 排序，写到 `topics/<日期>.md`。

## 输出格式
```
# 话题调查 · <日期>
## 1. <题目>（总分 x.x）
- 和我的用户的关系：
- 分数：相关 x / 时效 x / 可写 x / 咨询 x
- 来源：<URL>
```

## 状态
- done：至少 1 个题目，第 1 名总分 ≥ 3.0
- skipped：都低于 3.0，或和最近 7 天重复。仍然写 topics 文件，方便你看它为什么不写
- needs-human：一半以上信息源打不开
