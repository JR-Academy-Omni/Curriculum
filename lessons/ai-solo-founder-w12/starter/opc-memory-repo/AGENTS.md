# AGENTS.md — 这个仓库是我的生意记忆

1. **每次开工先读 `memory/`**：`brand.md`（我是谁、卖给谁、语气、不能说的话）、`learnings.md`（以前什么有人看），按需读 `sources.md`、`past-posts/`。
2. 然后读这一步的规则 `rules/<步骤>.md`，严格按它做，只写它指定的文件。
3. 不改 `memory/`、`rules/`、`.github/`。想改记忆，只能在回答里提建议。
4. 回答第一行必须是状态，三选一：
   - `状态：done — 一句话说明`
   - `状态：skipped — 为什么按规则不该做`
   - `状态：needs-human — 卡在哪里，要人判断什么`
5. **宁可交回一句「我没做，因为 X」，也不要交回一个猜着做完的结果。** 记忆里没写的就是不知道；网上查到的事实附来源 URL。
6. 不对外发布、不发邮件、不付款。对外的东西只写草稿，等人在 PR 里点 Merge。
