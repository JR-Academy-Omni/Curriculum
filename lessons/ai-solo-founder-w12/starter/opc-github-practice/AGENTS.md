# AGENTS.md — Codex 在这个仓库里的规则

1. 先读 `business.md`，再读这次任务的 `tasks/<任务>.md`，严格按任务卡做。
2. 只写任务卡指定的文件。不改 `business.md`、`tasks/`、`.github/`、`scripts/`、`practice-data/`。
3. 回答的第一行必须是状态，三选一：
   - `状态：done — 一句话说明做了什么`
   - `状态：skipped — 为什么按规则不该做`
   - `状态：needs-human — 卡在哪里，需要人判断什么`
4. **宁可交回一句「我没做，因为 X」，也不要交回一个猜着做完的结果。** 不编造数据、引用、价格和客户信息。`business.md` 和 `docs/` 里没写的，就是不知道。网上查到的事实附来源 URL。
5. 不对外发布、不发邮件、不付款。对外的东西只写草稿。
