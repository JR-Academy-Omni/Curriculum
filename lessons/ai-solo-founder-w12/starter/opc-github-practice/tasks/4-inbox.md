# 任务 4 · Issue 收件箱：客户来信分诊

## 要做的
`.issue.md` 里是一封客户来信。只根据 `business.md` 和 `docs/` 里写了的信息回答：

1. 分类：使用问题 / 退款或投诉 / 购买咨询
2. 使用问题、购买咨询：起草一封回复，每个说法后面标依据（例如「依据：docs/faq.md」）
3. 退款或投诉：不起草，写「转人工」和一句原因
4. 购买咨询：再写一行「下一步跟进」

不写任何文件，回答本身会被贴到 Issue 下面。

## 状态怎么判
- done：分类明确，草稿里每个说法都有依据
- needs-human：回答需要的信息 business.md 和 docs/ 里没有，写清楚缺什么
