# 任务 3 · 每日行业简报

## 信息源（练习前改成你行业每天会更新的 3–5 个网址）
- https://news.ycombinator.com/
- https://www.ato.gov.au/media-centre

## 要做的
读上面的信息源，只看最近 48 小时的内容，写今天最重要的 3 件事。每件 2–3 句：发生了什么、**对 business.md 里的用户意味着什么**，附来源 URL。最后写一个今天就能做的小动作。

写到 `briefs/<今天日期>.md`（日期见提示）。

## 状态怎么判
- done：3 件事都有来源，都写了对用户意味着什么
- skipped：信息源都没有新内容，不写文件
- needs-human：一半以上信息源打不开，不写文件，列出打不开的网址
