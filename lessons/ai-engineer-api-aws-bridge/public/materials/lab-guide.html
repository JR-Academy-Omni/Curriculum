在自己的电脑完成一次真实请求

打开护理记录、提交一条新记录，再从 Network 观察请求与响应；刷新后重新读取保存结果。

下载 API 实操包

  1. 解压下载的文件，确认电脑已安装 Python 3。
  2. macOS 可在解压目录打开终端运行 python3 lab/server.py；Windows 运行 py lab/server.py。
  3. 保持终端运行，打开下面的实操入口。

打开 API 实操 →

服务运行在你的电脑上，练习记录保存在实操包的数据库中。完成后在终端按 Ctrl+C 结束。

按这条链路检查

打开完整记录 → 编辑并保存 → 查看 POST 请求与状态码 → 刷新并重新读取 → 对照请求 ID 查看日志。随后切换 400、401、403、404，观察不同问题留下的证据。
