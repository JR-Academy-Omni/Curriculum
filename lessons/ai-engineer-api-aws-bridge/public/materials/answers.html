Reference answer · Technology stack

HTML provides structure, CSS styling, and JavaScript behavior. React organizes UI as components and state. Browser JavaScript executes in the client environment. Node.js is a JavaScript runtime outside the browser and may run backend services or frontend development tools. Express or NestJS organize a Node application. Nginx may serve static files and proxy requests to a separate Node process. AWS provides hosting and related cloud resources. React server rendering and full-stack frameworks require checking the actual execution location.

Reference answers · API

A valid POST contains exactly residentId, activity and note. The response is 201 with the created record. A subsequent GET for that ID returns the same content. A reload should still retrieve the saved record.

Reference answers · AWS

The browser resolves the API domain and connects over HTTPS to the ingress. ALB forwards to a healthy ECS task. The backend validates the business request and reads or writes RDS. File objects belong in S3 when required. IAM, Secrets Manager and CloudWatch support this topology; they are not sequential hops in every request.

Private tasks need an appropriate outbound path to public AI providers. Security groups govern allowed traffic; IAM governs cloud actions; business authorization governs application actions. Passing one of these checks does not imply passing the others.

Reference answer · AI job workflow

Keep the short save path synchronous. Submit long work through an authorized API that returns a job ID. A Worker consumes the queued job, coordinates duplicate processing, stores the result and updates authoritative status. The browser reads status and opens the result with an access check. Set bounded retries and backoff; use a stable logical operation identity. Cache only data with correct scope, permissions and freshness. Monitor queue age, completion rate, errors and latency. More workers remain constrained by downstream capacity.

Reference answer · IaC

IaC configurations describe infrastructure resources and relationships. Terraform and CloudFormation manage supported resources through platform APIs. Review the target environment and planned creation, modification, replacement or deletion before execution. Application code, image packaging and pipeline orchestration have separate responsibilities. Resource configuration history does not replace business-data backups or restore validation.

Reference answer · Delivery design

Verify the code, build a traceable artifact, store it in a registry or artifact location, validate it in the intended environment and promote the same version under the release policy. Keep environment addresses, identities, secrets and data separate. IaC has its own reviewed resource-change path. Verify runtime version, health, business behavior and monitoring after deployment. Retain a known usable artifact and a compatible migration/recovery strategy before release.

Reference answer · Firewall

Verify the full network path and actual listener before attributing a failure to a rule. Security Groups are stateful and allow-only; NACLs are stateless subnet filters with ordered allow/deny rules. WAF inspects supported web requests. IAM and application authorization govern separate access decisions. A permitted TCP connection does not grant business-data access.
