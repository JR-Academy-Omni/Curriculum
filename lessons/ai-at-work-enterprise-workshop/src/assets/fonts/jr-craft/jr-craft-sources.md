# Study Center typography

Local font files for the JR Soft Craft v6 product surface. Source: Google Fonts CSS API, fetched 2026-09-07. Local delivery avoids build-time font-network dependencies.

- `jr-craft-heading-700.ttf`: Bricolage Grotesque, normal 700. License: `jr-craft-heading-OFL.txt`.
- `jr-craft-body-400.ttf`: DM Sans, normal 400. License: `jr-craft-body-OFL.txt`.
- `jr-craft-body-700.ttf`: DM Sans, normal 700. License: `jr-craft-body-OFL.txt`.

Upstream license sources: `https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque` and `https://github.com/google/fonts/tree/main/ofl/dmsans`.
