Structured Data：概念、类型与Google Shopping

1 · 四个概念

Structured Data · 机器可读的事实

把网页中的商品、价格、作者或活动信息写成明确字段。

Schema.org · 类型与字段词汇表

规定 Product、Offer、Article 等类型，以及 name、price 等属性。

JSON-LD · 网页中的标记写法

用 <script type="application/ld+json"> 放入 JSON，表达 Schema.org 的事实。

JSON Schema · JSON 数据校验规则

检查必填字段与数据类型；不是 Google 商品标记，也不代替 Rich Results Test。

2 · Google常用类型（精选，不是完整清单）

Schema.org类型不都对应Google专门展示功能。按页面用途与官方资格选择；实际展示由Google决定。

Schema.org类型页面常见字段Google用途
Product + Offer商品页商品名、图片、价格、币种、库存产品摘要／商家商品展示
Article / BlogPosting文章页标题、作者、发布日期、图片文章信息及搜索中的相关展示
BreadcrumbList层级导航栏目名称、地址、顺序页面层级路径信息
LocalBusiness实体商家页名称、地址、营业时间本地商家信息
Organization机构介绍页名称、Logo、联系方式机构身份信息
Recipe食谱页原料、做法、用时食谱富结果
Event活动详情页名称、时间、地点、票务活动搜索体验
JobPosting职位详情页岗位、雇主、地点、薪酬职位搜索体验
VideoObject视频观看页标题、缩略图、日期、视频地址视频相关搜索展示
ProfilePage + Person作者／个人档案页人物身份、关联关系、资料帮助理解人物与网站的关系

3 · 一个Product + Offer示例

商品、A$299价格、库存和example.com地址均为教学虚构；不是Google实际搜索结果。

Demo Coffee Maker A

A$299.00 · AUD · In stock（教学库存）

Product描述商品；Offer描述这件商品的报价条件。网页可见商品信息与下面的JSON-LD一致。未生成评价或星级。

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "Demo Coffee Maker A",
  "image": "https://example.com/coffee-a.webp",
  "offers": {
    "@type": "Offer",
    "url": "https://example.com/products/coffee-a",
    "priceCurrency": "AUD",
    "price": "299.00",
    "availability": "https://schema.org/InStock"
  }
}
</script>

这是核心字段教学示例，不是可直接上线的真实商家资料。实施时替换为真实可访问的商品页和可抓取图片，并按适用要求补充商品标识、运费、退货、变体等信息。不要把示例库存或价格放进真实商品标记。

4 · Google中怎样使用

  1. 商品页显示真实名称、图片、价格、币种与库存，在HTML加入相匹配的Product / Offer JSON-LD。
  2. Google可用商品信息支持Product snippets或Merchant listings；符合条件不等于保证出现。
  3. Google Merchant Center是另一路商品数据入口：可提供商品feed、配置免费展示等。Shopping标签页有自己的Merchant Center数据与资格要求；广告还需要单独的广告设置与预算。
  4. 用Rich Results Test检查Google支持的类型与错误；上线后用URL Inspection及相关Search Console报告复查。此教学任务未提交Google测试、未注册Merchant Center、未投放广告。

5 · JSON Schema校验，为什么是另一回事

下面的JSON Schema检查教学数据是否有name和offers，以及报价字段是否符合类型和格式。它不是Schema.org的商品类型，也不是要放进网页等待Google识别的Product标记。

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "required": [
    "name",
    "offers"
  ],
  "properties": {
    "name": {
      "type": "string",
      "minLength": 1
    },
    "offers": {
      "type": "object",
      "required": [
        "priceCurrency",
        "price"
      ],
      "properties": {
        "priceCurrency": {
          "type": "string",
          "pattern": "^[A-Z]{3}$"
        },
        "price": {
          "type": "string",
          "pattern": "^[0-9]+(\\.[0-9]{2})?$"
        }
      }
    }
  }
}

通过JSON Schema只说明数据符合这里定义的规则；不证明满足Google全部字段、真实性或展示资格。
