Version 4 · 2026-10-17 · language=en

Use the main textbook in this package as the teaching text. This workbook provides the six assignments, expected output structures, worked checking notes, and final acceptance criteria. All Maple Slot people, observations, product descriptions, and measurement values are fictional teaching material. No live product, customer, account, or search performance is claimed.

Task 2 — Convert demand into a first content decision

Create ten candidate demand records. Record the origin and date of actual observations; keep hypotheses separate. Group expressions by user task, select the first task, and state what evidence would make you change that decision.

Use practice/demand-map.csv as a worked fictional example. Its search volume and difficulty fields are blank because no keyword tool was queried. Do not replace missing data with zero.

For a real results-page review, record the query, language, region, device, timestamp, result type, representative URL, task served, and an identifiable contribution you could make. Do not invent results or scrape search engines through unapproved automation.

Worked Maple Slot decision: Q02–Q05 belong to the same checking task and can be served by P2. Q08–Q10 are deferred because current capabilities or evidence do not support the likely promise. No search-volume conclusion is available.

Acceptance: Each priority has a reason tied to the project and evidence. Different wording does not automatically create another page.

Task 6 — Diagnose comparable data

Use practice/measurement-scenario.csv. It contains two equal fourteen-day synthetic windows. It assumes consistent event definitions and cohort selection within the exercise. It is not an export from Search Console or Analytics.

Calculate search CTR, checklist-completion share within the P2 session cohort, and P1-entry share within the same cohort. Do not add overlapping behaviors as separate people. Do not equate clicks with sessions. Explain why missing leads cannot be entered as zero.

Worked diagnostic memo: Within this synthetic scenario, checklist completion and P1 entry shares increase while search CTR stays constant. The data do not establish a causal effect or commercial demand. Review event consistency and visitor composition, then obtain authorized evidence about whether the method helps. Lead and payment outcomes remain unmeasured or not applicable because the required business paths do not exist.

Submit three prioritized actions. Each must include the trigger evidence, user affected, change scope, owner, permission dependency, and acceptance criterion.
