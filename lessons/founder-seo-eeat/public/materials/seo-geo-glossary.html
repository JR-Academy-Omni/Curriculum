SEO / GEO · English terminology

保留英文术语、全称与简短中文解释。用浏览器查找功能搜索术语。

HTML link examples

以下是语法教学例子，example.com为示例域名，不代表真实合作或用户内容。href是目标地址，anchor text是可点击文字，rel说明链接关系。普通编辑性引用无需为了SEO添加特殊rel属性。

sponsored · Paid placement / Sponsored link

<a href="https://example.com/offer"
   rel="sponsored">Partner offer</a>

ugc · UGC = User-Generated Content

<a href="https://example.com/post"
   rel="ugc">Community post</a>

nofollow · Unendorsed link

<a href="https://example.com/reference"
   rel="nofollow">External reference</a>

sponsored用于付费展示；ugc用于用户提交链接；nofollow用于其他不予认可的链接关系。Google将这些属性作为提示，不是绝对禁止抓取或索引。noindex是另一种页面索引指令。商业披露不能只用HTML属性代替。

Terminology index

SEOSearch Engine Optimization搜索引擎优化

改善内容、结构与技术条件，让相关用户更容易通过自然搜索找到网页。

GEOGenerative Engine Optimization生成式搜索优化

行业常用说法，关注内容在生成式回答中的可见性、引用与准确呈现；不保证被引用。

Search intentSearch intent搜索意图

用户搜索时想完成的任务，例如了解、比较或操作。

Organic searchOrganic search自然搜索

由搜索系统选择展示的非广告搜索结果。

Paid searchPaid search付费搜索

通过广告投放获得搜索展示；与自然结果分开衡量。

SERPSearch Engine Results Page搜索结果页

用户提交查询后看到的结果页；点击某条结果后才进入对应网页。

Landing PageLanding Page落地页

访客在一次访问中首先进入的网站页面；文章、产品页或专门营销页都可能是落地页。

On-page SEOOn-page SEO页面内优化

优化网页的标题、正文、语义结构、图片和链接；不等于One-page或Landing Page。

TitleHTML title element网页标签标题

<title>通常用于浏览器标签，也是Google生成搜索标题时可能参考的来源。

Meta descriptionMeta description页面描述元信息

通过<meta name="description">概括网页；不会自动显示在正文，也不保证被搜索摘要采用。

SnippetSearch result snippet搜索结果摘要

搜索结果中的说明文字；可能来自正文，也可能采用meta description。

H1 / H2 / H3Heading levels 1 / 2 / 3标题层级

HTML语义标题：H1通常表达页面主标题，H2/H3组织章节与小节；字号不等于层级。

altAlternative text图片替代文本

描述图像在当前语境中的信息；有意义的alt帮助无法查看图像的用户理解内容。

CaptionImage caption可见图注

显示在图片附近的文字说明，与alt不是同一个字段。

BreadcrumbsBreadcrumb navigation面包屑导航

表示当前页面在网站层级中的位置，通常可点击返回上级；不是浏览历史。

Anchor textAnchor text链接文字

<a>标签中用户看得到的可点击文字，应说明目标内容。

Internal linkInternal link站内链接

连接同一网站的其他页面，帮助导航、发现内容和理解页面关系。

Outbound linkOutbound link出站链接

从当前网站指向其他网站的链接；引用应支持具体说法。

hrefhref attribute链接目标地址

<a href="...">中的地址，决定用户点击后去哪里。

relLink relationship attribute链接关系属性

<a rel="...">说明当前文档与链接目标的关系；一个链接可以有多个rel值。

sponsoredSponsored link付费／商业合作链接

用于广告、付费推荐或其他付费展示链接；还应向读者披露商业合作关系。

UGC / ugcUser-Generated Content用户生成内容

评论、论坛帖子等用户提交内容中的链接，通常使用rel="ugc"。

nofollownofollow link value不予认可的链接提示

当其他属性不适用且不希望Google将本站与目标关联时使用；不是禁止索引的指令。

noindexnoindex robots rule禁止索引指令

用于表达页面不应被纳入搜索索引；搜索引擎需要能读取该指令。

URLUniform Resource Locator资源地址

包含scheme、host、path，并可带query parameters与fragment。

HTTPHypertext Transfer Protocol超文本传输协议

浏览器与服务器通过request和response交换资源；HTTPS在此基础上提供加密传输。

HTTP status codeHTTP response status codeHTTP响应状态码

例如200成功、301永久重定向、404未找到；状态码不等于搜索排名。

RedirectHTTP redirect重定向

把请求转到另一URL；永久和临时重定向用途不同。

HTMLHypertext Markup Language网页结构标记语言

用标签表达标题、段落、链接和图片等文档结构。

JavaScript / JSJavaScript网页脚本语言

可加载数据、更新页面和提供交互；正文也可能由脚本生成。

DOMDocument Object Model浏览器文档对象模型

浏览器解析HTML并执行脚本后的文档结构；可在DevTools的Elements查看。

DevToolsBrowser Developer Tools浏览器开发者工具

Network检查请求与响应；Elements检查当前DOM与样式；Console检查日志和脚本错误。

CrawlingCrawling抓取

搜索机器人发现并请求网页及资源的过程。

IndexingIndexing索引

搜索引擎处理页面并将其纳入可供检索的索引；能够抓取不等于已被索引。

robots.txtRobots Exclusion Protocol file抓取规则文件

表达哪些路径允许或限制机器人抓取；不提供身份认证，也不等于noindex。

SitemapXML sitemap站点地图

提供希望搜索引擎发现的URL列表及相关信息，不保证抓取或索引。

Canonical URLCanonical URL规范／首选URL

相同或高度相似页面的代表版本；网站声明与Google实际选择可能不同。

URL InspectionSearch Console URL Inspection网址检查

Search Console中用于查看或测试某URL的抓取、索引等信息的工具。

Structured DataStructured data / Schema.org结构化数据

用机器可读格式表达网页已有事实；Schema.org提供常用词汇，不是认证机构。

JSON-LDJavaScript Object Notation for Linked Data关联数据表示格式

常用结构化数据写法；也可见Microdata、RDFa等格式。

Rich resultRich result富结果

Google搜索中具备额外展示信息的结果；符合标记要求不保证展示。

RenderingRendering渲染

浏览器把文档、样式和脚本转换为可见页面的过程。

CSRClient-Side Rendering客户端渲染

浏览器运行JavaScript后组装页面内容。

SSRServer-Side Rendering服务端渲染

用户请求时由服务器生成页面HTML。

SSGStatic Site Generation静态站点生成

访问发生前生成可直接提供的静态HTML。

Core Web VitalsCore Web Vitals核心网页体验指标

当前以LCP、INP和CLS衡量加载、交互与视觉稳定性。

LCPLargest Contentful Paint最大内容绘制

衡量视口内最大内容元素的绘制时间，反映加载表现；良好阈值不高于2.5秒。

INPInteraction to Next Paint交互到下一次绘制

衡量点击等交互到下一次画面更新的响应；良好阈值不高于200毫秒。

CLSCumulative Layout Shift累计布局偏移

衡量非预期布局位移的视觉不稳定程度；良好阈值不高于0.1。

DNSDomain Name System域名系统

把域名解析到网络地址等记录。

CDNContent Delivery Network内容分发网络

通过分布式节点向访问者提供内容，常与缓存策略配合。

Load balancerLoad balancer负载均衡器

把进入的请求分配给后端服务。

CacheCache缓存

保存可复用的数据或资源副本；更新时需要正确的失效与版本策略。

E-E-A-TExperience, Expertise, Authoritativeness, Trustworthiness经验、专业性、权威性、可信度

Google内容质量评估框架中的概念，不是一个独立排名分数。

ProfilePage / PersonSchema.org ProfilePage / Person个人档案页／人物类型

结构化数据类型；需与可见内容和真实身份一致，不构成Google作者认证。

PromptPrompt给AI的任务指令

说明输入、目标、限制和预期输出；输出仍需核对。

RetrievalInformation retrieval信息检索

从资料或索引中找到与问题相关的信息，不等于模型训练。

CitationCitation来源引用

回答或文章指向支持具体说法的来源；应检查引用是否真正支持该说法。

GSCGoogle Search ConsoleGoogle搜索管理工具

查看站点搜索表现、索引等信息；需要对应站点权限。

GA4Google Analytics 4站内分析工具

分析站内访问和事件；与Search Console的指标和统计口径不同。

CTRClick-Through Rate点击率

Clicks ÷ Impressions；比较时需要统一查询、页面、时间和设备等维度。

Impressions / ClicksImpressions / Clicks展示次数／点击次数

表示搜索展示与点击的计数；不等于独立用户人数。

SessionSession会话

一段按分析工具规则组织的访问活动，不等于一次购买或一个独立用户。

ConversionConversion / Key event转化／关键事件

按业务明确界定的目标动作，例如询价、预约或购买；需验证实际发生。

hreflanghreflang annotation语言／地区版本标注

表达同类页面的不同语言或地区版本；不等于canonical，也不是自动翻译。

llms.txtllms.txt面向模型的站点说明约定

一种行业提案；不是Google AI搜索要求的特殊准入文件。

AIArtificial Intelligence人工智能

本课中的生成式AI工具用于辅助整理、分析和生成建议；输出不自动成为事实。

LLMLarge Language Model大语言模型

处理和生成语言内容的模型；是否能检索网页取决于具体产品提供的工具。

FAQFrequently Asked Questions常见问题

常见问题及答案的内容组织方式，不等于自动符合Google富结果展示资格。

p7575th percentile第75百分位

排序后约75%的观测值不超过该位置的值；Core Web Vitals按此评估相关体验。

Lab dataLaboratory data实验室数据

在受控测试条件下得到的数据，适合定位和复现性能问题。

Field dataField data / Real-user data真实用户数据

来自实际访问条件下的用户体验数据；与一次实验室测试用途不同。
