# SEO / GEO · Learner worksheet

Language: en. Reference decisions are available in public/materials/course-workbook.html.

## Workshop 01 · Match the task
Group the supplied Lovable queries by user task. Propose one page per distinct task and identify what still needs live SERP evidence.

Reference decision: Use separate tasks for understanding the tool, comparing alternatives, and configuring a domain. Similar wording alone does not justify more pages. Search demand and current result patterns remain unverified until observed.

## Workshop 02 · Write a revision brief
Choose one paragraph from the supplied page. Specify the user task, evidence gap, proposed revision and verification step.

Reference decision: Keep the original URL. Separate a proposed rewrite from a verified fact. Add primary sources or actual observations for claims; do not invent product capabilities, measurements or user stories.

## Workshop 03 · Inspect the response
A page returns HTTP 200 but shows only Loading. State what is known, what to inspect next, and what remains unverified.

Reference decision: Known: the request returned 200. Inspect the response body, rendered main content, resource failures and indexing directives. Actual Google indexing and successful user tasks remain unverified.

## Workshop 04 · Verify delivery
Select one content block and one interaction. Record how to inspect initial HTML, rendered content, mobile usability and a relevant performance symptom.

Reference decision: Use Network for the initial response and Elements for the rendered block. Perform the actual interaction. Record the device and conditions. A framework name or a single lab score does not establish indexing or real-user performance.

## Workshop 05 · Connect claims to evidence
Choose three author or project claims. Classify each source, state the limit of the claim, and propose one concrete website revision.

Reference decision: Separate self-description, first-hand project evidence and independent records. Add only verified roles and outcomes. Link claims to relevant material; do not invent credentials, testimonials or expert review.

## Workshop 06 · Review AI suggestions
For each supplied suggestion, choose accept, revise or reject. Cite the original input and state the verification step.

Reference decision: Accept a structural proposal only when it serves the page task. Revise claims needing current primary sources. Reject invented rankings, unsupported capabilities and fabricated authorship. Preserve the original and the decision record.

## Workshop 07 · Design an observation
Design one informational query, one comparison query and one brand-fact query. Define the fields needed to verify each linked statement.

Reference decision: Record the exact prompt, platform, mode, date, region/language, answer and source URL. Check whether the source supports the statement. Leave results empty until a real observation is saved; do not invent citations.

## Workshop 08 · Choose the next actions
Select three actions for one real page. For each, record evidence, user benefit, owner, completion criteria, review date and remaining uncertainty.

Reference decision: Prioritise a blocking delivery problem before cosmetic changes. Require primary evidence for claims. Define a checkable result and preserve the baseline. Do not promise ranking, AI citation or business growth without actual evidence.

## Deliverables
Submit a page inspection record, a revision brief, a claim-evidence map, a personal-site plan, a GEO observation design and three prioritised actions. Mark unsupported outcomes as unverified.
