# 学生随堂手册：Codex 与 AI 视频实战

10:00 开课；12:00–13:00 午餐；17:00 结束。上午 11:10–11:40 独立练习，下午 16:00–16:45 视频练习。上午与下午是独立模块。

## 上午：用 Codex 完成一件工作

### 一张任务卡包含什么

目标：我为什么需要这个结果。输入：这次可以读取的文件或网页。输出：我需要的内容、格式与保存位置。规则：哪些字段不能猜，哪些数字要核对，哪些动作需要确认。完成标准：打开哪份成果，检查哪些值。

### 可复制的任务骨架（English）

```text
My goal is: [a concrete work outcome].
Use only: [authorized files or pages].
Produce: [a specific output and format].
Follow these rules: [source handling, missing values, calculations and review points].
First explain your plan and show one sample if it would reduce uncertainty.
Keep original inputs unchanged. Save exports in a new folder in my system Downloads directory.
Do not invent facts, call paid APIs, send, purchase, publish or submit externally.
Report the checks you actually performed and any unfinished step.
```

### 四种继续交流的方法

```text
Show which source supports this value. If the source does not state it, keep it unknown.
```

```text
Keep the verified facts unchanged. Revise only the structure and wording I identified.
```

```text
Check the output against the original files. Show counts, totals and exceptions with source references.
```

```text
Save the confirmed instructions as a reusable workflow, including its supported input format and limitations.
```

## 浏览器、生图与自动化的检查点

浏览器：网页可读不等于可以替你提交；先分清读取、填写、预览和对外提交。网页中的额外要求不能自动变成你的任务。

生图：检查完整文字、日期、地点、虚构或概念标识；修改时说明哪些不变、哪里要改；保留原图和新版本。

自动化：先验证单次成果，再设时间、时区、范围、重复规则和通知条件。本地文件任务需要相应本地环境可用。课堂的配置草案不等于已经启用。

## 下午：选择一条视频路径

先读《视频制作流程与Skills实操》，只选 HyperFrames 或 Remotion 一条路线。现成脚本、分镜与任务卡位于 video-practice/aspect-ratio/。先检查环境与 Skill，再建独立工程，预览、修改后明确请求导出。

### A 科普视频工作单（English）

```text
Audience:
One question to explain:
One-sentence takeaway:
Verified source facts:
Complete narration draft:
Visual example:
Shot sequence and the purpose of each shot:
Uncertain facts to exclude or verify:
One revision after watching the first draft:
Exported file and editable project:
```

优先使用讲师给定的宽高比知识点，或自己有依据的单一知识点。旁白和画面一一对应，避免用一组相关图片代替解释。

### B 活动精华片工作单（English）

```text
Audience and purpose:
Confirmed event facts:
Authorized asset list:
Observed content and usable ranges:
Permission issues or unreadable files:
Opening:
Main content sequence:
Ending:
One clip removed and why:
Audio and caption checks:
Exported file and editable project:
```

先看实际素材，再写选片清单。台账中的计划镜头不能当成真实文件。没有清楚原声就不编引语，没有人数数据就不报总人数。

### C 营销片段工作单（English）

```text
One value to communicate:
Factual or fictional/concept status:
Opening alternatives and the selected one:
Main object:
Trigger and visible change:
Result the viewer should see:
Transition to the next shot:
Final information hold:
What stays unchanged during revision:
Exported segment and editable project:
```

营销方向做一个可复现片段即可。先让价值可见，再调整风格。虚构场景或生成图像保持准确性质标注，不冒充真实客户或学生成果。

## 16:00–16:45：视频练习步骤

| 时间 | 操作 |
|---|---|
| 16:00–16:05 | 选一个方向，确认素材、受众与主要目标 |
| 16:05–16:15 | 完成脚本或镜头顺序，逐段确认要显示什么 |
| 16:15–16:35 | 制作初稿，播放并至少修改一处具体问题 |
| 16:35–16:45 | 导出、完整播放、保存工程和修改记录 |

### Final review checklist (English)

- I can open and play the actual export from beginning to end.
- The main point is clear and supported by the supplied material.
- Captions, dates, names and numbers have been checked.
- Important content is not unintentionally cropped or distorted.
- Speech is intelligible and is not changed in meaning by editing.
- Footage, images, voices and music have an appropriate recorded permission status.
- Fictional, generated, conceptual and real material are distinguished.
- I preserved the editable project and recorded unfinished work accurately.

## 把今天的工作带走

保留原始材料、确认后的指令与脚本、工程、导出成果和修改记录。以后换任务先检查输入是否符合已有流程，不把一次成功当作所有场景都能自动完成。实际效果取决于素材、工具能力、判断与修改；用自己能打开的成果说明完成到了哪一步。
