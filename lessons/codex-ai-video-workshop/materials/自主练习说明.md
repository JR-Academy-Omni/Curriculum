# 自选一个案例，独立练习半小时

## 半小时自主练习

每人选一个与自己工作相关的案例，直接打开现成 input 和 lesson，使用自己的 Codex 完成。参考成果可先看；实际练习时不让 Codex 读答案。

优先推荐：04 邮件整理、02 PDF 转换、06 报价单、14 文件整理。希望练浏览器的可选 05 网页填表；已确认图像工具可用的可选 13 宣传图。发票或 Excel 有基础的学员也可选择，未完成部分课后继续，不要求半小时内处理多个案例。

| 练习阶段 | 时间 | 学生动作 |
|---|---|---|
| 选案例 | 0–3 分钟 | 打开完整参考成果，选定一个任务 |
| 交代任务 | 3–6 分钟 | 提供输入与要求，让 Codex 复述计划 |
| 独立操作 | 6–23 分钟 | 执行、看结果、至少提出一次修改或核对要求 |
| 检查成果 | 23–28 分钟 | 打开实际文件，对照来源与该案例检查标准 |
| 保存带走 | 28–30 分钟 | 保存成果及可复用指令，记下一个疑问 |

学生无需先写代码。讲师巡回处理操作问题，不统一带着全班逐步做某个案例。每个学生只需展示所选案例的结果；未完成则指出具体缺口，不冒充完成。

### Student completion checklist (English)

- Open the actual output, not just the chat response.
- Explain the task, inputs and output requirements you gave Codex.
- Show one revision or verification request you made.
- Check the result against the original input and identify any missing information.
- Save the result and reusable instructions without overwriting the source.
