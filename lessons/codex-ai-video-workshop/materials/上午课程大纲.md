# Codex 上午课大纲与讲师安排

时间：10:00–12:00，共 2 小时。12:00 准时午餐，13:00 开始独立的 AI 视频模块。

教学重点是 Codex 的交流、文件处理、浏览器、生图和自动化。18 个现成案例作为练习材料库；学生自选一个，在 11:10–11:40 独立练习半小时。

## 学习成果

学生能提供资料并交代任务，继续修改第一版，打开与核对成果，保存可复用指令。上午至少实际完成一个自选案例的核心输出；未完成部分记录具体缺口。

## 上午安排

| 时间 | 模块 | 内容 |
|---|---|---|
| 10:00–10:10 | 认识 Codex 与工作区 | 先看已有成果；添加课程资料文件夹，找到输入与输出 |
| 10:10–10:30 | 如何交流、追问与修改 | 讲清目标、背景、输入和输出；先看计划，修改第一版，要求核对依据 |
| 10:30–10:50 | 文件处理与浏览器示范 | 用现成案例短示范：读文件、提取或转换内容；浏览网页、核对字段和本地表单预览 |
| 10:50–11:10 | 生图与自动化示范 | 生图 10 分钟：描述与定点修改；自动化 10 分钟：单次跑通、频率、范围、通知与确认 |
| 11:10–11:40 | 学生自主练习 30 分钟 | 每人自选一个现成案例，独立操作；讲师巡回答疑 |
| 11:40–12:00 | 成果展示、答疑与复盘 | 邀请 2–3 位学生打开成果；说明任务、修改和核对方法；其余人保存指令 |

## 半小时自主练习

每人选一个与自己工作相关的案例，直接打开现成 input 和 lesson，使用自己的 Codex 完成。参考成果可先看；实际练习时不让 Codex 读答案。

优先推荐：04 邮件整理、02 PDF 转换、06 报价单、14 文件整理。希望练浏览器的可选 05 网页填表；已确认图像工具可用的可选 13 宣传图。发票或 Excel 有基础的学员也可选择，未完成部分课后继续，不要求半小时内处理多个案例。

| 练习阶段 | 时间 | 学生动作 |
|---|---|---|
| 选案例 | 0–3 分钟 | 打开完整参考成果，选定一个任务 |
| 交代任务 | 3–6 分钟 | 提供输入与要求，让 Codex 复述计划 |
| 独立操作 | 6–23 分钟 | 执行、看结果、至少提出一次修改或核对要求 |
| 检查成果 | 23–28 分钟 | 打开实际文件，对照来源与该案例检查标准 |
| 保存带走 | 28–30 分钟 | 保存成果及可复用指令，记下一个疑问 |

学生无需先写代码。讲师巡回处理操作问题，不统一带着全班逐步做某个案例。每个学生只需展示所选案例的结果；未完成则指出具体缺口，不冒充完成。

### Student completion checklist (English)

- Open the actual output, not just the chat response.
- Explain the task, inputs and output requirements you gave Codex.
- Show one revision or verification request you made.
- Check the result against the original input and identify any missing information.
- Save the result and reusable instructions without overwriting the source.

## 讲师课前准备

- 在与学生相近的账号、版本和权限中检查添加文件夹、读取文件、导出成果、浏览器、生图和自动化入口。
- 准备一个 5 分钟文件任务示范和一个 5 分钟本地网页操作示范，重点展示如何沟通、检查与修订；不在前半场完整讲完发票、PDF、Excel 三套业务案例。
- 打开案例库入口与各完整参考成果，学生可直接使用，无需自带客户文件。
- 准备 PDF/XLSX 阅读工具和确定性本地依赖；订阅会话内练习，不配置或调用额外付费模型 API。
- 使用虚构资料，不投屏真实发票、工资、客户或合同。
- 自动化先演示手动试跑和配置草案；学生核对范围与时间后自行决定启用，不替全班注册周期任务。

## 讲师示范重点

1. 模糊需求与完整要求的区别：先说目标、给材料、说明输出，再看计划。
2. 第一版不满意时，只针对有问题的部分修改，保留已核对事实。
3. 浏览器操作先读页面、核对字段，再进入受控预览。
4. 生图保持日期、地点等事实不变，再调整版式。
5. 自动化先把单次任务做对，再讨论重复执行、失败处理和通知。

## 复盘提问（English）

- What did you ask Codex to do, and what information did you provide?
- What did you change after seeing the first result?
- How did you check the output against the source?
- What would you reuse next time?

完整素材库仍保留 16 个主案例和 2 个内容策划选修；未在课堂选用的可课后继续。参考成果为预先编制教学样例，不是学员成果或无人干预执行证明。
