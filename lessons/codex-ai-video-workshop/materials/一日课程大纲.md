# Codex 与 AI 视频实战课：一日课程方案

课名暂拟。面向希望把 AI 用于日常办公、内容制作与活动宣传的行政、运营、市场和小企业团队；以无需提前编程为起点。

时间安排：10:00–12:00 Codex；12:00–13:00 午餐；13:00–17:00 AI 视频，下午含 10 分钟休息。教学与练习共 350 分钟。上午、下午独立授课，不强行串成一个项目。

## 上午：Codex 日常使用实战

重点：怎么与 Codex 交流、提供文件、使用浏览器、生图、设置自动化。案例包直接用于学生自主练习。

| 时间 | 模块 | 内容 |
|---|---|---|
| 10:00–10:10 | 认识 Codex 与工作区 | 先看已有成果；添加课程资料文件夹，找到输入与输出 |
| 10:10–10:30 | 如何交流、追问与修改 | 讲清目标、背景、输入和输出；先看计划，修改第一版，要求核对依据 |
| 10:30–10:50 | 文件处理与浏览器示范 | 用现成案例短示范：读文件、提取或转换内容；浏览网页、核对字段和本地表单预览 |
| 10:50–11:10 | 生图与自动化示范 | 生图 10 分钟：描述与定点修改；自动化 10 分钟：单次跑通、频率、范围、通知与确认 |
| 11:10–11:40 | 学生自主练习 30 分钟 | 每人自选一个现成案例，独立操作；讲师巡回答疑 |
| 11:40–12:00 | 成果展示、答疑与复盘 | 邀请 2–3 位学生打开成果；说明任务、修改和核对方法；其余人保存指令 |

## 午餐：12:00–13:00

12 点准时结束上午教学。收尾问题可记录后再答，不挤占午餐。

## 下午：AI 视频制作实战

以 HyperFrames 带做科普片，Remotion 演示另一工程路线；活动剪辑与营销内容贯穿素材、镜头和修改环节。

| 时间 | 教学内容 | 实操 |
|---|---|---|
| 13:00–13:20 | 剧本、分镜与镜头动作 | 需求、事实素材、完整剧本、逐镜动作和验收 |
| 13:20–13:45 | 安装 Skills 与环境检查 | 插件/独立技能分流，实际读取 Skill，确认运行依赖 |
| 13:45–14:35 | HyperFrames 主线 | 初始化、场景与素材、检查、预览、修改、导出说明 |
| 14:35–14:45 | 休息 |  |
| 14:45–15:25 | Remotion 对照 | 创建工程、composition、帧时间、Studio、指定导出 |
| 15:25–16:00 | 活动剪辑、营销与复用 | 素材台账、时间线、粗剪确认、主对象动作和自动化边界 |
| 16:00–16:45 | 学生自选一条路线练习 | HyperFrames 或 Remotion，预览、修改和实际输出 |
| 16:45–17:00 | 作品播放与复盘 | 打开成果，检查事实、画面、声音和未完成项 |

## 学生带走什么

- 上午：一个自己操作的文件、表格、图片或网页填写结果；一条经过修改与核对的可复用指令；16 个主案例与 2 个选修的完整练习包。
- 下午：目标完成一条科普或活动短片；选择营销方向时可完成一个关键片段；同时保留脚本、分镜、工程文件与修改记录。以实际导出与播放为准，不以聊天回复代替作品。

## 半小时自主练习怎么安排

每人选一个现成案例：邮件整理、PDF 转换、报价单、文件整理优先；浏览器选网页填表，图像工具可用时选宣传图。学生直接使用案例包内素材与指令。0–3 分钟选案例，3–6 分钟交代任务，6–23 分钟操作与修改，23–28 分钟核对，28–30 分钟保存成果。讲师巡回答疑，不统一带全班做同一案例。

## 备课与范围

- 安装、登录、权限与确定性本地依赖在课前检查；现场只做快速确认，不占用上午主要教学时间。
- 上午只取案例短片段说明用法，不完整讲解全部案例。保留 30 分钟自主练习和 20 分钟复盘。
- 下午课前由讲师准备并跑通完整科普成片、获授权活动素材与精华片、可复现营销片段。只有完成素材与工具预检后，才适合承诺学生现场可制作相同范围成果。
- 视频工具按讲师已跑通流程与课堂账号确定；不把某工具的目标能力说成已验证。扣子工作流可作为已验证流程的展示，火山引擎开户、付费 API 和接口排障不占用基础课时间。
- 不承诺全自动完成优质活动片或酷炫营销片；保留素材选择、结构、节奏和事实核对的人工步骤。
- 本方案只编排教学，不启用任何学生自动化、不发布、不发生真实付款或对外提交。
