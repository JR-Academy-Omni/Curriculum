# 我指挥了 65 个 AI 助手：用 Claude 搭一套信息核验系统 · WORKSHEET

## 任务

挑一件你经常要查、要比较、要判断的事（选供应商、筛简历、挑房子、看竞品、查政策……），把你脑子里的判断方法写成一张能直接派给 AI 助手的「派活单」。

## 输入资料

- 课件第 10 页：派活单五件事
- 课件第 11 页：固定结果格式的样例
- 课件第 21 页：派活单模板

## 操作步骤

1. **说出来（2 分钟）**：对着 Claude 口述你的判断标准，让它整理成条目。没有电脑就写在纸上，一条一行。
2. **画出来（2 分钟）**：让它画成流程图，每一步标清谁来做（程序 / AI / 人），通过线在哪。
3. **写派活单（3 分钟）**：挑其中一步，照下面的模板写：

```
你要查：［对象清单］
判定标准：
  满足 = ［……］
  部分满足 = ［……］
  不满足 = ［……］
只认来源：［……］
不认：［……］
结果格式：每行  对象|项|判定|证据一句话|出处网址
查不到：按规则判，不许编
```

## 完成判据

- 判定标准写到别人能照着判，不用再问你
- 写明了只认哪些来源、不认哪些
- 结果格式固定，能用程序逐行检查
- 写了「查不到怎么办」

## 独立迁移任务（课后）

1. 用这张派活单让 Claude 实际查 3 个对象。
2. 让它写一段脚本，按完成判据检查这 3 行结果。
3. 换一个新对话，让另一个 AI 只看派活单独立重查一遍，对比两次结论，记下不一致的地方。

## 提交证据

- 派活单全文
- 3 行结果和校验脚本的输出
- 两次结论的对比，以及你据此改了派活单的哪一句
