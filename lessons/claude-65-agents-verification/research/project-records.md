| 数据 | 值 | 怎么得到 |
|---|---|---|
| 搭建周期 | 课件写「三天」（讲师口径） | 底账 decisions 表最早一条 2026-10-12；宣传片高清定稿 2026-10-25 |
| 人拍板的决定 | 42 | decisions 表行数 |
| 并行助手组数 | 65 | 五项全项补查名单 batches.txt 的组数 |
| 被查公司 | 641 | 同上，名单公司数 |
| 结论条数 | 2,438 | 校验脚本 check_fill.py 统计的有效行数，全部通过 |
| 官方原文 | 1,087 | 补查结果中出处网址去重；其中 1,070 份来自 static.cninfo.com.cn |
| 独立复核 | 64 家，推翻 15 家 | recheck2 记录 |
| 口径 v2 改判 | 49 家 | 口径 v2 改判清单 |
| 汇川技术 2026 Q2 营收 | 145.32 亿（半年累计 246.75 − 一季度 101.43）；上年同季 115.31 亿；同比 +26.02% | 程序按累计相减计算，与半年报第 8 页、一季报一致 |
