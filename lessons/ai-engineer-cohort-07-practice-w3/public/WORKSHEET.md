# W3 工作单 · Rapid CareKind MVP Build with Claude Code

本课按 ADLC 五步推进：需求 → PRD → 开发 → 部署 → 反馈。每一步填完、由你确认后，再进入下一步。

本周产品不调用 AI 模型；Claude Code 是开发工具。所有字段用实际 starter、实际命令输出和课程合成数据填写，没有运行的检查写“未验证”，不写猜测。

## 课前预读：开发前要想清的六件事

1. 对象关系与机构归属：Resident、Shift、Task、Care Activity、Progress Note 之间是几对几，每个对象属于哪家机构。
2. Note 状态机：谁能在什么状态做什么；确认后的内容是否不可改，改错是否新建修订版本。
3. API 错误约定：401、403、404、409、422 各代表什么，界面分别怎么提示；重复点击“送审”会不会产生两条记录。
4. 敏感数据：日志和 audit 不写姓名与记录内容，课堂只用合成数据。
5. 时间与班次：班次跨午夜怎么算，时区按机构，数据库存 UTC。
6. 测试账号与数据：各角色固定账号（含另一家机构）、每次测试前可重置的合成数据。
