## 0. 怎么读这份文件（先读这一节，三分钟）

**这份文件里只用下面这些词。除此之外不用缩写。**

| 词 | 意思 |
|---|---|
| **一幕 / 二幕……** | 课分成五段，每段叫一幕 |
| **翻车** | 让学员跑一段**看起来写得很正常**的代码，然后看见它的真实行为出乎意料。**全课只有这一次（P14）** |
| **埋点** | 前面故意说一句「这个待会儿会回来」，后面再接上 |
| **硬停** | 这一页讲到这个时间必须走，不管讲完没讲完 |
| **收口** | 最后几分钟那段话。全课所有东西在这里收成一句 |
| **立论** | 全课的核心主张。只说一次，说在第二幕 |
| **反转** | 推翻学员刚刚建立的安全感的那一下。说在第五幕 |
| **聊天框信号** | 线上没有助教，所以让学员在聊天框打字告诉你进度。这是唯一的进度来源 |
| **agent** | 替你干活的那个 AI。本节从头到尾在说"给它什么权限" |
| **写权限表** | 本节的核心产物。一张表，四列，一行一类写操作 |

**这节课要讲的几个专有说法，第一次出现时都会现场解释，这里先列出来：**

| 说法 | 一句话解释 | 第一次出现 |
|---|---|---|
| **白名单（`allow`）** | 一份"这些命令不用每次问我"的清单。**它减少弹窗，不阻止任何事** | P06 |
| **`deny` 列表** | 跟 `allow` 同一个文件里的另一半。**列进去的命令它直接不做，而且 `deny` 优先于 `allow`** —— 这是命令层面唯一真的拦得住的东西 | P06 |
| **不动工作区的命令** | 只看不改你的文件（看状态、看历史、取远端更新）。⚠️ 取远端更新会写 `.git` 里的引用，所以判据是"不碰你的文件"，不是"什么都不写" | P06 |
| **配置 / 指令文件** | **配置**＝那份命令放行清单（白名单放在这儿）。**指令文件**＝agent 每次进这个仓库都会先读的那份项目规则文件，你写给它看的 | P03 / P05 |
| **规则仓 / 记录 / 产品仓** | 三个放不同东西的地方：规矩、每天的工作状态、真正的业务代码 | P04 |
| **写权限表** | 一张表，一行一类写操作。**它记录"组织批准了什么"，它本身不执行任何事** | P08 |
| **连接器** | 让 agent 通过接口去读写外部系统的那个接入件 | P12 |
| **通行证（令牌）/ 同意屏** | 你点一次"同意"，系统发给连接器一张**有期限的通行证**；它过期了要人回那个授权页重新点一次 —— 那个页面就是**同意屏** | P13 |
| **服务凭据** | 一种**不需要人去点同意**就能用的授权。定时跑的任务只能用这种 | P13 |
| **四态结果** | 一次查询的四种结局：成功有数据 / 成功但确实是空 / 成功但没拿全 / 失败 | P16 |
| **技能 / 规范层 / 执行层** | **技能**＝一份可复用的"agent 该怎么干这件活"的说明。**规范层**记为什么能这么干，**执行层**记具体步骤 | P17 |
| **符号链接** | 文件系统里的一个指针文件，指向另一处的真文件。**不是网页链接** | P17 |
| **会话启动钩子** | 每次打开 agent 会话时自动跑一下的小脚本 | P20 |
| **巡检 / 硬政策** | **巡检**＝定期跑一次看看有没有对不上，**不拦任何东西**。**硬政策**＝唯一真的能让一个改动进不来的那一层 | P20 |
| **P0 / P1 / P2 / P3** | **派一件活、做一个决策时就要带的级别**，P0 最急。判据全是问一句就能判的：P0 有对外承诺挂在上面 · P1 点得出名字有人在等 · P2 没人等但有到期日 · P3 都没有 | P19b |
| **升级 / 降级** | **升级**＝往上提一级（更快叫人）；**降级**＝往下放一级。⭐ **降级条件和升级条件一样重要** | P19b |
| **漂移** | 实际的权限，和规矩里写的权限，**对不上了** | P20 |
| **具名** | 写一个具体岗位（"客服主管"），不许写"团队" | P08 / P18 |
| **身份目录 / 单点登录 / 共享凭据** | **身份目录**＝公司存"谁对应哪个账号"的系统；**单点登录**＝一个公司账号登录多个系统；**共享凭据**＝多人共用的一个密码或密钥 | P22 |

### ⭐ 四种东西不要混，这是全课最容易糊的一处

| | 它是什么 | 它拦不拦人 |
|---|---|---|
| **命令白名单**（P06） | 省事配置 —— 少弹几次确认框 | **不拦。** 它只减少打断 |
| **写权限表**（P08） | 政策记录 —— 组织批准了什么、依据是什么 | **不拦。** 它是一份写下来的决定 |
| **自动检查**（P20 中间那层） | 技术执行 —— 不合规的改动进不来 | **拦。全课唯一真的拦人的那层** |
| **人工批准** | 谁有权做这个政策决定 | **做决定可以；当成"每次改动的关口"就会失效**（P21） |

> 🚨 **这张表讲师要能随时翻出来。** 学员最常见的误解是
> **把"写下来的政策"当成"技术上拦住了"** —— 而这两件事差一整层。

## 1. 这一节的三句话（讲师必须能默写）

**立论** —— 第二幕说，全课只说一次：

> **权限不是一个开关，是一张一行一行批出来的表。**

**反转** —— 第五幕，学员刚给自己的表加完审批人、最有安全感的时候翻：

> **你加的那个人工审批，多半不是保障，是失效模式。**

**收口** —— 全程不许提前说：

> **它最危险的时候，不是它做错了事，**
> **是它什么都没做，而你以为它做了。**

**三句话怎么连起来（讲飞的时候回到这条链）：**

```
权限一行一行批
  → 每一行都要记下「这项批准立在什么上面」
  → 因为可核查的是【依据】，不是【按钮】
  → 一个按钮产生不了任何可核查的东西
  → 而不可核查的系统，最典型的失败不是做错事
  → 是什么都没发生，而所有人以为发生了
```

**收口那句同时收掉四样东西，这是它比上一节收口更硬的地方：**

| 课上哪一格 | 怎么被它收掉 |
|---|---|
| 四态结果（失败绝不报 0） | 查询失败报成 0，你以为本期无异常 |
| 连接失败必须自带修复步骤 | 连接过期没人知道，报告天天是空的 |
| 人工审批是失效模式 | 有人点了合并，但没人读过 |
| 权限漂移每周巡检 | 离职残留的授权一直在，只是没人看 |

**四件事是同一个形状：看起来发生了，实际没有。**

## 2. 为什么有这一节（开场要说清楚）

上节课（第十三节）学员造出了一个**会自己拦人的规则仓库**。

> 🚨 **不要说「它现在没有消费者」「AI 在哪」。那是假的，学员会觉得莫名其妙。**
> **学员现在就在那个目录里开着 Claude Code —— 它早就在读了。**

**真实情况是这样的，而且它比那个假问题好用：**

Claude Code 一进 `my-ops` 这个目录就开始读东西。但是：

| 它在读 | 问题在哪 |
|---|---|
| **它读的不是你指定的那几份** | `my-ops` **连指令文件都没有** —— 它读到什么全靠自己翻，你没告诉过它该读哪几份 |
| **它能改，而且比你以为的能改得多** | 第一幕第二格那个动手就是让他看见这个 |
| **没有任何东西拦着它** | 这就是今天剩下 110 分钟在做的事 |

**所以今天的问题不是「AI 在哪」。它在。今天的问题是这三个。**

**顺序是故意的，而且这是两节课之间最重要的一句话：**

> **地基错了，上面那层越强越危险。**
> 一个规则写得糊涂的仓库，配上一个有写权限的 agent，**比没有 agent 糟得多。**

## 2b. ⭐ 本期的演示设定（接着第十三节那套往下做）

**这一节不换场景。** 第十三节那个「青柠工作室」继续用，而且今天三个仓**全是真的**：

| 三仓图上的 | 今天是哪个 | 现在什么状态 |
|---|---|---|
| **规则仓** | `~/Desktop/team-ops/my-ops` | 有 `rules/`（4 个角色）+ `people/`。**没有指令文件** |
| **产品仓** | `~/Desktop/star-mansions` | 真的产品仓，前后端 + 文档，有自己的 `CLAUDE.md`。**L4 和 L8 一路用下来的那个** |
| **记录** | **还没有** | ⭐ 今天不建。第一幕三仓图讲到这一格，**如实说它还空着** |

### 🔥 今天最漂亮的一下：指令文件今天才第一次被建出来

**第十三节的八步里，指令层是排在最后的。** 当时给的理由是：

> 它是唯一一份**会反过来管住这次施工**的文件 ——
> 你写完它的那一刻，帮你建仓库的那个 agent 就开始受它管。
> 所以：**规则先定死、检查先跑绿、强制点先挂上，最后才告诉 AI「这些是你要遵守的」。**

**排到最后的结果是：它一直没做。** `my-ops` 里到现在没有指令文件。

**所以 P05 不是「改一份已有的文件」，是它第一次被建出来。**
讲到 P05 的时候，这句话要说出口：

> 「上节课我说指令层最后做。**最后做的意思不是不做。**
> 　**今天就是那个『最后』。**」

### 产品仓那条禁令，今天有具体对象

P05 要写进指令文件的那句，今天是：

```
不许向 star-mansions 写入任何内容。
读它是对的，也应该鼓励；写是禁止的。
```

**为什么这个例子特别好用（讲师可以多说一句）：**
`star-mansions` 自己**就有一份 `CLAUDE.md`** —— 它有自己的审查人、自己的流程。
**一个 agent 同时能写 `my-ops` 和 `star-mansions`，就是把两套互不相干的审查制度短路了。**
这不是假设，**今天这两个仓就在你们机器上。**

> ⚠️ **deck 上不出现这些名字** —— deck 要跨班复用，名字只活在这份讲稿里。
> **讲师口头说具体名字，投屏时学员看到的是通用的三仓图。**

## 5. 线上没有助教，怎么知道学员跟上了没有

**唯一的进度来源是聊天框。所以必须主动要信号，不能等人举手。**

**五条纪律：**

1. **每次动手开始前，先说清楚"做完在聊天框打什么"。** 例如："做完打 `1`。"
2. **每次动手给一个具体的时间**，并且在中途报一次："还有两分钟。"
3. **收信号要收两次**：中途一次看进度，结束一次看完成率。
4. **不到一半的时候不要往下走。** 投屏自己做一遍，让没跟上的人照着抄。
5. **一个人卡超过两分钟，不要在直播里单独给他调环境。** 让他用课前包里对应那份文件跟上，你继续往下走。

**这节课有七处要收信号，在逐页口播里都标了「📊 收信号」。**

**学员卡住的四种情况，怎么处理：**

| 情况 | 怎么办 |
|---|---|
| **没有上节课那个规则仓库** | 不影响前四幕。**第五幕三层自动化那格改成听，不要求他挂** |
| **说不出一件希望 agent 替他做的事** | 用 `p09` 模板里那份填好的样例，**在它上面改** |
| **P14 在他机器上跑不出来** | 先让他确认 `node -v` 有输出。还不行 —— **讲师投屏演一遍**，这一格看比做损失小，它要的是那个画面 |
| **填的全是编的内容** | 第二幕填表会"填不疼"。**让他换成真实的一件事**，这是第三列能不能填出来的前提 |

## 6. 产品名怎么说 —— 本节比别节都要紧

| 哪一类 | 说不说 | 怎么说 |
|---|---|---|
| **学员公司的系统** | **绝对不说产品名** | 说「你们那个记事情的系统」「你们那个发消息的工具」 |
| **Claude 自己的东西** | **照常说** | 白名单配置、技能、钩子，直接说 |

**一句话判据：学员换一家公司还要用的，说；换一家公司就不用了的，不说。**

**为什么学员公司那边不说，三个理由：**

1. **脱敏** —— 讲师公司用什么，学员不需要知道。
2. **国内班海外班同一份课件** —— 本节五问的结构对任何一套工具都成立，只换连接器清单。**所以这节课不需要做"国产替代"专页。**
3. **学员能把自己代入** —— 学员公司用的东西跟你不一样是常态。讲产品名会让一半人觉得"这跟我没关系"。

> ⚠️ **本节比上一节还要严，因为它通篇在讲外部系统。**

## P04 ｜ 12 到 15 分钟 ｜ 东西放在哪 ⭐

**三行，一行一句：**

> 「**规则仓** —— 放稳定的运营定义。上节课你造的就是这个。写的人很少。
>
> 　**记录** —— 放每天的工作状态，一人一天一个文件。所有人都能写。

**第三行要停一下，给理由：**

> 「注意，**禁止写产品仓不是怕它写坏。**

> 　是因为**权限边界要跟责任边界对齐**。
> 　产品仓有它自己的审查人，有它自己的检查。
> 　**一个 agent 同时能写两边，等于把两套互不相干的审查制度短路了。**」

> ⭐ **讲师：这三个仓今天都是真的，名字直接说出来（但不要写到屏幕上）：**
> **规则仓 = 你上节课建的那个 · 产品仓 = 我们从第四节一路做到现在那个 · 记录 = 还没有。**
>
> **记录那一格要如实说：**
> 「**这一层我们今天不建。** 它该是仓还是数据库，上节课给过判据 ——
> 　**被读的进 git，被数的进库。** 今天先把它在图上占住位置。」

**顺带埋一句分仓的理由（不展开，有人问再翻附录 A0）：**

> 「为什么非要分三个？因为**规则和记录对审查的要求正好相反** ——
> 　规则要强制审查，记录绝不能要，否则不会用 git 的人根本交不了东西。」

## P06 ｜ 18 到 26 分钟 ｜ 白名单怎么建 ⭐🎯 **全班动手** 📊

> 🔴 **2026-10-04 改版（讲师：「第八页白名单怎么建」）：**
> 这一页原来只讲了「里面该放什么」，**从没教怎么建**。
> 而取消翻车① 之后，**学员整节课根本没碰过白名单**，第二幕也丢了终端输出。
> 现在改成：长什么样 → 它其实是怎么来的 → 怎么正经建 → **当堂建一个**。

> 🔴 **顺带修掉一处讲得不准的：** `settings` 里不只有 `allow`，**还有 `deny`**。

**第一步，指着屏幕上那段配置说它在哪：**

> 「它在你规则仓的 `.claude/settings.json` 里。

> 　`allow` 决定的是**「要不要问你一声」**。
> 　`deny` 决定的是**「能不能做」**。**而且 `deny` 优先于 `allow`。**」

**第二步，说那件不太舒服的事。这一句是这一页的重量：**

> 「现在说一件不太舒服的事。
>
> 　**你那份 `allow`，多半不是你设计出来的。**
> 　是你一路点**『总是允许』**，它自己攒出来的 ——
> 　每次弹窗你嫌烦，点一下，它就往里加一条。
>
> 　**所以它才不是安全边界：没有人设计过它。**
>
> 　**打开你那份看一眼。** 你多半会看到几条你完全不记得自己批准过的东西。」

> 🚨 **这里停一下，让他们真的去看。** 比你说十遍都有用。

**第三步，正经建的三件事：**

> 「**一，`allow` 只放不动你工作区的** —— 看状态、看差异、看历史、取远端更新。
>
> 　**二，`deny` 放真正危险的** —— 删除、强推、硬重置。
> 　**⭐ 这是你今天就能加上的第一道真边界。一行配置，立刻生效。**
>
> 　**三，个人偏好放 `settings.local.json`，并且忽略提交** —— 别把你的习惯塞给全队。」

> 「对，它会写 `.git` 里的引用。**判据是它不碰你的文件，不是它什么都不写。**

> 　加完打 `1`。」

**收完信号，埋下一页：**

> 「注意 `allow` 和 `deny` 不是一回事。**下一页说清楚它们各自管什么** ——
> 　**而且会说到一件更要紧的：`deny` 拦得住的东西，比你以为的少。**」

## P07 ｜ 26 到 30 分钟 ｜ `allow` 管什么，`deny` 管什么 ⭐

> 🔴 **2026-10-04 改版：这一页原来是「翻车①」**—— 让学员故意把白名单放宽、
> 跑一条会改东西的命令，然后发现没人拦他。**讲师取消了：不要从反面教。**
> （沿用第十三节 v3.2 那条：**正面给规矩，不赌学员犯错。**）

**两栏，一栏一句：**

> 「**`allow` —— 省事。**
> 　它决定的是『要不要问你一声』，**不是『能不能做』**。
> 　**不在 `allow` 里的命令，它照样会做，只是先问一句。**
> 　所以 **`allow` 是省事边界，不是安全边界**。
>
> 　**`deny` —— 它真拦。**
> 　列进去的命令，**它不会问你，直接不做**。这是你今天就能加上的第一道真边界。」

**然后给那个关键的限制。这是这一页真正要讲的：**

> 「但注意 `deny` 的管辖范围：**它只拦得住「命令」。**
>
> 　它拦不住**『发一封邮件』**，拦不住**『改一条工单』** —— **那些不是命令。**
> 　**管那些的，是下一页那张表。**」

**最后把四样东西分开。这一句很重要，别省：**

> 「今天会出现**四样**东西，**管的事都不一样，不要混**：
>
> 　`allow` —— **省事**，不拦。
> 　`deny` —— **拦**，但只拦得住命令。
> 　**下一页那张写权限表** —— 管的是『对外做了什么』，它是**政策记录，不拦**。
> 　**第五幕那层自动检查** —— 管的是『改动进不进得来』，**它拦**。
>
> 　学员最常犯的误解，就是**把「写下来的政策」当成「技术上拦住了」**。」

> **硬停：第 30 分钟。**

## P08 ｜ 30 到 34 分钟 ｜ 写权限表 ⭐⭐ **立论在这 · 让学员拍照**

> 🚨 **这一页必须让学员拍照。讲到这里主动说一句：「这一页拍下来。」**

> 「写权限**不是一个开关**。它是一张**明细表**。
> 　每一行是一类写操作。每一行都要回答四个问题。」

**指四列，一列一句：**

> 「**第一列，写到哪。** 邮箱草稿、仓库提交、工单系统、聊天通知。
>
> 　**第二列，谁批准的。** 一个**具体的角色**，不是『团队同意』。
>
> 　**第三列，这项批准立在什么上面。** —— 先记住这一列，我马上说它。
>
> 　**第四列，什么时候能升级。** 从『每次有人盯着』到『让它自己跑』，要什么证据。」

**然后点立论，全课只说这一次：**

> 「**权限不是一个开关，是一张一行一行批出来的表。**」

**停一秒。然后讲第三列，这是全课最值钱的一格：**

> 「**第三列是这节课存在的理由，而且它反直觉。**
>
> 　真正起作用的限制，**不在『谁按那个按钮』，在这项批准立在什么上面。**
>
> 　一封**任何人都能重新打开来读**的邮件，和**一通电话**，
> 　**在权限这件事上，不是一个东西。**
> 　**邮件可以被重新打开来核；电话转述不能。**
> 　**而一个按钮，什么都核不了 —— 它只留下『有人按过』，留不下『凭什么按』。**」

**最后说强弱两行那一格：**

> 「所以这张表里**允许出现强弱不同的两行，而且必须标出来**。
> 　依据是一通电话转述的那一行，**是一项批准在仍然算作批准的前提下，最弱的形式。**
>
> 　**把它的弱标出来，比把它伪装成跟另一行一样，安全得多。**」

> **硬停：第 34 分钟。**

**然后这一句要说出口，它是这一幕的落点：**

## P10 ｜ 40 到 43 分钟 ｜ 有四件事，谁批都不行 ⭐

> 「写权限表之外，还要有一组**不在表上**的事。
> 　它们不是『**没批准**』，是『**不可批准**』。
>
> 　一，不从活跃度、消息长度、在线时长，推断一个人投入了多少或产出了多少。
> 　二，不给人打分、排名、互相比较。
> 　三，不把私人聊天和邮件当成汇报数据。

## P16 ｜ 73 到 76 分钟 ｜ 它必须能说出四种话 ⭐⭐

## P19c ｜ 101 到 107 分钟 ｜ 走一遍：一件超时没验收的活 ⭐⭐

> > 　一个超时就自动降级的系统，**是在把『没人管』当成『不要紧』的证据** ——
> > 　**而没人管的那件事，经常正是最该管的。**」

**再过一遍「它该做的」，四步，每步点一下出处：**

> 「**① 观察事实，不下判断。** 到期日已过、未验收 —— 两条都是可观察的现象。
> 　**② 按规则定级，不自己定。** 对外承诺过 → P0；只是内部到期 → P1。
> 　　**⛔ 定级是规则的事**，上一页刚说过。
> 　**③ 起草一条提醒。** 在操作者自己那里建草稿 —— **发送要人按**，
> 　　那条线今天第二幕讲过。
> 　**④ 发给验收人 + 负责人。**
> 　　**只发负责人没用 —— 他多半就是卡住的那个人。**」

**最后那条，跟第三幕咬上：**

> 「提醒里必须有三件事，**跟连接失败那三件一模一样**：
> 　**事实**（到期日、逾期多久）· **它现在卡在哪** · **下一步具体该谁做什么**。
> 　**最后那件通常是缺的。而缺了它，提醒就只是在制造焦虑。**」

> **硬停：第 107 分钟。**

## P20 ｜ 107 到 112 分钟 ｜ 谁在替你盯着 ⭐ · **埋点 4**

**先说检查是怎么来的，三条，第一条最重要：**

> 「**第一条：新检查从真发生过的错来，不从想象来。**
> 　凭想象加的检查是噪音，两周后会被注释掉。
> 　**从事故反推的每一条，都有人愿意维护。**
>
> 　第二条：**硬失败和提示必须分开。** 全设成失败 = 天天红 = 没人再看。
>
> 　第三条：**改流程 = 同一次改动里同时改检查。**
> 　一处更新另一处没更新的规则，**比没更新的规则更糟** —— 因为没人分得清哪个是当前的。」

**然后说三层自动化：**

> 「三层，各管各的：
>
> 　**每次开会话** —— 会话启动钩子。只报告你这份落后多少，**永不自动拉取，永远正常退出**。
> 　**每次提改动** —— 一致性检查。绿了才能合。⭐ **这一层是唯一真正的硬政策。**
> 　**每周一次** —— 权限漂移检查。比对实际权限和规矩里写的权限。
>
> 　**注意中间那层和两边的差别：钩子是提醒，巡检是巡检 ——**
> 　**只有中间那层，能让一个改动进不来。**」

**然后给第一层那条铁律 —— 正面给，不让他们先挂一个坏的：**

> 🔴 **2026-10-04 改版：这里原来是「翻车③」**（让学员故意把钩子改成阻塞的，
> 自己感受一下有多烦）。**讲师取消了：不要从反面教。**

> 「**第一层有一条铁律：它永远正常退出，永远不拦你。**
> 　课前包 `p20-session-hook/` 里那个就是写对的，**照着抄，不用自己发明。**
>
> 　为什么必须不拦？因为**一个会阻塞会话的新鲜度警告，比它警告的陈旧本身更糟** ——
> 　它每天拦你一次，**拦的还都是你当下不打算处理的事**。
>
> 　**两天之内你会亲手把它关掉。然后连提醒都没有了。**」

> 🔥 **埋点 4。这句「你会亲手关掉它」是下一页反转的入口：**
> 　 **一个频繁拦你、又给不出有用信息的关口，会被绕过去。**

> **硬停：第 112 分钟。**

## P21 ｜ 112 到 118 分钟 ｜ 反转 ⭐⭐ **一口气到底，中间不要提问**

> 🚨 **这是全课最容易被听错的一页。最后那一块必须念出来，一个字不要改。**

**先接上一页：**

> ⚠️ **这里有两件事必须分开说，混了这一页就讲砸了：**
>
> | | 是什么 | 今天的态度 |
> |---|---|---|
> | 你表上第二列「谁批准的」 | **谁有权批准这一类写操作** | **保留。这是政策决定，必须有人做** |
> | 「每次改动都要等某人点一下合并」 | **逐次的人工放行** | **下面要翻的是这一个** |

> 「刚才那个钩子，你会亲手关掉它。**记住这个形状：一个频繁拦你、又给不出有用信息的关口，会被绕过去。**
>
> 　现在换一个关口 —— **不是你表上那一列『谁批准的』，那一列要留着。**
> 　我说的是另一件事：**很多团队还会要求『每一次改动都得等某个人点一下合并』。**
> 　**那一下，多半不是保障，是失效模式。**」

**三条理由，一条一条给，第三条最重：**

> 「**第一，那个按钮从来就不是控制点。**
> 　如果本来就没有自动检查，一次为了等人而扣住的合并，
> 　**增加的是延迟，不是审查。**
>
> 　**第二，它不是一次审查。**
> 　没有人真的在读那些改动。
> 　**一个被执行、却从不被真正行使的步骤，会训练所有人把它当成形式** ——
> 　**这比没有它更糟。**
>
> 　**第三，被扣住的合并会让仓库说谎。**」

**第三条要展开，这是最硬的一条：**

> 「一个改动挂了三天。
> 　那三天里，文件上写着『只起草，不发送』，
> 　**而实际上它已经在按一份已经合并的授权发送了。**
>
> 　**那次延迟什么也没阻止。它生产了一份有据可查的自相矛盾。**」

**停一秒。然后这一块必须念出来：**

> 「⚠️ **我要说清楚：这是对『人工审批』说的，不是对『审批』说的。**
>
> 　**结论是：把关口放在『检查绿不绿』上，不要放在『谁点了合并』上。**
>
> 　**检查是可核查的，按钮不是。**」

> 🚨 **没念这一块，学员回去会把审批全撤了。**

> **硬停：第 118 分钟。**

## P22 ｜ 118 到 120 分钟 ｜ 每周数一次，但不点名 ⭐

> 「最后一层，权限漂移检查。
> 　**漂移**就是：实际的权限，和你规矩里写的权限，对不上了。
>
> 　有个限制：**个人账号的映射属于身份目录，不进规则仓。**
> 　**所以这个检查不能按人查。**」

**然后给那个反直觉的收获：**

> 「**而这个限制，反而逼出了更强的检查形态。**
>
> 　比如这一条：『**一个不是组织成员的协作者**』——
> 　**不需要任何人知道那是谁，就能抓到一条离职残留。**」

**最后说它看不见什么，这一段同样重要：**

> 「**同样重要的是写清楚它看不见什么：**
> 　身份提供商与单点登录、邮件组、共享盘、日历系列、共享凭据。
>
> 　**高风险的残留恰恰在那边，不在这边。**
> 　**那几类需要人走一遍清单，没有自动化能替你。**」

> **硬停：第 120 分钟。**

## P23 ｜ 120 到 125 分钟 ｜ 收口 ⭐⭐⭐ **五分钟，一秒都不能压**

> 🚨 **这五分钟分三段，中间各停一秒。不要连着念完。**

### 第一段 —— 把四样东西合到一起（约 2 分钟）

> 「今天你给它开了权限、接了系统、写了技能、挂了检查。
> 　**现在回头看四样东西：**」

**指屏幕，一行一句，不要解释：**

```
查询失败报成了 0        →  你以为本期无异常
连接过期没人知道        →  报告天天是空的
有人点了合并，但没人读过 →  你以为有审查
离职残留的授权还在      →  你以为清过了
```

> 🚨 **第一行就是你们两小时前亲手造出来的那个 0。指一下它。**
> 　 **这是埋点 2 的回收。**
> 🚨 **第二行是埋点 3 的回收** —— 那个"下次有人来的时候告诉他"。

> 「**四件事是同一个形状：看起来发生了，实际没有。**」

### 第二段 —— 收口（约 1.5 分钟）

**停一秒。然后慢：**

> 「**它最危险的时候，不是它做错了事，**
>
> 　**是它什么都没做，而你以为它做了。**」

> 🚨 **说完停两秒。不要接任何话。**

### 第三段 —— 作业（约 1 分钟）

> 「这周就一件事：
> 　**回去看你那张写权限表的第三列。**
>
> 　**哪一行的依据你写不出来，那一行就先关掉。**」

> 🚨 **不要加"下节课我们将……"。说完作业直接下课。**
