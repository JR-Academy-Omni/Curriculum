# P07 · 翻车① 用的命令

> 第二幕（P07）用。**三分钟。**
> 🔴 **不要自己选「危险命令」。用下面这条。**

## 做什么

**第一步**，建一个临时目录，进去：

```bash
mkdir -p /tmp/l14-allowlist-test && cd /tmp/l14-allowlist-test
```

**第二步**，把这条命令加进你的命令白名单（放行清单）：

```
touch
```

> `touch` 会在磁盘上建一个空文件 —— 它**会落盘**，但**完全可逆**（删掉就行）。
> 我们要的就是「一条会改东西的命令」，但不要真的有破坏性。

**第三步**，保存配置，然后让 agent 执行这句：

```
在当前目录建一个空文件 l14-test.txt
```

**第四步**，看它跑完了没有，然后删掉：

```bash
rm -f l14-test.txt
```
