## 上课前自己跑一下，确认环境没问题

```bash
cd p14-zero-or-unknown
node broken.mjs reports      # 应该输出：本期报告数：2
node broken.mjs repor7s      # 应该输出：本期报告数：0   ← 看到这个就对了
```

**第二条看到 `0` 就说明你的环境是好的。** 课上我们会一起看那个 `0` 是怎么来的。
