# P20 · 翻车③：挂一个会阻塞的钩子

> 第五幕（P20）用。**三分钟，做完必须恢复。**

**会话启动钩子** = 每次打开 agent 会话时自动跑一下的小脚本。

这里有两个版本。**先挂 blocking 的，感受一下，然后换回 non-blocking。**

| 文件 | 行为 |
|---|---|
| `check-freshness.mjs` | 正常版：**只报告，永远正常退出**，不拦你 |
| `check-freshness.blocking.mjs` | 翻车版：**检查不过就退出码非 0**，会把会话卡住 |

## 做什么

1. 把 `check-freshness.blocking.mjs` 挂成你的会话启动钩子
2. 关掉会话，重新开一个 —— **感受一下被卡住**
3. 然后问自己一句：**这东西你能忍几天？**
4. **换回 `check-freshness.mjs`，重开会话确认恢复正常**

> 🔴 **第 4 步不许跳过。** 别让学员带着一个会卡住的钩子下课。
