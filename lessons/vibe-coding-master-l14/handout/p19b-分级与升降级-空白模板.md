# 这事儿有多急 · 分级表空白模板

> 第五幕（P19b）用。**五分钟填完。**
> 四态模型说的是「它该报什么」。这张表说的是：**报了之后，谁动、多快动。**

## 规则

| 多急 | 判据（**必须是可观察的现象**） | 谁动、多快 | **什么条件下降回下一级** ⭐ |

## 填的时候守三条

### 一、判据必须是**可观察的现象**，不是「很严重」

| ❌ 判断题（没法判） | ✅ 形状题（一眼就能判） |
|---|---|
| 这个问题很严重 | **对外可见的东西已经错了** |
| 影响比较大 | **客户看到了 / 钱动了 / 消息发出去了** |
| 有点风险 | **它没跑，而且没有人知道** |

> 这是第十三节那个动作的第三次出现：**把判断题换成形状题。**
> 判据写成判断题，等于每次都重新吵一遍这事儿到底急不急。

### 二、⭐ 降级条件必须和升级条件一起写

**最后一列不许空。**

> **没有降级条件的分级，三个月后全是最高级** ——
> 然后所有人对最高级脱敏，它就跟没分级一样了。
>
> 这跟「**全设成失败 = 天天红 = 没人再看**」**是同一个形状**。

降级条件也要是可观察的现象，比如：

```
最高 → 高    对外可见的那一条已经撤回或更正，而且有人确认过
高   → 中    它重新跑起来了，并且连续两次结果正常
中   → 低    缺的那部分补齐了
低   → 关掉  连续四周没有再出现
```

### 三、⛔ 定级权不给 agent

它只报**事实** —— 就是上一幕那四种状态（成功 / 真零 / 不完整 / 失败）。

**多急是规则说了算，不是它说了算。**
否则它会**很合理地**觉得什么都很急 —— 而且它每次都很有道理。

## 一份填好的样例（可以在它上面改）

| 多急 | 判据 | 谁动、多快 | 什么条件下降回下一级 |
|---|---|---|---|
| **最高** | 对外可见的东西已经错了（客户看到了 / 钱动了 / 消息发出去了） | **立刻叫到人**，不等下一个工作日 | 那一条已经撤回或更正，**而且有人确认过** |
| **高** | 它没跑，而且没有人知道（查询失败报成 0、连接过期没人发现） | **当天有人看** | 它重新跑起来了，**连续两次结果正常** |
| **中** | 它跑了，但没拿全（分页只拿到前两页） | **下次有人来的时候告诉他** | 缺的那部分补齐了 |
| **低** | 只影响内部，而且可以等（格式不统一、命名不规范） | 攒着，**每周一起看** | 连续四周没有再出现 → **关掉这条检查** |

> 注意最低那一级的降级条件是「**关掉**」。
> **一条四周都没响过的检查，留着只是噪音。**
