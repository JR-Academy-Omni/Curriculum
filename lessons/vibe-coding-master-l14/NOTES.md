## 0. 怎么读这份文件（先读这一节，三分钟）

**这份文件里只用下面这些词。除此之外不用缩写。**

| 词 | 意思 |
|---|---|
| **一幕 / 二幕……** | 课分成五段，每段叫一幕 |
| **翻车** | 让学员跑一段**看起来写得很正常**的代码，然后看见它的真实行为出乎意料。**全课只有这一次（P14）** |
| **埋点** | 前面故意说一句「这个待会儿会回来」，后面再接上 |
| **硬停** | 这一页讲到这个时间必须走，不管讲完没讲完 |
| **收口** | 最后几分钟那段话。全课所有东西在这里收成一句 |
| **立论** | 全课的核心主张。只说一次，说在第二幕 |
| **反转** | 推翻学员刚刚建立的安全感的那一下。说在第五幕 |
| **聊天框信号** | 线上没有助教，所以让学员在聊天框打字告诉你进度。这是唯一的进度来源 |
| **agent** | 替你干活的那个 AI。本节从头到尾在说"给它什么权限" |
| **写权限表** | 本节的核心产物。一张表，四列，一行一类写操作 |

**这节课要讲的几个专有说法，第一次出现时都会现场解释，这里先列出来：**

| 说法 | 一句话解释 | 第一次出现 |
|---|---|---|
| **白名单（`allow`）** | 一份"这些命令不用每次问我"的清单。**它减少弹窗，不阻止任何事** | P06 |
| **`deny` 列表** | 跟 `allow` 同一个文件里的另一半。**列进去的命令它直接不做，而且 `deny` 优先于 `allow`** —— 这是命令层面唯一真的拦得住的东西 | P06 |
| **不动工作区的命令** | 只看不改你的文件（看状态、看历史、取远端更新）。⚠️ 取远端更新会写 `.git` 里的引用，所以判据是"不碰你的文件"，不是"什么都不写" | P06 |
| **配置 / 指令文件** | **配置**＝那份命令放行清单（白名单放在这儿）。**指令文件**＝agent 每次进这个仓库都会先读的那份项目规则文件，你写给它看的 | P03 / P05 |
| **规则仓 / 记录 / 产品仓** | 三个放不同东西的地方：规矩、每天的工作状态、真正的业务代码 | P04 |
| **写权限表** | 一张表，一行一类写操作。**它记录"组织批准了什么"，它本身不执行任何事** | P08 |
| **连接器** | 让 agent 通过接口去读写外部系统的那个接入件 | P12 |
| **通行证（令牌）/ 同意屏** | 你点一次"同意"，系统发给连接器一张**有期限的通行证**；它过期了要人回那个授权页重新点一次 —— 那个页面就是**同意屏** | P13 |
| **服务凭据** | 一种**不需要人去点同意**就能用的授权。定时跑的任务只能用这种 | P13 |
| **四态结果** | 一次查询的四种结局：成功有数据 / 成功但确实是空 / 成功但没拿全 / 失败 | P16 |
| **技能 / 规范层 / 执行层** | **技能**＝一份可复用的"agent 该怎么干这件活"的说明。**规范层**记为什么能这么干，**执行层**记具体步骤 | P17 |
| **符号链接** | 文件系统里的一个指针文件，指向另一处的真文件。**不是网页链接** | P17 |
| **会话启动钩子** | 每次打开 agent 会话时自动跑一下的小脚本 | P20 |
| **巡检 / 硬政策** | **巡检**＝定期跑一次看看有没有对不上，**不拦任何东西**。**硬政策**＝唯一真的能让一个改动进不来的那一层 | P20 |
| **P0 / P1 / P2 / P3** | **派一件活、做一个决策时就要带的级别**，P0 最急。判据全是问一句就能判的：P0 有对外承诺挂在上面 · P1 点得出名字有人在等 · P2 没人等但有到期日 · P3 都没有 | P19b |
| **升级 / 降级** | **升级**＝往上提一级（更快叫人）；**降级**＝往下放一级。⭐ **降级条件和升级条件一样重要** | P19b |
| **漂移** | 实际的权限，和规矩里写的权限，**对不上了** | P20 |
| **具名** | 写一个具体岗位（"客服主管"），不许写"团队" | P08 / P18 |
| **身份目录 / 单点登录 / 共享凭据** | **身份目录**＝公司存"谁对应哪个账号"的系统；**单点登录**＝一个公司账号登录多个系统；**共享凭据**＝多人共用的一个密码或密钥 | P22 |

### ⭐ 四种东西不要混，这是全课最容易糊的一处

| | 它是什么 | 它拦不拦人 |
|---|---|---|
| **命令白名单**（P06） | 省事配置 —— 少弹几次确认框 | **不拦。** 它只减少打断 |
| **写权限表**（P08） | 政策记录 —— 组织批准了什么、依据是什么 | **不拦。** 它是一份写下来的决定 |
| **自动检查**（P20 中间那层） | 技术执行 —— 不合规的改动进不来 | **拦。全课唯一真的拦人的那层** |
| **人工批准** | 谁有权做这个政策决定 | **做决定可以；当成"每次改动的关口"就会失效**（P21） |

> 🚨 **这张表讲师要能随时翻出来。** 学员最常见的误解是
> **把"写下来的政策"当成"技术上拦住了"** —— 而这两件事差一整层。

## 2. 为什么有这一节（开场要说清楚）

上节课（第十三节）学员造出了一个**会自己拦人的规则仓库**。

> 🚨 **不要说「它现在没有消费者」「AI 在哪」。那是假的，学员会觉得莫名其妙。**
> **学员现在就在那个目录里开着 Claude Code —— 它早就在读了。**

**真实情况是这样的，而且它比那个假问题好用：**

Claude Code 一进 `my-ops` 这个目录就开始读东西。但是：

| 它在读 | 问题在哪 |
|---|---|
| **它读的不是你指定的那几份** | `my-ops` **连指令文件都没有** —— 它读到什么全靠自己翻，你没告诉过它该读哪几份 |
| **它能改，而且比你以为的能改得多** | 第一幕第二格那个动手就是让他看见这个 |
| **没有任何东西拦着它** | 这就是今天剩下 110 分钟在做的事 |

**所以今天的问题不是「AI 在哪」。它在。今天的问题是这三个。**

**顺序是故意的，而且这是两节课之间最重要的一句话：**

> **地基错了，上面那层越强越危险。**
> 一个规则写得糊涂的仓库，配上一个有写权限的 agent，**比没有 agent 糟得多。**

## 2b. ⭐ 本期的演示设定（接着第十三节那套往下做）

**这一节不换场景。** 第十三节那个「青柠工作室」继续用，而且今天三个仓**全是真的**：

| 三仓图上的 | 今天是哪个 | 现在什么状态 |
|---|---|---|
| **规则仓** | `~/Desktop/team-ops/my-ops` | 有 `rules/`（4 个角色）+ `people/`。**没有指令文件** |
| **产品仓** | `~/Desktop/star-mansions` | 真的产品仓，前后端 + 文档，有自己的 `CLAUDE.md`。**L4 和 L8 一路用下来的那个** |
| **记录** | **还没有** | ⭐ 今天不建。第一幕三仓图讲到这一格，**如实说它还空着** |

### 🔥 今天最漂亮的一下：指令文件今天才第一次被建出来

**第十三节的八步里，指令层是排在最后的。** 当时给的理由是：

> 它是唯一一份**会反过来管住这次施工**的文件 ——
> 你写完它的那一刻，帮你建仓库的那个 agent 就开始受它管。
> 所以：**规则先定死、检查先跑绿、强制点先挂上，最后才告诉 AI「这些是你要遵守的」。**

**排到最后的结果是：它一直没做。** `my-ops` 里到现在没有指令文件。

**所以 P05 不是「改一份已有的文件」，是它第一次被建出来。**
讲到 P05 的时候，这句话要说出口：

> 「上节课我说指令层最后做。**最后做的意思不是不做。**
> 　**今天就是那个『最后』。**」

### 产品仓那条禁令，今天有具体对象

P05 要写进指令文件的那句，今天是：

```
不许向 star-mansions 写入任何内容。
读它是对的，也应该鼓励；写是禁止的。
```

**为什么这个例子特别好用（讲师可以多说一句）：**
`star-mansions` 自己**就有一份 `CLAUDE.md`** —— 它有自己的审查人、自己的流程。
**一个 agent 同时能写 `my-ops` 和 `star-mansions`，就是把两套互不相干的审查制度短路了。**
这不是假设，**今天这两个仓就在你们机器上。**

> ⚠️ **deck 上不出现这些名字** —— deck 要跨班复用，名字只活在这份讲稿里。
> **讲师口头说具体名字，投屏时学员看到的是通用的三仓图。**

## 6. 产品名怎么说 —— 本节比别节都要紧

| 哪一类 | 说不说 | 怎么说 |
|---|---|---|
| **学员公司的系统** | **绝对不说产品名** | 说「你们那个记事情的系统」「你们那个发消息的工具」 |
| **Claude 自己的东西** | **照常说** | 白名单配置、技能、钩子，直接说 |

**一句话判据：学员换一家公司还要用的，说；换一家公司就不用了的，不说。**

**为什么学员公司那边不说，三个理由：**

1. **脱敏** —— 讲师公司用什么，学员不需要知道。
2. **国内班海外班同一份课件** —— 本节五问的结构对任何一套工具都成立，只换连接器清单。**所以这节课不需要做"国产替代"专页。**
3. **学员能把自己代入** —— 学员公司用的东西跟你不一样是常态。讲产品名会让一半人觉得"这跟我没关系"。

> ⚠️ **本节比上一节还要严，因为它通篇在讲外部系统。**

## 5. 线上没有助教，怎么知道学员跟上了没有

**唯一的进度来源是聊天框。所以必须主动要信号，不能等人举手。**

**五条纪律：**

1. **每次动手开始前，先说清楚"做完在聊天框打什么"。** 例如："做完打 `1`。"
2. **每次动手给一个具体的时间**，并且在中途报一次："还有两分钟。"
3. **收信号要收两次**：中途一次看进度，结束一次看完成率。
4. **不到一半的时候不要往下走。** 投屏自己做一遍，让没跟上的人照着抄。
5. **一个人卡超过两分钟，不要在直播里单独给他调环境。** 让他用课前包里对应那份文件跟上，你继续往下走。

**这节课有七处要收信号，在逐页口播里都标了「📊 收信号」。**

**学员卡住的四种情况，怎么处理：**

| 情况 | 怎么办 |
|---|---|
| **没有上节课那个规则仓库** | 不影响前四幕。**第五幕三层自动化那格改成听，不要求他挂** |
| **说不出一件希望 agent 替他做的事** | 用 `p09` 模板里那份填好的样例，**在它上面改** |
| **P14 在他机器上跑不出来** | 先让他确认 `node -v` 有输出。还不行 —— **讲师投屏演一遍**，这一格看比做损失小，它要的是那个画面 |
| **填的全是编的内容** | 第二幕填表会"填不疼"。**让他换成真实的一件事**，这是第三列能不能填出来的前提 |
