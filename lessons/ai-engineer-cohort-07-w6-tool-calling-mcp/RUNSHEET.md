## 被问到时

- **终端输出从哪来**：老师本机实测，FastMCP 4.1.4、MCP Python SDK 2.3.0，记录在 `research/demo-runs.md`。
- **第 14 页那段 JSON 是实测吗**：不是，是 Anthropic API 文档里 tool_use 的格式示例；今天的终端输出才是实测。
- **为什么不是 server/discover**：2026-07 版规范改了，但 FastMCP 4.1.4 还没实现，实测返回 Method not found；它走 initialize（协议版本 2025-11-25）。
- **print 到 stdout 真的会断吗**：规范禁止。我们用的客户端会悄悄丢掉那一行；别的客户端没测，所以别赌。
- **Claude Code 能不能设 cwd**：`.mcp.json` 只有 command、args、env，路径写完整；server 里的数据路径按文件自己的位置找（`Path(__file__).parent`）。
