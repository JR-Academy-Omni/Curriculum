# W2 工作单 · CareKind UI 与 Design System

依据 [PRD](PRD.md) 与 [讲师流程](RUNSHEET.md)。从 W1 产品契约出发，本周产出 Design Brief、DESIGN.md、tokens、关键页面、状态和 Product Design Review。

## 1. 页面与用户路径

选择一条 CareKind 业务路径，列出用户、页面、操作、CRUD、组件和导航。分别说明用户在每页做什么，以及如何知道操作成功。

将规则落到 DESIGN.md 与 tokens；让 Agent 生成两个页面，检查是否复用相同规则，而非每页重新写一套样式。

## 3. 状态与评审

为关键页面设计 loading、empty、error、success 与权限受限状态。用同一用户路径检查信息架构、可读性、操作反馈和组件一致性。保留30分钟页面动手与10分钟评审，具体进度按讲师流程执行。

## 交付与独立迁移

提交 Brief、DESIGN.md、tokens、页面截图、状态清单与一次评审修改。再用同一规范做一个不同页面，记录哪些规则能复用。没有接通后台的 UI 标明模拟，不声称业务闭环已完成。
