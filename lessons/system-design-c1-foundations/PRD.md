# System Design 实战课 · 第一期 · L01

## System Design 基础

Lightman · 120 分钟 · 在线直播 · 21 页

## 定位

整期课只有 3 节、6 小时，靠案例练系统设计。第一节负责打底：学员离开时会用一套固定步骤分析任何系统设计题，并知道最常用的几个组件各是什么、解决什么问题、要付出什么代价。

其余概念不在本节讲，放进后两节的案例里：

| 概念 | 在哪讲 |
|---|---|
| CDN、带宽估算、推流与拉流、最终一致 | L02 直播 |
| 任务状态机、租约、条件更新、版本与只重做一步 | L03 AI 视频生成 |
| 分片、限流、API 网关 | 第二期 |

## 学习目标

1. 说出 System Design 要回答什么：在给定需求和约束下，画出架构并讲清每个选择的代价。
2. 用 5 步方法分析一道题：澄清需求 → 估算 → 高层架构 → 深挖关键点 → 故障与瓶颈。
3. 对数据库、对象存储、负载均衡、缓存、message queue，各说出三件事：是什么、解决什么问题、代价是什么。
4. 判断什么时候同步返回、什么时候交给队列异步处理。
5. 说明为什么重试必须幂等，并用一个例子讲清楚。

贯穿案例：用户上传视频，后台转码，处理完可以播放。课堂练习换一道新题（订单报表导出），检验学员能否迁移方法。
