# System Design 实战课 · 第一期 · L01

## System Design 基础

Lightman · 120 分钟 · 在线直播

## 学习目标

从视频上传到播放，拆需求、画架构并推演任务失败。

- 用户目标 · 上传视频，处理后播放
- 状态 · 在哪保存任务和文件
- 路径 · 区分同步返回和后台处理
- 故障 · 处理完成后进程退出
- 验证 · 播放产物并核对状态

## 教学节奏

| 分钟 | 内容 | 页码 |

| 00–15 | 看完整结果，明确系统边界 | P01–P03 |
| 15–25 | 需求与容量估算 | P03–P04 |
| 25–55 | 对照拓扑和状态设计 | P05–P08 |
| 55–65 | 休息 | P08 |
| 65–105 | 小组工作单与故障注入 | P09–P10 |
| 105–120 | 答辩、参考解与迁移 | P11–P13 |
