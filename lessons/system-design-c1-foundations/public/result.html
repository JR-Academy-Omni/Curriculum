视频上传与处理 · 完整成果

System Design 实战课 · 第一期

job-42 · ready

用户上传视频后获得任务编号。后台完成转码，刷新页面后即可播放以下成品。

完整架构

文件上传　浏览器 → 对象存储。上传成功后提交原件版本。

控制路径　浏览器 → 负载均衡 → Job API → 数据库保存任务 → 消息队列。

处理路径　Worker 领取消息 → 从对象存储读取原件 → 写成品 → 把任务更新为 ready → 确认消息。

结果读取　浏览器查 Job API → 校验所有者 → 获取限时地址 → 对象存储返回成品。
