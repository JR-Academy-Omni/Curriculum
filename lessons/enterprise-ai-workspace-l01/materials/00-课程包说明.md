# AI Workspace + Codex｜第一节课程包

## 本次范围
第一节重点为 SoT、记忆、企业 Workspace 与 Codex 工作方法，120 分钟。客户的 Building Construction 背景用于选择实操材料，后四节保留原课程结构。

## 文件使用
- 第一节课件.html：正式学生投屏课件，直接复用用户指定的创业营 W12 页面与 kit 组件，只替换课程必要文字。
- 成果阅读.html：企业介绍、两版项目简报、当前项目状态及资料依据全文。
- 01-第一节定稿.md：本节内容与时间安排。
- 02-教师授课流程.md、教师资料/：备课、材料性质、检查项和课堂记录，不投屏。
- 03-学员操作手册.md：项目操作及可直接使用的任务说明。
- 05-SoT与记忆工作单.md：资料组织、更新与新任务读取操作。
- 模板/、练习Workspace/、参考成果/：可编辑文件与完整内容。

## 来源与状态
课件视觉以用户指定的 W12 线上页面为唯一参考：https://jracademy.ai/curriculum/lessons/ai-solo-founder-w12/?page=1 。直接复用其 kit 与选定原页，逐页来源按实际映射登记。
Harbour Build Studio、人员、项目日期及记录为本课程编写的教学资料，不代表客户的实际业务。参考成果按这些资料整理，不是学员执行记录或真实 Codex 调用回执。
尚未在四位学员设备和账号上试讲。课前由老师实际运行两项任务和更新任务，检查文件读取、修改、保存与跨任务读取情况。
本包只含第一节课件与资料，不是五节全套课件；不包含真实业务发送、支付、发布、专业 OHS 判断或模型 API 授权。
