# SoT 与记忆工作单

## 企业 / 项目 SoT 字段
事实字段｜当前值｜状态（已确认/待确认/未批准）｜来源编号及文件｜维护人｜确认人｜更新时间｜原值与变化原因。
事实来源不得只写“AI说的”。合同变更须按公司审批流程处理，不由文件写入替代。

## 信息归位操作
把稳定偏好写入工作规则；把经确认的服务写入企业SoT；把项目当前日期写入项目SoT；把会议原文留在source；把新生成的简报留在outputs。未审核想法留在讨论中。

## 每次任务
明确指定当前资料 → 先复述并指出未知 → 纠正 → 执行 → 人工检查 → 确认新事实 → 更新对应SoT。

## 新任务验证
记录实际读取文件、复述结果、日期/审批状态是否正确、输出位置、检查人。发现旧信息先检查资料与版本，不默认工具已读取。
