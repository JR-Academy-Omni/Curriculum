## 课件来源
唯一视觉参考为用户指定的 [创业营 W12 线上课件](https://jracademy.ai/curriculum/lessons/ai-solo-founder-w12/?page=1)。直接复制对应的 `kit.tsx` 与选定原页，包括 `P01_Cover` 封面、`P05_Memory` 记忆文件树；保留原构图、颜色、字体、动画和组件。课程内容保持本课已确认范围，逐页来源按实际复用映射登记。

## 授课与资料
- 投屏：正式教学内容、原课件对应图示、必要来源与操作步骤。
- 教师：RUNSHEET.md 与 materials/教师资料，保留时间安排、检查记录、材料性质与课堂准备。
- 学员：WORKSHEET.md 与 materials/03-学员操作手册.md，包含项目资料、任务与更新操作。
- 完整成果：public/成果阅读.html，与课件单独打开；可编辑材料：materials/。

运行：`bun install`，然后 `bun run dev --host 127.0.0.1`。构建：`bun run build`。
