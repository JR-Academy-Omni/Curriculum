# 企业 AI 自动化实战营 L02 · Design System 与报价单

120 分钟工作坊。学员带着第一节的企业资料进入课堂，先把视觉规则写成可复用的 Design System，再从一条客户询价做出完整品牌报价单。报价单作为首次展开的独立主题，覆盖范围确认、逐项计价、条款、A4 排版、变更和 PDF 回读。

| 页 | 主题 |
| --- | --- |
| 1 | 封面与交付路径 |
| 2–4 | 创业营原页：为什么先做规范、品牌六项、Codex 实操 |
| 5 | 四阶段总览：报价 Markdown、SoT、HTML、PDF |
| 6 | 生成报价 Markdown 草稿，记录范围与待确认项 |
| 7 | 计算明细、小计、税额与总计 |
| 8 | 核对草稿并确认报价 SoT |
| 9 | 用报价 SoT 和 Design System 生成 HTML |
| 10 | 客户加一小时，重算并保留报价版本 |
| 11 | A4 打印、导出 PDF 和回读 |
| 12 | 独立完成自己的报价单 |

课堂案例 Cedar Events 沿用仓库 06-quote 练习的数据，业务事实和 10% 的税率均为该练习的既定输入。没有实际客户发送、合同签署或付款。
