# 120 分钟讲师流程

- 0–40 分钟｜页 1–4。带入第一节企业资料，复用创业营原页。学员用自己的资料生成 Markdown 规范和 HTML 预览。
- 40–50 分钟｜页 5。展示 Cedar Events 报价的四份文件。先看草稿和确认后的 SoT，再打开 HTML 和最终 PDF。
- 50–70 分钟｜页 6–8。给原始询价，先写 quote.md，再投屏逐项核对金额、条款并形成 quote-sot.md。10% 是课堂资料给定的参数，学员案件应从已确认的价格与税务资料取值。
- 70–100 分钟｜页 9、12。用报价 SoT、Design System 和 Prompt 生成 HTML，再让学员换成自己的需求。实际打开 HTML 检查。
- 100–120 分钟｜页 10–11。把执行时间由 2 小时加到 3 小时，检查总计从 AUD 1,474.00 变为 AUD 1,749.00。导出并打开 PDF，核对条目、版本、金额和分页。课堂不实际外发。
