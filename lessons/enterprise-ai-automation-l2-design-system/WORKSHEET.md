# Design System 与报价单工作单

1. 从第一节的企业资料提取并补齐六项品牌规则：名字和一句话定位、色板、字体、语气、图片风格、Logo。
2. 写下客户的原始需求。用一句话说明服务范围，再列交付项、计量单位、数量、已确认单价、交付时间和排除项。写入 quote.md，未知字段另列待确认。
3. 确认报价编号、客户名称、币种、已确认的税费口径、有效期、付款条件和书面接受方式，整理进 quote-sot.md。
4. 将报价 SoT 和 Design System 交给 Codex，生成 quote.html。核对每行数量乘以单价，核对各行合计、税费和最终金额。
5. 将一个数量改掉，重算并保存下一版。使用 A4 打印预览，导出 PDF 后再打开，和明细逐项比对。

随附材料在 public/quote/。先通读 brief.md 和 rates.csv，再打开 quote.html。
