## 0. 这个 deck 要让学员带走什么

### 0.1 四件硬产物

1. **一张资产表** —— 前十四节造出来的每一样东西，各自标上：活在哪个文件、哪一层 scope、进没进 git
2. **一个真的装得上的插件包** —— 里面至少有学员自己的一个 skill 和一个 hook，当堂装到干净 profile 上并验证生效 ⭐⭐
3. **一份四格交接说明** —— 它会碰什么 / 它什么时候自己跑 / 它依赖什么外部凭据 / 它坏了之后谁修
4. **一条「我走了之后要收回什么」** —— 补进自己的包

### 0.2 三句话（deck 上各占一屏，不许和别的内容混）

| | 落在哪一页 |
|---|---|
| 立论：**装不到第二台机器上的，不是系统，是习惯** | **P05** |
| 反转：**你交出去的不是文件，是默认值 —— 别人不会读你的 README，他们会直接用你设的默认** | **P20** |
| 收口：**一套系统的真正考验，不是它跑得多好，是它的作者离开之后它还在不在** | **P28** |

**链条**：东西散在一台机器上 → 散的东西没法交 → 交的形状是一个包 → 包里装的是默认值，不是文件 → 默认值是你替别人做的、没说出口的决定 → 所以交接必须把那些决定说出口 → 而最后一个没人说出口的决定是「你走了之后谁收」

### 0.3 这一节为什么是这一节，而不是补内容

L13 给了规则仓，L14 给了权限、连接、技能、维护。但到 L14 结束为止，学员造出来的每一样东西 —— L5 的 skill、L7 的 subagent、L11 的定时任务、L12 的 hook、L13 的规则仓、L14 的权限配置 —— **全部散落在一台笔记本上，全部没有被当成一个整体描述过，活不过换一台机器。**

而 Claude Code 的插件机制恰好就是这些东西的打包格式：一个插件能带 skills、subagents、hooks、slash commands、MCP、settings。

> **它不是「好用的工具」，它是前面十四节成果的分发格式。**

所以装插件不是硬塞进来的实操，它是本节的正题。

### 0.4 🔴 教学决定一：最大的风险是变成「装软件教程」

这一节天然像一节工具课。**解药：每一幕都必须回指前面十四节的某一样具体产物。**

学员装的每一个东西，都要能答出「这对应我第几节课造的哪一样」。答不出来，这一幕就讲飞了。

### 0.5 🔴 教学决定二：正面给规矩，不赌学员犯错

沿用 L14 的改版决定。**P18 的三种死法正面讲，不让学员故意把它装坏。** 只在学员恰好犯过错时才成立的教学点，是抽奖不是教学。

### 0.6 🔴 教学决定三：收口不许留钩子

**本节是最后一节。** P28 那句话之后不接任何东西 —— 没有「下节课」，没有「接下来你可以」，没有课程推荐。留白就是收口的一部分。

### 0.7 🔴 教学决定四：干净 profile 不许动学员的真配置

当堂验证要装到一个隔离环境里。**绝对不能让学员在自己日常配置上做实验** —— 这一节结束时他们的机器必须跟开课时一样能用。实现方式见 §7 风险 R3，**课前必须实测**。

## 3. 已核实的技术事实（写 deck 时以这里为准）

> 核实时间 2026-10-11，方式：直读本机已安装插件与市场目录。**deck 不得写本表以外的机制细节。**

| 事实 | 内容 |
|---|---|
| **插件 manifest** | `.claude-plugin/plugin.json`，字段：`name` / `version` / `description` / `author` |
| **市场 manifest** | 市场仓库根的 `.claude-plugin/marketplace.json`，字段：`name` / `owner` / `metadata` / `plugins[]`，每个插件条目带 `source` 指向它在仓库里的目录 |
| **插件的约定目录** | `skills/` · `agents/` · `commands/` · `hooks/`（内含 `hooks.json`），另可自带 `scripts/` 等自由目录 |
| **hooks.json 形状** | `{ description, hooks: { SessionStart: [...], SessionEnd: [...] } }`，每条是 `{ type: "command", command, timeout }` |
| **插件内脚本路径** | 用 `${CLAUDE_PLUGIN_ROOT}` 占位，**不许写死绝对路径** ⭐ 这是一个教学点 |
| **三层 scope** | `user`（装给自己，跨项目）· `project`（装给这个项目，进 git）· `local`（只在这台机器的这个项目） |
| **安装记录落点** | `~/.claude/plugins/installed_plugins.json`，每条记 scope / installPath / version / installedAt / lastUpdated / gitCommitSha |
| **市场记录落点** | `~/.claude/plugins/known_marketplaces.json`，记 source（github repo）/ installLocation / lastUpdated |
| **插件缓存落点** | `~/.claude/plugins/cache/<市场>/<插件>/<版本>/` |
| **市场缓存落点** | `~/.claude/plugins/marketplaces/<市场>/`（就是那个仓库的一份 clone） |
| **命令** | `/plugin marketplace add <github repo>` → `/plugin install <插件>@<市场>` |

**可以上屏的真实样本**（公开 marketplace，已核）：

| 市场 | 插件 |
|---|---|
| `anthropics/claude-plugins-official` | feature-dev · github · skill-creator · project-artifact · atlassian · chrome-devtools-mcp · stripe |
| `jarrodwatts/claude-hud` | claude-hud |
| `openai/codex-plugin-cc` | codex |
