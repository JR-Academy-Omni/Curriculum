## A. 上完 L15，学员手上有什么（四件硬产物）

- [ ] 不可逆清单上至少一行标了「**假可逆**」

## B. 五问逐项覆盖明细

### 问 1 · 它刚才干了什么（0-20 分钟）

- [ ] 承接句 + **终点宣告**（今天结束你会真的开一个定时任务，前四幕是它的条件）
- [ ] **翻车①**：真去翻它上次留下的东西，念出来
- [ ] **痕迹三级**：0 级叙述（「我已完成」）/ 1 级事实 / 2 级**可核查的事实**
- [ ] 判据：**一条痕迹值不值钱，看它能不能被重新打开来读**（L14 第三列那把尺子，换对象）
- [ ] 🎯 **终端**：输出末尾加一个能重新打开来读的东西

### 问 2 · 这条痕迹谁会读（20-44 分钟）⭐ 翻车②

- [ ] **翻车②** ⭐⭐：素材包，**三分钟内找出它改错的那一次** ,, 计时，时间到就停
- [ ] 「它什么都记了，它什么都没拦住,因为它在等人来找，而没有人会来找」
- [ ] **立论：证据不是存在哪，是谁在什么时候会被它拦住**
- [ ] 三个推送时点：跑完当场 / **下次有人来的时候** / 出不可逆动作之前
- [ ] 🔥 埋点：「这一格今天最后会回来」

### 问 3 · 撤得回来吗（44-74 分钟）⭐ 核心产物

- [ ] **明说「我在改上节课那张表」** ,, 两张表的分行方式并排
- [ ] **重排成不可逆清单**（12 分钟，不许压）
- [ ] **不可逆不是是非题，是一个时间** ,, 第二列必须填时长
- [ ] **假可逆三行**（A 形式可逆实质不可逆 / B 撤得回但早到人眼里 / C 真不可逆）
- [ ] 第四列「撤回之后还剩什么」不许空
- [ ] 通往第四幕的桥：**那些分钟全建立在「有人在看」上面**
- [ ] **翻车③**：真跑一次撤回（**两种结局都对**，讲师都要能接）
- [ ] **反转：你刚才撤回的是你的系统，不是外面的世界**
- [ ] **人按的那一下只在一个地方有用：不可逆的前一秒**（精确修正 L14 §6.5）

### 问 4 · 凭什么让它自己跑（74-114 分钟）⭐⭐ 本节终点

- [ ] **还债**：念 L14 §4.2 那句结论和它认的代价 + **一句分界**（§0.2b）
- [ ] **自检 A · 冷启动** ⭐：任务描述丢进全新空会话跑 ,, 三连问，第三问是全幕内容
- [ ] **定时任务是 L13 那个远端的第一个真消费者**（冷启动是那个仓库的考试）
- [ ] **升级三道门**：跑够 / **错过且被抓住** / 撤回演练过
- [ ] 🎯 **终端**：三道门写成能跑的判定，输出「还差几次」
- [ ] **真的开一个** + **自检 B · 它在不在**（关掉会话再开，列一下）
- [ ] **自检 C · 它会不会来找你** ,, 第二幕那条兜底升成主路径
- [ ] 讲形状不讲参数（§0.12 三个不变的形状 + 讲师课前核对清单）

### 问 5 · 这次错怎么变成下次的规矩（114-135 分钟）

- [ ] **回流四步**：发生了什么 / **哪条痕迹本该拦住它** / 写成一条跑红的检查 / 改清单哪一行
- [ ] 第 2 步要停：「答案是『没有任何一条』,, **那才是真正的发现**」
- [ ] 🎯 **终端**：当堂回流，**跑红**（**两处都改才算一次完整回流**）
- [ ] **定时任务是这套系统的喂料口**（还债的第二层意思）
- [ ] **收口**：五种陈列 + 接 L14 收口（一次运行 → 整套系统）+ 接终点 + 真正的年龄
- [ ] 收口之后**直接下课，不许加下节预告**（§6.1 铁律 10）
