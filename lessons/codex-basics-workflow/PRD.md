# Codex 基础功能与工作流 · PRD

## 学习目标

- 理解 Project、Chat、Result 的工作模型。
- 能区分 AGENTS.md、Skill、Plugin 与 Automation。
- 能选择模型、权限和 Plan Mode，并使用反馈控制完成一次任务。
- 能用“理解—准备—规划—执行—验证—交付”六步完成可分享成果。
