What is an Agent

这是一门真正的 Agent 搭建课

普通 AI 通常是“问一句、答一句”。在这门课里，你会把 Codex 配置成一个能读取资料、遵循规则、分步骤完成工作并主动检查结果的工作 Agent。

接收任务明确要完成什么
检索资料查找已有文件与知识
遵循规则按行业要求工作
调用工具生成文件或图片
检查结果识别缺失与异常
自动执行按计划重复运行

全班只搭建这一个“个人 AI 信息整理助理”。课程目标不是完全无人管理，而是让 Agent 整理信息、判断资料是否足够并生成初稿，由人审核后确认使用。

What we teach

这一天会教你什么

从第一次打开 Codex 开始，不跳步骤。每个知识点都紧跟一次现场操作，最后组合成一个完整工作流。

01 · SETUP

Codex 基础设置

完成登录、工作目录、文件权限和基本使用设置，知道 Codex 能做什么、不能做什么。

02 · TASK

把工作讲清楚

用目标、资料、规则、步骤和输出格式五个要素，让 Agent 得到清楚、可执行的任务。

03 · CONTEXT

读取文件与资料

让 Codex 理解本地文档、表格和图片，把散乱资料整理成结构化结果。

04 · RULES

配置长期工作规则

通过工作说明文件保存岗位背景、输出要求、安全边界和人工复核条件。

05 · TOOLS

生成工作成果

让 Agent 不只回答问题，还能生成报告、表格、工作文件和图片，并按要求修改。

06 · AUTOMATION

设置自动化任务

把已经验证过的工作流设置为每日或每周运行，并保留关键人工确认节点。

What you will learn

完成后，你会真正学会

不是记住几个按钮，而是掌握一套可以迁移到不同岗位、不同任务的 Agent 搭建方法。

判断什么任务适合 Agent

找到高频、重复、有明确规则且可以复核的工作。

设计完整工作流程

把一个模糊需求拆成输入、处理、检查和输出。

给 Agent 配置上下文

让它读懂岗位资料，并持续遵循你的工作规则。

让 Agent 使用工具

生成报告、文件、表格或图片，而不止是聊天回复。

测试和修正 Agent

用正常、缺失和错误资料验证它是否可靠。

安全地设置自动运行

知道哪些步骤可以自动化，哪些必须由人确认。

Who it is for

适合什么人

课程默认学员几乎没有 AI 和编程基础。只要平时需要处理文件、整理信息、重复生成内容或定期汇报，就有适合练习的工作场景。

适合零基础的非技术职场人

会计 / 财务HR行政市场销售教育小企业主
  • 只会简单使用 ChatGPT，不知道怎么让 AI 连续完成工作
  • 经常整理文件、做周报、检查资料或重复生成内容
  • 希望学习一套通用方法，再根据自己的行业修改
  • 不想学代码，但愿意跟着老师现场操作

暂时不适合

高级开发复杂集成无人值守系统
  • 希望学习 API、Python 或多 Agent 工程开发
  • 需要现场接入企业核心系统
  • 希望 Agent 自动处理付款、审批等高风险决定

Safety by design

自动化之前，先学会安全边界

  • 练习使用模拟或脱敏资料
  • 不上传密码、证件和敏感客户数据
  • 金额、日期和专业结论必须复核
  • 缺少资料时，Agent 必须停下来询问
  • 付款、审批等高风险动作不自动执行
  • 自动任务保留人工确认和结果记录
FAQ

零基础常见问题

课程会提供统一练习资料和模板。安装与账号检查安排在课前完成，课堂时间主要用于搭建和实操。

完全不会编程，可以参加吗？

可以。课程不教 Python、API 或代码开发。你需要具备基本的电脑文件操作能力，并愿意跟着老师逐步完成练习。

没有 Codex 会员怎么办？

可以正常报名。没有会员的学员将获得匠人学院提供的 7 天 AI 会员免费试用，用于完成课堂练习和课后复习；这不是 Codex 官方赠送，具体开通方式与可用功能以报名通知为准。

这和普通的 AI 提示词课有什么区别？

提示词只是其中一部分。你还会配置长期规则、让 Agent 读取资料、生成文件或图片、检查异常，并设置自动运行。

一定要做会计案例吗？

不需要。统一案例用于带大家跑通方法，最后会改造成会计、HR、市场、销售、行政或教育等个人场景。

一天后能做到什么程度？

你可以独立搭建和测试一个简单个人工作 Agent；复杂系统集成、多人协作和工程开发不在本次课程范围内。
