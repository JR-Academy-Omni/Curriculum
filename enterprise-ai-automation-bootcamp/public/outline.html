Phase 1 · 企业 AI Workspace

统一企业事实、工作职责与输出标准。

L01

企业 AI Workspace 与 Codex 入门

实操授课 · 120 min

把零散企业资料整理成 Source of Truth，让 Codex 按同一套事实完成任务。通过一次企业介绍与 FAQ 草稿，检查输入、修改和保存成果的完整路径。

  • 整理一份事实与未知分开的企业 Source of Truth。
  • 写明 AI Assistant 的职责、输入、输出和升级人工的条件。
  • 执行并修改一项企业任务，保留依据。

教学内容

  • 完整成果与 Codex 入门
  • 建立企业 Source of Truth
  • 配置 Workspace 与 Task Templates
  • 执行、修改与验收

课堂实操

使用同一家企业的资料，整理企业介绍和客户 FAQ 回复草稿；对缺失价格、客户证明等字段标记待确认。

成果整理与 Review

整理课堂完成的企业资料包、AI Assistant 工作说明和至少两项 Task Templates；课堂内完成核心版本，课后可选迁移至自有业务。

课堂内教师检查；不承诺额外课后服务。

带走的成果

  • 企业 Source of Truth
  • AI Assistant 工作说明
  • Task Templates 与一次输出记录

120 分钟教学安排

  1. 01 · 完整成果与 Codex 入门20 min

    展示企业资料、FAQ 草稿与任务输出；练习给需求、看预览、提修改，说明 AI 处理和人工审核的分工。

  2. 02 · 建立企业 Source of Truth25 min

    整理产品、服务、客户、卖点、FAQ 和语气；逐项注明确认事实、来源与待确认信息。

  3. 03 · 配置 Workspace 与 Task Templates45 min

    组织企业资料、素材、任务和输出目录；写职责、必读输入、输出标准、不做项与停止条件。

  4. 04 · 执行、修改与验收30 min

    生成企业介绍和 FAQ 草稿，检查依据与缺失项，修改任务规则并重新执行。

验收标准

  • 产品、服务、受众和事实出处可追溯。
  • 未知不被自行补齐；不编造客户证明。
  • 任务可重新执行，输出格式与审核责任明确。

Phase 2 · VI / Design System / Website

先定基础品牌规范，再直接应用到企业官网原型。

L02

AI 品牌设计：VI、Design System 与 Website

实操授课 · 120 min

将企业定位转化为基础 VI 和可复用 UI 规范，再用 Codex 制作企业单页官网。包含企业介绍、服务、成果案例与咨询入口，重点检查视觉和内容的一致性。

  • 区分 VI 与 Design System 的用途。
  • 定义字体、配色、间距、版式和基础 UI Components。
  • 使用同一规范完成 Desktop / Mobile 单页官网原型。

教学内容

  • 成果展示与视觉方向
  • 基础 VI 与 Design System
  • 用 Codex 制作单页 Website
  • Desktop / Mobile 检查与修改

课堂实操

沿用 L01 企业资料与预置网站模板，完成品牌规范和首页、服务、案例、咨询四部分。已有品牌沿用原有规范，已有 Logo 不由模型重绘。

成果整理与 Review

整理品牌规范、Design System 展示页与可浏览网站；附 Desktop / Mobile 检查记录，明确咨询入口为演示。

课堂内教师检查；不承诺额外课后服务。

带走的成果

  • 基础 VI 与 Logo 使用规范
  • Design System 展示页
  • 可浏览的企业单页官网原型

120 分钟教学安排

  1. 01 · 成果展示与视觉方向15 min

    打开完成的品牌规范和网站，解释 VI、Design System 与企业定位的关系，确定视觉方向。

  2. 02 · 基础 VI 与 Design System30 min

    整理 Logo 用法、Typography、Color、Spacing、Layout，以及 Button、Card、Navigation 和 Form 规范。

  3. 03 · 用 Codex 制作单页 Website55 min

    从 Source of Truth 填写企业介绍、产品／服务、成果和咨询入口，使用同一套组件与语气。

  4. 04 · Desktop / Mobile 检查与修改20 min

    实际打开两种布局，检查可读性、完整内容、图片、导航和咨询演示反馈；记录尚未上线。

验收标准

  • 字体、颜色、Button、Card 和 Form 使用统一规则。
  • 企业事实与 L01 一致，课程案例说明内容来源。
  • 桌面和手机无横向溢出，咨询演示不会提交真实信息。

Phase 3 · AI Content Factory

同一份业务事实，形成适合不同渠道的完整内容。

L03

AI Content Factory：企业营销内容工厂

实操授课 · 120 min

从企业资料和业务更新提炼选题，编写 Content Brief，再制作不同渠道的内容草稿。建立事实、品牌、权利与重复检查，并安排 Content Calendar。

  • 根据业务目标定义 Content Pillars。
  • 编写包含受众、目的、依据、渠道和 CTA 的 Content Brief。
  • 制作完整多渠道草稿并完成 Review Checklist。

教学内容

  • 完整 Content Pack 与内容策略
  • 选题与 Content Brief
  • 多渠道内容制作
  • Review 与 Content Calendar

课堂实操

为同一产品设计三个有资料依据的选题，制作小红书、公众号和 LinkedIn 内容草稿，说明各渠道调整。

成果整理与 Review

提交一周 Content Calendar、三个选题与多渠道完整草稿；附来源和人工审核结果。

课堂内教师检查；不承诺额外课后服务。

带走的成果

  • 一周 Content Calendar
  • 多渠道 Content Pack
  • Review Checklist

120 分钟教学安排

  1. 01 · 完整 Content Pack 与内容策略20 min

    展示一周完整内容，定义受众、业务目标和 Content Pillars，解释不同渠道的表达差异。

  2. 02 · 选题与 Content Brief25 min

    从 FAQ、产品、业务更新和案例取材，记录受众、目的、来源、渠道与 CTA。

  3. 03 · 多渠道内容制作50 min

    用 Codex 将同一事实整理为完整渠道草稿，调整语气、长度和信息密度，保留原始依据。

  4. 04 · Review 与 Content Calendar25 min

    检查事实、品牌、素材权利和重复内容，记录待确认事项，形成排期草案。

验收标准

  • 每个选题有业务目标和资料依据。
  • 草稿包含正文和 CTA，不只有标题或封面。
  • 区别 draft / reviewed / approved；不自动外发。

Phase 4 · Codex Video Production

把企业卖点变成可播放、可修改的短视频。

L04

Codex Video Production：企业视频制作

实操授课 · 120 min

用 Codex 编写 Script、Storyboard 并编排品牌动态图文、产品截图和已有素材。使用课前验证的渲染模板完成一条 30–60 秒企业／产品介绍视频。

  • 把企业卖点压缩为一个明确的信息目标。
  • 完成时间、画面、字幕与素材对应的 Storyboard。
  • 预览修改并导出 MP4，保留可编辑源文件。

教学内容

  • 成片展示与 Codex 制作方法
  • Script 与 Storyboard
  • 视频制作与修改
  • 导出与验收

课堂实操

沿用 L02 品牌规范和 L03 内容素材，使用预置视频模板编排 30–60 秒企业介绍；不以付费镜头生成、配音或音乐为必需前提。

成果整理与 Review

提交 MP4、Script、Storyboard、项目源文件与素材来源记录；本地预览、视频导出、平台发布分别记录。

课堂内教师检查；不承诺额外课后服务。

带走的成果

  • 30–60 秒完整 MP4
  • Script 与 Storyboard
  • 可修改源文件与素材清单

120 分钟教学安排

  1. 01 · 成片展示与 Codex 制作方法15 min

    播放完整案例，拆解单一信息、品牌素材和渲染模板的关系，明确 Codex 编排与视频渲染的分工。

  2. 02 · Script 与 Storyboard25 min

    写受众、卖点和 CTA，逐镜对应时间、画面、字幕、素材与过渡。

  3. 03 · 视频制作与修改60 min

    复用品牌规范与已有素材，由 Codex 修改预置渲染模板；逐段预览并调整信息密度和节奏。

  4. 04 · 导出与验收20 min

    导出 MP4，检查播放、时长、字幕、画面和素材来源，整理可编辑项目。

验收标准

  • 视频完整播放，字幕可读，时长在 30–60 秒。
  • 品牌与官网一致，素材来源及权利可解释。
  • 源文件可修改；脚本、分镜或动画预览不能替代最终 MP4。

Phase 5 · Agent Schedule / Workflow Automation

把每周营销工作整理为可重复执行、有人工审核的任务。

L05

Agent Schedule 与 Workflow Automation

实操授课 · 120 min

把企业资料、本周业务更新和上周内容连接成每周营销任务。先手动执行，再配置 Scheduled Task，并演练缺失信息、重复选题和执行失败的处理。

  • 写清 Trigger、Input、Rules、Output 与 Human Review。
  • 跑通一次每周营销工作包，保留来源和待确认事项。
  • 区分手动执行、定时配置和独立定时运行证据。

教学内容

  • 完整每周营销工作包
  • 编写 Workflow 任务说明
  • 手动执行与修改
  • Scheduled Task 配置
  • 异常测试与 Human Review
  • 成果验收与 SOP

课堂实操

读取企业资料、本周业务更新与上周内容，输出三个选题、两篇草稿、审核清单和工作简报。随后检查重复触发、缺失日期、无新资料与环境不可用。

成果整理与 Review

整理任务说明、一次手动执行记录、Scheduled Task 配置与操作 SOP；真实定时触发未发生时明确标记未验证。

课堂内教师检查；不承诺额外课后服务。

带走的成果

  • 完整每周营销工作包
  • 可复用任务与 Schedule Contract
  • 人工审核规则、异常处理与操作 SOP

120 分钟教学安排

  1. 01 · 完整每周营销工作包15 min

    展示输入资料、选题、完整草稿、审核清单与简报，说明哪些由 AI 完成、哪些交人工确认。

  2. 02 · 编写 Workflow 任务说明20 min

    写触发条件、输入版本、输出结构、负责人、时区、停止条件和禁止外发边界。

  3. 03 · 手动执行与修改35 min

    用 Codex 执行任务，核对来源、缺失信息与重复选题，修改任务规则并重跑。

  4. 04 · Scheduled Task 配置20 min

    在授课选定工具中配置重复任务，记录下一次运行时间、时区、输入和输出位置。需要本地文件时保持电脑、应用和项目可用；本次课程创建不启动真实排程。

  5. 05 · 异常测试与 Human Review20 min

    演练缺活动日期、没有新资料、重复触发与输出未审核；标记 blocked 或 needs-review，不编造、不自动发布。

  6. 06 · 成果验收与 SOP10 min

    展示工作包，明确每周需要更新和审核的内容；分别记录手动运行、排程配置和真实定时触发状态。

验收标准

  • 所有事实引用输入资料；未知事项进入待确认清单。
  • 重复运行不覆盖已审核成果，重复选题可识别。
  • 配置明确时区、运行条件、结果落点和暂停方式；真实定时触发另留记录。
