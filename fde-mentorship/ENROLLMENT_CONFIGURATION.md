## 数据关联及写入顺序

复用两个现有隐藏 Training，并为陪跑创建独立 Training。分别创建 Modules → Program → Syllabus → Lessons。每个 Lesson 绑定 Module 和 Syllabus，完整正文写入 `learningMaterial.content`，不是只填销售描述。随后按顺序绑定 Syllabus 的全部课时、Program 的 Syllabus、Training 的 Modules / showPrograms / syllabusesToDisplay / pricingOptions；最后才在中文课程目录显示。

Tech 和 Business 复用本仓库现有完整教学源。陪跑依据官网 12 周框架整理三个阶段，学员在每周指导前提交工作、关键决定、证据和卡点，指导后保留修改与未解决限制。当前计划不改既有视频、资料、作业绑定，不生成真实学生、订单、报名人数或支付记录。

## 同步与验证

必须先备份并下载生产现状，保留其身份和字段；对照源文件生成逐字段变更清单，取得 owner 对这份清单的确认后才写入。写入前重读基线，发现变化先合并。创建操作遇到失败或结果不明时停止，按名称和实际返回 ID 核对，不盲目重试。

同步后回读三个课程详情、报名课程列表、各课程 Program / PricingOption / Syllabus；逐一核对课时数量、正文、顺序、双向关联及学费。刷新生产镜像并重新比较，应无计划内差异。页面分别检查桌面与手机的入口、载入、失败重试及正确课程选择。验证到正式付款前，不创建测试订单、扣款或报名记录；真实支付验收需另有明确范围。
