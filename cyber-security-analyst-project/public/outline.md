# AI 时代 Cyber Security Analyst 项目课

- 周期：16 周
- 节奏：每周 2 次直播，每次 2–3 小时
- 教学方式：直播授课 + 16 周贯穿项目 + 岗位能力考核
- 贯穿项目：HarbourShield Enterprise Security Transformation
- 主要岗位：Junior Cyber Security Analyst、SOC Analyst L1、Security Operations Analyst、IT Security Analyst、Graduate Cyber Security Consultant

## 项目主线

学员作为 HarbourShield 新成立的安全团队，从接管资产、网络、身份、云和日志开始，逐步建立 SIEM 与检测能力，最终处理一条“AI 钓鱼邮件 → 身份被盗 → Token / Cloud 访问 → Endpoint persistence → 数据访问与外传”的复合攻击链。

## 四阶段

1. W1–W3：企业环境、网络、数据流和流量分析。
2. W4–W8：Endpoint、Identity、Cloud、Vulnerability 与 Web/API 风险。
3. W9–W12：Logging、SIEM、Alert Triage、Detection Engineering 与 Threat Hunting。
4. W13–W16：Incident Response、Recovery、Risk、AI Security、综合事件和求职答辩。

## 毕业证据

Asset inventory、architecture diagram、PCAP investigation、IAM review、cloud assessment、vulnerability register、query library、SOC dashboard、detection rules、threat hunting report、incident report、recovery runbook、risk treatment、AI threat model、CV 项目描述与个人技术答辩。
