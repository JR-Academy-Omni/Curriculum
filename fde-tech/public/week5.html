Knowledge check

What does proposal approval need?

  • Explicit scope, assumptions, budget, acceptance criteria and an accountable decision.
  • A working demo without an agreed budget.
  • A feature list approved by a user with no budget authority.
Answer and reasoning

Explicit scope, assumptions, budget, acceptance criteria and an accountable decision.

Explicit scope, assumptions, budget, acceptance criteria and an accountable decision. The decision must be supported by the project evidence.

Reference reasoning

Use the case constraints and policy owners as authority. Approve the implementation scope, budget and acceptance criteria. Inspect the supporting artefacts and unresolved issues before granting approval.
