本周工程任务

TASK 01

Enterprise System Discovery

Inspect an unfamiliar repository, interface documentation and operating records to trace a business request and identify gaps.

Deliverable

System boundary map, interface inventory and investigation questions.

TASK 02

Discovery under Uncertainty

Investigate incomplete customer requirements and distinguish evidence, assumptions and unknowns about users, decision-makers and constraints.

Deliverable

Discovery brief and explicit assumptions.

TASK 03

Data Readiness and Ownership

Check schemas, missing values, versions, ownership and access conditions to decide what data can enter the first phase.

Deliverable

Data readiness assessment and ownership boundaries.

TASK 04

Baselines and Acceptance

Turn requests for better accuracy or speed into inspectable requirements, a baseline and an initial set of checks.

Deliverable

Baseline, acceptance criteria and initial check set.
