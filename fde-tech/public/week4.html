本周工程任务

TASK 08

Retrieval with Evidence

Build retrieval with chunking, versions and citations, including explicit handling of insufficient evidence.

Deliverable

Retrieval implementation, citation checks and insufficient-evidence handling.

TASK 21

Evals and Regression Gates

Build evaluations from normal inputs, boundaries and known failures, with regression criteria for model, prompt and tool changes.

Deliverable

Evaluation set, comparison report and regression criteria.

TASK 23

Testing Retrieval and Permissions

Evaluate citations, knowledge versions, abstention and cross-user access as distinct retrieval and authorisation concerns.

Deliverable

Retrieval and permission evaluation with failure analysis.
