# FDE Tech

FDE Tech 职业进阶班。10 周，每周 180 分钟工作坊，另有约 3–5 小时课外准备与实践。

- `public/outline.json`: canonical course source, including all weeks, lessons, steps, tasks and case packets.
- `public/curriculum.html`: all six modules and all twenty lessons.
- `public/learning-plan.html`, `public/week1.html` through `week10.html`: weekly preparation, workshop, assignment, deliverables, review and official reading.
- `public/outline.html`, `phase1.html` through `phase6.html`: expanded learning material and evidence reviews.
- `public/cases.html`, `outcomes.html`: complete case inputs, reference decisions, budget calculations, implementation and handover requirements.
- `public/reference.py`: executable control implementation using standard Python only.
- `exports/fde-tech.json`: generated Skills Data Manager CourseDetail, with local keys and no fabricated production IDs.

See WORKFLOW.md for build, preview and production boundaries. Sales URL stays `/fde/training`. Curriculum is not indexed or tracked by GA.
