03 · CONSULTATIVE DISCOVERY

先问对问题，再介绍产品。

顾问不是背诵价格表。先判断客户卡在哪一关：缺经历、缺能力、缺表达、缺时间，还是只希望买一个“结果承诺”。

A · GOAL

目标与时间线

  • 目标岗位和行业是什么？
  • 准备投哪一轮、何时开始？
  • 希望这段经历解决哪个问题？
  • 未来在哪个国家/城市求职？
B · EVIDENCE

现有经历与能力

  • 简历上最相关的经历是哪段？
  • 做过什么，个人负责什么？
  • 遇到追问最容易卡在哪里？
  • 有没有作品集或可展示成果？
C · FIT

投入与适配

  • 每周能稳定投入多少时间？
  • 能否按节点提交并修改？
  • 偏技术、产品、数据还是运营？
  • 预算与决策人分别是谁？
推荐的咨询顺序先问目标 → 再看证据 → 找到缺口 → 解释产品如何补缺口 → 说明交付和边界 → 最后谈档位与下一步。不要一上来发价格，也不要用“名企名称”代替需求诊断。

竞品怎么介绍，
我们应该怎么听。

以下是基于现有内部材料与旧版话术归纳的匿名模式，不代表对任何具体品牌的事实认定。涉及品牌名、原话、价格和承诺时，以有日期的原始咨询记录为准。

TYPE A · RESULT-LED

“名企 / Offer / 背书”型

先用公司名、结果和稀缺资源建立吸引力，较少先解释学员实际做什么。

  • 追问：公司和岗位何时确认？
  • 风险：把资源样例听成确定匹配
  • 我们：先评估、再书面确认
TYPE B · DOCUMENT-LED

“证明 / 推荐信 / 背调”型

把材料作为核心卖点，客户容易忽略实际任务、投入和个人产出。

  • 追问：材料由谁出、核验什么？
  • 风险：只想拿纸、不想做项目
  • 我们：材料对应真实完成事实
TYPE C · SERVICE-LED

“导师 / 陪跑 / 求职”型

把课程、项目、简历、投递和面试打包，范围大但边界容易模糊。

  • 追问：频次、SLA、次数和责任人？
  • 风险：误以为所有服务无限次
  • 我们：逐项写清交付和验收

06 · CUSTOMER FAQ

客户会问什么，
顾问应该怎么答。

Q1：这和普通培训班有什么区别？

标准回答：普通课程通常按知识点授课；这个项目以岗位实践为主。你会收到任务简报，完成阶段成果，接受导师反馈并修改，最后把真实成果转成作品集和面试案例。

Q2：具体是哪家公司、什么岗位？

标准回答：可以介绍当期可评估的方向和资源样例，但不能在看简历前承诺具体公司或岗位。需要先确认背景、目标、能力和排期，再书面确认匹配结果。

Q3：导师来自大厂，就等于在那家大厂实习吗？

标准回答：不等于。导师背景、项目主体和材料签发主体是三件事，必须分别说明。最终以匹配确认书中的主体、任务和材料口径为准。

Q4：我具体会做什么？

标准回答：任务根据方向和基础确定，可能是分析、方案、文档、数据、代码、产品或运营成果。匹配后会给出目标、工具、节点和验收标准。

Q5：零基础可以参加吗？

标准回答：可以先评估，但不代表都适合。我们会看学习能力、目标和每周投入；基础不足时会建议先补基础，而不是为了成交直接进入。

Q6：每周投入多少？能完全自由安排吗？

标准回答：远程不等于没有排期。具体会议、任务节点和小时数要在匹配后确认，需要稳定参加必要沟通并按时提交，不能承诺“完全随时做”。

Q7：会有人手把手帮我做吗？

标准回答：导师会解释任务、提供方法和反馈，但成果必须由学员本人完成。我们不代写、代做或制造经历。

Q8：完成后可以写进简历吗？

标准回答：可以基于真实完成的周期、角色、任务和成果如实整理。不能把导师所在公司写成自己的雇主，也不能扩大职责或编造数字。

Q9：会提供 Offer、证书或推荐信吗？

标准回答：取决于具体项目主体和当期书面交付清单。匹配确认前只能记录需求，不能口头保证；即使提供，也只能反映真实参与和表现。

Q10：支持背调吗？能查到什么？

标准回答：是否支持、由谁核验、可核验哪些字段，以项目确认书为准。没有书面规则前，不承诺“任何公司都能查”或“永久可查”。

Q11：能保证拿全职 Offer 或转正吗？

标准回答：不能。我们提供实践、反馈和求职表达训练，录用由用人单位独立决定。任何“保证录用”都不属于产品承诺。

Q12：有没有内推？

标准回答：推荐机会如有，也以当期岗位和明确条件为准；推荐不等于面试，面试不等于录用。不能把可能存在的机会包装成固定交付。

Q13：为什么要先看简历？

标准回答：为了判断你缺什么、能承担什么，以及这项服务是否值得你投入，而不是为了设置门槛。

Q14：三个价格档位差在哪里？

标准回答：当前按导师和项目资源层级分为成长型公司、中大型公司和头部大厂导师三档。具体导师、频次、任务和材料必须逐项写清，不能只用公司名解释价差。

Q15：为什么这么贵？

标准回答：价格对应三个月的评估匹配、任务设计、导师带教、成果反馈和求职转化，不是购买几节视频课，更不是购买一个公司名。

Q16：别家更便宜 / 承诺更多，为什么选你们？

标准回答：不要只比宣传词，逐项比较：谁带、做什么、多久反馈一次、最后留下什么证据、哪些能书面确认。我们要求每条简历表达都能回到真实成果。

Q17：远程实习会不会很水？

标准回答：质量由任务、节点、反馈和成果决定。重点看是否有任务简报、版本记录、导师 Review 和最终产出；如果只有一张证明，没有过程证据，就要谨慎。

Q18：中途跟不上、请假或想退出怎么办？

标准回答：按具体项目的延期、请假、更换和退款规则执行。售前必须提供书面条款，不能用“到时候再说”替代规则。

Q19：什么时候可以开始？

标准回答：先完成评估，再根据当期导师、任务和排期确认开始时间。没有完成匹配前，不承诺固定开工日。

Q20：我只想拿一段经历，不想做任务，可以吗？

标准回答：不可以。我们的原则是真实参与、真实产出、如实表达。如果目标只是购买或包装经历，这个项目不适合你。

07 · OBJECTION HANDLING

处理异议，不是反驳客户。

四步法：确认顾虑 → 找到背后的风险 → 用可核验交付回答 → 给出下一步。

客户异议先问一句回应重点下一步
“太贵了”你主要在和哪种方案比较？拆分周期、反馈、成果和适配度推荐档位或明确不适合
“远程很水”你担心没人管、没任务，还是材料不被认可？展示任务、节点、Review 和证据链提供样例交付清单
“先保证公司”你看重公司名，还是岗位能力与经历？解释评估和资源确认机制先收简历与目标
“别家保证 Offer”对方是否把保证条件和退款写进合同？区分机会与录用承诺建议核验书面条款
“我没时间”未来三个月每周最稳定投入多少？真实任务需要真实投入能满足再匹配，否则延期

09 · TRAINING & ASSESSMENT

会看页面不等于会咨询。

新顾问须完成角色演练，由主管按事实准确性、诊断能力、边界意识和推进能力评分。建议 80 分以上才可独立接待。

只想买“名企经历”

客户追问指定公司、能否把导师雇主写进简历。顾问须重置预期、解释三种主体，并判断是否拒绝销售。

零基础但急着秋招

客户两个月后投递、每周只有 3 小时。顾问须判断适配度，给出先补基础或调整计划的建议。

家长质疑远程真实性

用任务、版本、Review、成果和核验规则解释，不使用“我们肯定靠谱”一类空话。

竞品承诺压价

客户说别家更便宜且保 Offer。帮助核验条款，不攻击品牌、不随口降价、不跟进夸大。

追问证明与背调

细节尚未确认时记录需求、升级确认并明确回复时间，不自行承诺。

独立上岗前检查

  • 能在 30 秒内说明产品，并主动讲清“不是什么”
  • 能完成目标、经历、证据、投入四类诊断提问
  • 能区分导师雇主、项目主体和材料签发主体
  • 能回答 20 个高频问题，不虚构未知信息
  • 能识别至少 6 种禁用承诺
  • 能在不适配时明确劝退
