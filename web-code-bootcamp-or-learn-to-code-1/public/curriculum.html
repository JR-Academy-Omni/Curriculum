TWO-STAGE METHOD

手写与 AI Coding，各在正确的时间出现。

零基础最怕两个极端：一直手写，开发速度跟不上；一开始全交给 AI，出了问题完全看不懂。新版课程把两者分成清楚的两个阶段。

MONTH 01 · NO FULL GENERATION

⌨️ 第一阶段：手写代码

  • 手写页面结构、样式与交互
  • 亲自发出 API 请求并处理错误
  • 用 Git 保存每次变化
  • AI 只可解释、提示、辅助 Debug
→
MONTH 02–03 · AI PAIR PROGRAMMING

🤖 第二阶段：AI 协作开发

  • 把功能拆成 AI 可执行的任务
  • 用 AI 生成骨架，人工审查与修改
  • 让 AI 补测试、排错与重构
  • 每段代码都要能解释、能验收
课程原则：第一阶段，你写每一行；第二阶段，你为每一行负责。

FAQ

你可能还想知道

零基础能学吗？
可以。前四周专门用手写代码建立网页、JavaScript、API 和 Git 基础。但课程节奏紧凑，需要按时看指定录播并完成每次课后作业。
为什么不从第一天就用 AI Coding？
因为 AI 会生成能运行但不一定正确的代码。先建立基础，后面你才有能力判断、调试和修改，而不是被 AI 牵着走。
学习过程中卡住怎么办？
直播课设有集中答疑，课后可以按规范提交问题；关键里程碑还会安排重点检查，帮助学员及时发现并解决项目问题。
录播需要全部看完吗？
不需要。每周会给出必看、选看和资料库三级清单。必看内容只服务于下一堂直播，避免无目标刷课。
AI Coding 阶段是不是不用写代码了？
不是。AI 可以生成初稿，但学生必须阅读、运行、测试和修改。作业会要求提交关键 Prompt 和人工修改记录。
