# 学员 Offer 与感言存档 · Data Engineer / Data Analyst

> slug: `data-engineer-data-analyst`
> 维护：课程运营
> 建立日期：2026-10-15

本目录统一存放数据工程班学员的 Offer、感言和对应凭证。一个学员一份档案，存放于 `students/`；汇总信息维护在 `INDEX.md`。

## 录入规则

- 只记录已经确认的事实；未知字段写“待补”，不猜测。
- Offer 截图必须先脱敏，再存入 `students/_assets/`。
- 学员原话逐字保存，不代写、不润色。
- 未取得明确授权时，素材仅限内部备查，不得用于销售页、公众号、小红书、LinkedIn 或销售话术。
- Offer 记录不得被表述为“包就业”“保 Offer”或课程效果承诺。
